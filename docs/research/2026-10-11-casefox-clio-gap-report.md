## 1. สิ่งที่เห็นจากการลองใช้จริง

### Casefox

เมนูหลัก: Dashboards · Calendar · Tasks · Cases · Clients · Billing · Accounts · Communication · Leads · Vendors · Reports · Settings · Apps · Tags

- **แถบบนสุด**
  - มี **ตัวจับเวลา (timer)** ที่เดินอยู่ตลอด (00:00:00 พร้อมปลุกเตือน)
  - มีปุ่ม Add New
  - มีช่องค้นหาฟีเจอร์ ("Go to features")
- **หน้า Dashboard**
  - Quick Create: ลูกค้า / คดี / ลงเวลา / ค่าใช้จ่าย / ออกบิลทีละหลายคดี / งาน / นัด / ฝากเงิน / ถอนเงิน / บันทึกสายเข้า-สายออก
  - AI ร่างเอกสารและวิเคราะห์เอกสาร: วิจารณ์คำแถลง, ร่างคำแถลงเปิด-ปิดคดี, ประเมินมูลค่าคดี
  - ภาพรวมการเงิน: รับแล้ว / ตัดหนี้สูญ / รอชำระ / ยังไม่ออกบิล
  - กราฟการเติบโตของสำนักงาน
  - ชั่วโมงที่เก็บเงินได้ของวันนี้ แยกรายคน
  - ชั่วโมงงานแยกตามช่วงเวลา
  - รายรับ-รายจ่าย
- **Wizard เริ่มต้นใช้งาน 5 ขั้น**: เพิ่มลูกค้า → เพิ่มคดี → ลงเวลา → ออกบิล → เลือกขั้นต่อไป (ตรวจผลประโยชน์ขัดกันตั้งแต่ตอนกรอกชื่อลูกค้า)
- **แท็บในหน้าคดี**: Dashboard · เวลา/ค่าใช้จ่าย · งานในคดี · บิล · เอกสาร · นัดหมาย · ผู้ติดต่อ · ตั้งค่า · บันทึกการโทร · ประกอบเอกสารจากแม่แบบ · บันทึกการตรวจผลประโยชน์ขัดกัน · โน้ตส่วนตัว
  - Dashboard ของคดีแสดง: ยอดยังไม่ออกบิล, งบที่เหลือ (กรณีกำหนดงบไว้), ออกบิลแล้ว/รับชำระแล้ว, ชั่วโมงที่คิดเงินได้กับไม่คิดเงิน, เงื่อนไขการชำระ, ดอกเบี้ยค้างชำระ, ยอดตัดหนี้สูญ, ชั่วโมงที่ไม่คิดเงิน, ยอดบิลแยกรายคน
- **Accounts**: แยกบัญชีดำเนินงานกับ **บัญชีเงินฝากลูกความ (trust)** มีฝาก/ถอนเงิน และพิมพ์เช็ค
- **Communication**: บันทึกการโทรเข้าและโทรออก
- **Leads**: รายการ **ฟอร์มรับเรื่อง (intake form)** ที่ลูกค้ากรอกเข้ามา เป็นลิงก์สาธารณะหรือฝังในเว็บไซต์ได้
- **Vendors**: ทะเบียนผู้ขาย/ผู้ให้บริการ
- **Settings**
  - ใบแจ้งหนี้: รูปแบบเลขที่, ข้อความท้ายบิล, แม่แบบอีเมล, **ออกบิลอัตโนมัติตามรอบ**, อัตราแลกเปลี่ยน, **อัตราภาษี**
  - ทั่วไป: กฎแบ่งค่าตอบแทนพนักงาน (fee split), **อัตราค่าบริการรายชั่วโมงต่อคน/คดี/ลูกค้า**, กลุ่มฟิลด์เพิ่มเติม, คำย่อ, client portal, LEDES, **กฎคำนวณวันนัด (มีสำเร็จรูป และสร้างเองจากเหตุการณ์ตั้งต้น)**, **กลุ่มงาน (task group)**
  - จัดการ: รหัส UTBMS, หมวดคดี, ประเภทค่าใช้จ่าย, ประเภทนัด, ฟอร์มรับเรื่อง, แท็ก, **ขั้นตอนคดี (case stages)**
  - นำเข้า/ส่งออก: ลูกค้า (Google, QuickBooks, CSV), คดี, เวลางาน, ส่งออกทั้งหมด
- **Reports**: รายงานสำเร็จรูปประมาณ 40 แบบ แบ่ง 10 กลุ่ม (เวลา/ค่าใช้จ่าย, บัญชี/trust, ใบแจ้งหนี้และการชำระ, คดี, ลูกค้า, ผลงาน, บัญชีแยกประเภท, งานและนัด, ผู้ขาย) รวมถึงจดหมายขอเงินฝากเพิ่ม

### Clio Manage

เมนูหลัก: Dashboard · Calendar · Tasks · Matters · Contacts · Activities · Billing · Accounts · Documents · Communications · Reports · App integrations · Settings

- **Dashboard**: แบ่งเป็นของตัวเอง / ของสำนักงาน / ฟีดความเคลื่อนไหว มีวาระวันนี้, **เป้าชั่วโมงที่เก็บเงินได้ของแต่ละคน** และตัวเลขบิล (ร่าง / ยังไม่ชำระ / เกินกำหนด)
- **ฟอร์มสร้างคดีใหม่ (Matter)**
  - "ตั้งค่าจากเอกสาร": **AI ดึงข้อมูลจากเอกสารที่อัปโหลดมากรอกฟิลด์คดีให้**
  - เลือกใช้แม่แบบคดีได้
  - ทนายผู้รับผิดชอบ / ทนายผู้หาคดีมา
  - สาขากฎหมาย, **ขั้นตอนคดี**, สถานะ (เปิด / รอ / ปิด), **วันหมดอายุความ พร้อมช่องติ๊กว่าดำเนินการทันแล้ว**
  - สิทธิ์เข้าถึง: ทุกคน / เฉพาะบางคน / **บล็อกบางคน (ethical wall)**
  - ผู้เกี่ยวข้องพร้อมระบุความสัมพันธ์ และเลือกได้ว่าใครเป็นผู้รับบิล
  - ฟิลด์เพิ่มเติม (custom fields)
- **การเงินในคดี**
  - วิธีคิดค่าบริการ: **รายชั่วโมง / เหมาจ่าย / ตามผลสำเร็จ (contingency)**
  - ตารางอัตรา, อัตราเฉพาะคดี, **งบประมาณคดี**, แยกใบแจ้งหนี้ได้
  - **ยอดขั้นต่ำในบัญชีเงินฝาก + ขอเงินเติมอัตโนมัติ (evergreen) + เตือนเมื่อยอดต่ำ**
  - ใส่ชุดงานให้อัตโนมัติ, โฟลเดอร์เอกสาร, ผูกผลตรวจผลประโยชน์ขัดกัน
- **Tasks**: ประเภทงาน, **ชุดงาน (task list) ไว้ใช้เป็นแม่แบบ**, task feed (ICS)
- **Contacts**: ตรวจผลประโยชน์ขัดกัน, แท็ก
- **Activities**: รายการเวลา / ค่าใช้จ่าย / **ค่าบริการเหมาจ่าย** และหมวดกิจกรรม
- **Bills**
  - ยอดค้างชำระ, แม่แบบบิล, บันทึกการรับชำระ
  - สถานะ: ร่าง → **รออนุมัติ** → ยังไม่ชำระ → ชำระแล้ว
  - มี **ใบขอเงินฝาก (trust request)**
- **Bank accounts**: บัญชี trust และบัญชีดำเนินงาน
- **Documents**: แม่แบบเอกสารพร้อมฟิลด์ผสาน (merge fields)
- **Communications**: client portal (Clio for Clients)
- **Reports**
  - ลูกหนี้, **ลูกหนี้แยกตามอายุหนี้**, บิล, นัดหมาย
  - **ผลงานรายลูกค้า/รายคน**, ธุรกรรมของลูกค้า
  - **การแบ่งค่าตอบแทน / การปันส่วนรับชำระ (เครดิตผู้หาคดี)**
  - การชำระ, ธุรกรรม trust
  - ตัวสร้างรายงานเอง + บันทึกมุมมองรายงานไว้ใช้ซ้ำ
- **Settings → Billing**
  - เตือนบิลอัตโนมัติ, แม่แบบข้อความบิล, ภาษี, ช่องทางรับชำระ
  - **ตารางอัตรา**, UTBMS, เงินที่ต้องกันไว้ (protected funds)
  - PDF ขนาด A4, หน้าปกบิล, LEDES
  - **ปัดเศษเวลา**, ตั้งเวลาเป็นไม่คิดเงินโดยอัตโนมัติในคดีเหมาจ่ายหรือคดีตามผลสำเร็จ
  - ล็อกบิลที่อนุมัติแล้ว, ส่งบิลเป็นลิงก์ PDF ที่ปลอดภัยหรือแนบไฟล์
- **Settings อื่น ๆ**
  - บทบาทและสิทธิ์, กลุ่มและตำแหน่งงาน, ชุดฟิลด์เพิ่มเติม
  - **ถังกู้คืน (recovery bin)**, MFA และการจัดการ session
  - ข้อความสำเร็จรูป (text snippets), การแจ้งเตือน
  - **กฎศาล (เลือกตามเขตอำนาจศาล)**, แม่แบบอีเมลและลายเซ็น
  - การรันเลขคดีและสาขากฎหมาย, สำรองข้อมูลไป S3 (data escrow), แชร์งานกับทนายร่วม (co-counsel)
- **Automated Workflows**: เมื่อเกิดเหตุการณ์ (สร้างคดี / เปลี่ยนขั้นตอน / แปลงมาจาก Grow) ให้ทำอัตโนมัติ (ใส่ชุดงาน / สร้างเอกสารจากแม่แบบ / ใช้แม่แบบคดี)

## 3. ลำดับที่แนะนำให้สร้าง

เกณฑ์เลือก: คุณค่าต่อสำนักงานกฎหมายไทย × ต่อยอดจากของที่มีอยู่ได้ × ขนาดงาน

**ระยะที่ 1: แกนเวลาและเงิน** (ช่องว่างใหญ่ที่สุด และงานอื่นเกือบทั้งหมดต้องใช้)
1. ตารางอัตรา: อัตราต่อทนาย และกำหนดทับต่อคดี/ลูกค้าได้ → เติม `TimeEntry.rate` ให้อัตโนมัติ
2. ตัวจับเวลากลาง (แถบบนของเว็บ + มือถือ) → บันทึกเป็น TimeEntry
3. หน้าลงเวลาในหน้าคดี + หน้า Timesheet รวมทั้งสำนักงาน
4. วิธีคิดค่าบริการต่อคดี: รายชั่วโมง / เหมาจ่าย / ตามผลสำเร็จ + งบประมาณ
5. ใบแจ้งหนี้: VAT 7% / หัก ณ ที่จ่าย 3%, ส่วนลด, ตัดหนี้สูญ, ยกเลิก, รูปแบบเลขที่

**ระยะที่ 2: เงินฝากลูกความและการติดตามหนี้**

6. บัญชีเงินฝากลูกความ (ฝาก, ถอน, หักชำระบิล, ยอดขั้นต่ำ + เตือนเมื่อยอดต่ำ)
7. PDF ใบแจ้งหนี้ฝั่งเซิร์ฟเวอร์ + ส่งอีเมล + เตือนชำระอัตโนมัติ (มี scheduler อยู่แล้ว)
8. ลูกค้าจ่ายบิลออนไลน์ผ่าน Omise PromptPay (เชื่อม Omise ไว้แล้ว)

**ระยะที่ 3: ให้สำนักงานตั้งค่าคดีเองได้ + ระบบอัตโนมัติ**

9. ขั้นตอนคดีที่สำนักงานกำหนดเอง (แทน enum) + หน้าจัดการฟิลด์เพิ่มเติม
10. แม่แบบคดี + ระบบอัตโนมัติแบบเงื่อนไข → การกระทำ (เปลี่ยนขั้นตอน → ใส่ชุดงาน / สร้างเอกสาร)
11. เป้าชั่วโมงรายคน + รายงานผลงานและอัตราการใช้เวลา

**ระยะที่ 4: มีก็ดี**

12. ซิงก์ปฏิทิน Outlook/Google + ICS feed
13. ตัวสร้างฟอร์มรับเรื่องสาธารณะ
14. ลงนามอิเล็กทรอนิกส์, ข้อความสำเร็จรูป, ถังกู้คืน, นำเข้า/ส่งออก CSV, ตัวสร้างรายงาน

**ไม่ทำ**: LEDES/UTBMS (ใช้เฉพาะอเมริกา), พิมพ์เช็ค, SMS (LINE ทำหน้าที่แทนแล้ว), ซิงก์ QuickBooks/Xero
