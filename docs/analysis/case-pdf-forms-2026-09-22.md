# ส่งออกคำฟ้องหน้าแรกและปกสำนวน

เพิ่มในหน้าคดีปัจจุบันแล้ว (local ยังไม่ได้ deploy)

## วิธีใช้

1. เปิดหน้าคดี กด **ส่งออกคำฟ้อง / ปกสำนวน** ด้านบน
2. เลือก **คำฟ้อง (หน้าแรก)** หรือ **ปกสำนวนคดี**
3. ตรวจแก้ข้อมูลที่ดึงมาจากคดี ช่องที่ยังไม่มีข้อมูลจะเว้นว่าง
4. หากต้องใช้โลโก้สำนักงานหรือตราครุฑ ให้เลือกภาพต้นฉบับ PNG/JPEG ภาพจะใช้ในเครื่อง ไม่อัปโหลด
5. ตรวจตัวอย่าง A4 แล้วกด **พิมพ์ / บันทึก PDF** เลือกปลายทาง Save as PDF ตั้ง A4 แนวตั้ง ขนาด 100% และปิดหัว/ท้ายกระดาษ
6. สลับแบบเพื่อส่งออกอีกใบ แยกเป็น PDF คนละไฟล์

เป็นการบันทึก PDF ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์ ยังไม่ใช่ปุ่มดาวน์โหลด PDF โดยตรง

## ขอบเขตแบบฟอร์ม

- คำฟ้องเฉพาะหน้าแรกตามที่ผู้ใช้เลือก มีข้อมูลศาล คู่ความ ทุนทรัพย์ ข้อมูลติดต่อ ข้อความเปิดคำฟ้อง และช่องลงชื่อ
- ปกสำนวนมีเลขอ้างอิง กรมธรรม์ เลขคดี ศาล คู่ความ ทุนทรัพย์ วันสำคัญ นัดพิจารณา 12 ช่อง และวันในชั้นอุทธรณ์/ฎีกา
- ไม่คัดลอกข้อมูลส่วนตัว เลขคดี หรือลายเซ็นจากภาพตัวอย่างเข้าไปในคดี
- แบบจัดหน้าสร้างตามโครงสร้างภาพตัวอย่าง แต่ไม่ได้ตรงแบบศาลทุกตำแหน่ง: รวมช่องรายละเอียดบุคคลและที่อยู่บางส่วนไว้ด้วยกัน และไม่มีภาพตราให้โดยอัตโนมัติ หากต้องตรงต้นฉบับทุกช่อง จำเป็นต้องใช้แบบเปล่าหรือ PDF ต้นฉบับที่เห็นครบหน้า
- ข้อมูลแก้ไขใช้เฉพาะการจัดพิมพ์ในหน้านี้ ยังไม่บันทึกร่างลงระบบ และหายเมื่อโหลดหน้าใหม่ มีข้อความแจ้งบนหน้าจอ

## หลักฐานตรวจสอบ

- ทดสอบชื่อและบทบาทคู่ความ การเว้นข้อมูลไม่ทราบ ทุนทรัพย์ศูนย์ การ escape HTML การไม่โหลดภาพภายนอก และไม่ใส่ข้อมูลส่วนตัวของคำฟ้องบนปกสำนวน: ผ่าน
- TypeScript: ผ่าน
- เปิดหน้าคดีจริงหลังล็อกอิน พบปุ่มใหม่ เปิดทั้งสองแบบได้ และตรวจภาพตัวอย่างภาษาไทยบนหน้าจอ
- ทดสอบข้อความยาว 100 บรรทัด: ปุ่มพิมพ์ถูกปิดและแจ้งว่าข้อความเกิน A4
- ย่อข้อความแล้วปุ่มพิมพ์กลับมาพร้อมใช้งาน กดเรียกการพิมพ์ได้โดยไม่พบ console error
- ยังไม่ได้ยืนยันการบันทึก PDF ปลายทางหรือเปิดไฟล์ PDF ที่บันทึกจากหน้าต่างพิมพ์ และยังไม่ได้ทดสอบมือถือ
