# ปรับฟอร์มเพิ่มและแก้ไขข้อมูลคดี

ขอบเขตการตรวจ: local ยังไม่ได้ deploy

## สิ่งที่เปลี่ยน

- ฟอร์มแก้ไขเรียงเป็น ข้อมูลหลักคดี → ศาลและหมายเลขคดี → เลขอ้างอิงและจำนวนเงิน
- ย้ายชื่อคดีและข้อหาหรือฐานความผิดขึ้นต้นฟอร์ม แยกคำอธิบายข้อเท็จจริงออกจากข้อหา
- คู่ความและผู้เกี่ยวข้องอยู่ในการ์ดข้อมูลคดี ถัดจากศาลในหน้าดูข้อมูล ปุ่ม “บันทึกข้อมูลคดี” กับ “บันทึกคู่ความรายนี้” ระบุขอบเขตชัดเจน
- ฟอร์มคู่ความรองรับชื่อบริษัทอย่างชัดเจน แสดงประเภทบุคคล ฐานะในคดี และฝ่ายแยกกัน พร้อมพับที่อยู่/เลขประจำตัว/ข้อมูลเสริม
- เพิ่ม label ที่สัมพันธ์กับช่องกรอกและขยายพื้นที่กด
- หน้าสร้างคดีมีข้อหาหรือฐานความผิดอยู่ใต้ชื่อคดี ไม่ต้องเปิดข้อมูลเพิ่มเติม และใช้ข้อมูลช่องเดียวกับฟอร์มแก้ไข (`customFields.chargeSection`)
- เชื่อมข้อหาที่บันทึกไว้กับคำฟ้องหน้าแรกและปกสำนวน เมื่อข้อมูลคดีเปลี่ยน ตัวช่วยส่งออกจะรับข้อมูลล่าสุดเมื่อเปิดใหม่
- แก้คำเป็น **หมายเลขคดีแดง** ทั้งในฟอร์มส่งออกและแบบพิมพ์ ตามที่ผู้ใช้ระบุ

## การตรวจ

- เปิดหน้าคดีจริงหลังล็อกอิน และบันทึกผ่านฟอร์มใหม่ด้วยข้อมูลเดิมสำเร็จ ไม่ใส่ข้อหาสมมติลงคดี
- เปิดฟอร์มเพิ่มคู่ความจริงและตรวจชื่อช่องกับปุ่มบันทึก โดยไม่สร้างคู่ความทดสอบ
- ตรวจฟอร์มแก้ไขที่ 320, 768, 1024, 1440 px: ไม่ล้นแนวนอน และ input/select/textarea ทุกช่องมี label
- ตรวจภาพมือถือ 320 px และภาพ desktop
- เปิดหน้าสร้างคดีจริง: ข้อหาแสดงหนึ่งช่องและมองเห็นได้โดยไม่เปิดข้อมูลเพิ่มเติม ยังไม่ได้ส่งสร้างคดีใหม่
- ทดสอบข้อมูลข้อหาไปยังเอกสารทั้งสองแบบ รวมค่าว่างและข้อมูลเก่าผิดชนิด: ผ่าน
- TypeScript และ diff whitespace check: ผ่าน
- ค้นใน source ของ web/API/shared ไม่เหลือคำ “คดีหมายเลขแดง”

การทดสอบนี้ยังไม่ครอบคลุมการสร้างคดีใหม่จนจบหรือการบันทึกคู่ความใหม่จริง และไม่ได้ยืนยัน PDF ปลายทางเพิ่มเติมจากรอบก่อน
