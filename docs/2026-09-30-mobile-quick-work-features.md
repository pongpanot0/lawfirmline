# Mobile: เพิ่มอะไรจากเว็บเพื่อทำงานให้จบไว

ข้อเสนอวันที่ 30 กันยายน 2026 จากโค้ดใน checkout นี้ ยังไม่ได้ทดสอบบนเครื่องจริงหรือยืนยันเวอร์ชันที่ผู้ใช้ติดตั้ง

## สิ่งที่มีแล้ว

Mobile มีวันนี้ คดี ปฏิทิน งาน ทีม ลูกความ Court Day บันทึกค่าใช้จ่าย ส่งชุดเบิก อนุมัติ/จ่ายชุดเบิก และขอลาแล้ว หน้ารายละเอียดงานมีมอบหมาย แนบไฟล์ ความคิดเห็น ส่งตรวจ ผ่านตรวจ และส่งกลับแก้ไขด้วย

จึงควรเพิ่มทางเข้ากับขั้นตอนสั้น ๆ ให้คนทำงานจบได้เร็ว มากกว่าขยายจำนวนเมนู

## แบ่งเป็น 5 ชุดฟีเจอร์

| ลำดับ | ชุด | เอาจากเว็บมาใช้บนมือถืออย่างไร | ตัวอย่างใช้งานเร็ว |
|---|---|---|---|
| 1 | สั่งงานและตามงาน | เพิ่มตัวกรอง **งานของฉัน / งานที่ฉันสร้าง / รอตรวจ** พร้อมสถานะ ผู้รับผิดชอบ กำหนดส่ง และข้อความล่าสุด | เจ้าของเปิดงานที่ฉันสร้าง → เห็นงานค้าง → เปิดแล้วตามงานหรือเปลี่ยนคน |
| 2 | งานที่ต้องจัดการวันนี้ | ย่อ Daily Workboard และ Action Center เป็นรายการ **ต้องตาม / รอฉันตรวจ / ยังไม่มีคนรับ** กดแล้วเข้าเรื่องนั้นโดยตรง | เปิดแอป → เห็นงานส่งตรวจ → ดูไฟล์และผลส่งงาน → ผ่านหรือส่งกลับ |
| 3 | เอกสารหน้างาน | จากหน้าเอกสารคดี เพิ่ม **ถ่ายเอกสารเข้าคดี** และชุดเอกสารสำหรับนัดที่เลือก | ถ่ายคำสั่งศาล → ตรวจรูป → ยืนยันคดีและประเภท → บันทึกไว้ให้สำนักงานทำต่อ |
| 4 | ส่งต่อหลังขึ้นศาล | ต่อ Court Day เข้ารายงานลูกความ ให้เห็นผลนัด นัดถัดไป งานติดตาม และร่างรายงานในทางเดียวกัน | บันทึกผลนัด → ตรวจสิ่งที่จะสร้าง → ยืนยัน → เปิดร่างรายงานที่สำนักงานรับต่อ |
| 5 | รับเรื่องลูกความแบบสั้น | ย่อ Intake เป็น **ชื่อลูกความ / ช่องทางติดต่อ / เรื่องที่ติดต่อ** แนบไฟล์ได้ แล้วเข้าคิวรับเรื่องเดิม | คุยโทรศัพท์ → จด 3 ช่อง → บันทึกเข้าคิว → กลับมาทำรายละเอียดบนเว็บ |

### ชุด 1: สั่งงานและตามงาน — ทำก่อน

- ใช้หน้ารายละเอียดงานเดิม เพิ่มตัวกรองบนหน้างาน ไม่สร้างระบบงานใหม่
- งานที่ฉันสร้างต้องยังเห็นหลังมอบหมายให้คนอื่น โดยใช้ผู้สร้างเป็นฐาน ไม่ใช้ผู้รับผิดชอบแทน
- เพิ่มงานแบบสั้น: ชื่องาน + ผู้รับผิดชอบ; กำหนดส่ง รายละเอียด ไฟล์ และผู้ตรวจเปิดเพิ่มเมื่อต้องใช้
- การตามงานต้องบันทึกว่าตามเมื่อไร และเห็นความคืบหน้าล่าสุด ถ้าจะส่งแจ้งเตือนให้ใช้ช่องทางที่ระบบรองรับและยืนยันผลจากระบบ
- การส่งตรวจ/ผ่านตรวจ/ส่งกลับมีอยู่แล้ว ให้พาจากตัวกรองเข้าหน้าเดิมได้ทันที

### ชุด 2: งานที่ต้องจัดการวันนี้ — ทำต่อจากชุด 1

- หน้าแรกแสดงเรื่องที่เกี่ยวกับสิทธิ์ของผู้ใช้ พร้อมเหตุผลสั้น ๆ เช่น “เลยกำหนด 2 วัน” หรือ “ส่งตรวจแล้ว”
- OWNER เห็นงานที่ต้องตัดสินใจและงานทีม; ผู้ตรวจเห็นงานที่ส่งถึงตัวเอง; LAWYER/ASSISTANT เห็นงานและนัดของตัวเองตามสิทธิ์จริง
- ใช้ Action Center เดิมที่มีทางเข้าใน mobile แล้ว เพิ่มทางเข้าตรงถึงงานและตัวกรอง ไม่เพิ่มกล่องแจ้งเตือนอีกชุด
- คิวงานพักไว้ต้องเปิดถึงงานนั้นได้ พร้อมเรื่องที่รอและวันติดตาม
- ทุกการอนุมัติให้เห็นรายละเอียดก่อนยืนยัน การแจ้งเตือนเป็นทางเข้า ไม่ใช่การอนุมัติอัตโนมัติ

### ชุด 3: เอกสารหน้างาน

- ปุ่ม “ถ่ายเอกสารเข้าคดี” อยู่ในคดีและ Court Day โดยเติมคดี/นัดที่เปิดอยู่ให้แล้ว
- ถ่ายหลายหน้า ตรวจรูป ตั้งประเภท แล้วอัปโหลดเข้าระบบเอกสารเดิม; ไม่สร้างคลังเอกสารแยก
- แยกสถานะ “เก็บในเครื่องแล้ว / กำลังส่ง / ส่งแล้ว / ส่งไม่สำเร็จ” ให้ชัด ปิดแอปแล้วรูปที่ยังไม่ส่งต้องไม่หาย
- เอกสารสำหรับขึ้นศาลแสดงชื่อ รุ่น และเวลาที่เตรียมไว้ พร้อมเปิดตรวจได้
- ต่อความสามารถเตรียมเอกสารของ Court Day เดิม โดยทดสอบเปิดไฟล์หลังปิดเน็ตและเปิดแอปใหม่ก่อนแสดงว่าพร้อมออฟไลน์ ปัจจุบัน README ยังระบุข้อจำกัดการกู้ session เมื่อไม่มีเน็ต
- OCR/AI และการตรวจข้อมูลละเอียดทำต่อในเว็บได้ ไม่ต้องขวางขั้นตอนถ่ายและเก็บเอกสาร

### ชุด 4: ส่งต่อหลังขึ้นศาล

- ใช้ร่างและการยืนยัน Court Day เดิม ให้เห็นว่ายังเป็นร่างหรือยืนยันผลแล้ว
- แสดงนัดถัดไปและงานติดตามที่จะสร้างก่อนยืนยัน พร้อมผู้รับผิดชอบ
- เพิ่มทางเข้าเปิดร่างรายงานลูกความและดูสถานะการตรวจ/ส่งจากระบบรายงานเดิม
- แสดงผู้รับและข้อความจริงก่อนการส่ง ลูกความไม่ควรได้รับข้อความจากการบันทึกผลนัดอย่างเดียว
- ใช้การพิมพ์ด้วยเสียงจากคีย์บอร์ดเครื่องได้ก่อน ระบบถอดเสียงเฉพาะเพิ่มเมื่อมีความต้องการจริง

### ชุด 5: รับเรื่องลูกความแบบสั้น

- บันทึกเป็นเรื่องเข้าคิว Intake ไม่สร้างคดีทันที
- เปิดรายละเอียดลูกความเดิมจากเรื่องที่รับได้ เพื่อลดการสร้างคนซ้ำ
- แนบรูป/ไฟล์และเก็บร่างได้ เรื่องไม่ครบยังกลับมาเติมต่อได้
- ให้สำนักงานประเมินข้อมูล เอกสาร และผลประโยชน์ขัดกันในเว็บตามกระบวนการเดิม

## ลำดับทำที่แนะนำ

**รอบแรก: ชุด 1 + ส่วนทางเข้าของชุด 2** — งานที่ฉันสร้าง รอตรวจ รายการต้องตาม และทางเข้าถึงรายละเอียดงาน ใช้สิ่งที่มีแล้วมากที่สุด

**รอบสอง: ชุด 3 + ชุด 4** — ถ่ายเอกสารเข้าคดี เตรียมไฟล์สำหรับนัด และส่งต่อรายงานหลังขึ้นศาล

**รอบสาม: ชุด 5** — รับเรื่องสั้นบนมือถือเมื่อทีมมีการรับเรื่องนอกสำนักงานจริง

## รูปแบบหน้าจอให้ไว

- คงแท็บหลัก **วันนี้ / คดี / ปฏิทิน / งาน / ทีม** ที่มีอยู่ ใช้ “เพิ่มเติม” สำหรับงานไม่ประจำ
- ปุ่มเพิ่มเปิดตัวเลือกสั้น ๆ: **งาน / เอกสาร / ค่าใช้จ่าย / รับเรื่อง** ตามสิทธิ์
- ถ้าเริ่มจากคดีหรือนัด ให้เติมบริบทให้แล้ว ลดการเลือกซ้ำ
- เป้าหมายคือถึงจุดทำงานในไม่เกิน 2–3 กดจากหน้าที่เกี่ยวข้อง ไม่รวมการกรอกและตรวจข้อมูล
- รายละเอียดเพิ่มเติมซ่อนไว้หลังปุ่มเปิดเพิ่ม ฟอร์มหลักไม่ควรบังคับกรอกครบเหมือนเว็บ

## ยังให้ทำบนเว็บ

รายงานวิเคราะห์เต็ม การเงิน/ใบแจ้งหนี้หลายรายการ งานเอกสารยาว การค้นคว้ากฎหมายเชิงลึก ตั้งค่าสำนักงาน สิทธิ์ และ audit log ส่วนการเบิก/อนุมัติที่มีใน mobile แล้วให้ใช้ต่อได้

## เกณฑ์ตรวจรอบแรก

1. สร้างงานและมอบหมายให้คนอื่นแล้ว ผู้สร้างยังหาเจอใน “งานที่ฉันสร้าง”
2. ผู้ตรวจเปิดจาก “รอตรวจ” แล้วดูหลักฐาน ผ่านตรวจ หรือส่งกลับได้ตามสิทธิ์เดิม
3. กดรายการต้องตามแล้วเข้าถึงงานตรงตัว ไม่ต้องค้นหาใหม่
4. วันที่และสถานะตรงกับเว็บ เมื่อทำรายการสำเร็จแล้วหน้ารวมปรับตาม
5. คนละสำนักงานไม่เห็นงานกัน และผู้ไม่มีสิทธิ์ทำรายการไม่ได้แม้เรียก API โดยตรง

## หลักฐานจากโค้ดที่ตรวจ

- `apps/mobile/app/task/new.tsx`: มีมอบหมาย ความคิดเห็น แนบไฟล์ และขั้นตอนส่งตรวจอยู่แล้ว
- `apps/mobile/app/notifications.tsx` และ `apps/mobile/app/(tabs)/index.tsx`: ใช้ Action Center และมีทางเข้าแจ้งเตือนแล้ว
- `apps/mobile/app/operations.tsx`: คิวงานพักไว้ปัจจุบันเชื่อมไปคดี

- `apps/web/src/components/operations/DailyWorkboard.tsx`: งานยังไม่มีคนรับ งานต้องตาม และการบันทึกการติดตาม
