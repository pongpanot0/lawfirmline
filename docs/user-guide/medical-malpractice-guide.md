# คู่มือรับคดีทางการแพทย์ (Medical Malpractice Case Guide)

> **วันที่จัดทำ:** 2026-07-28  
> **ประเภทคดี:** คดีเวชปฏิบัติ / ละเมิดทางการแพทย์ (Medical Negligence / Malpractice)  
> **ครอบคลุม:** ตั้งแต่ขั้นตอนก่อนฟ้อง (Pre-litigation) จนถึงการยื่นฟ้องต่อศาล

---

## ภาพรวมกระบวนการ / Process Overview

```
รับเอกสารจากลูกค้า
       ↓
ประเมินเบื้องต้น (Initial Assessment)
       ↓
รวบรวมเวชระเบียนและพยานหลักฐาน
       ↓
ปรึกษาผู้เชี่ยวชาญทางการแพทย์
       ↓
วิเคราะห์ความผิดพลาดและความเชื่อมโยง (Causation)
       ↓
ตัดสินใจ: ฟ้อง / ไม่ฟ้อง / เจรจา / ร้องเรียน ก.พ.ส. / แพทยสภา
       ↓
(ถ้าฟ้อง) เตรียมคำฟ้องและยื่นต่อศาล
```

## ขั้นที่ 2 — รวบรวมข้อมูลและเอกสาร (Document Collection)

### 2.1 เวชระเบียน (Medical Records) — สำคัญที่สุด

> **กฎหมาย:** พ.ร.บ.สุขภาพแห่งชาติ พ.ศ. 2550 มาตรา 7 — ผู้ป่วยมีสิทธิได้รับข้อมูลในเวชระเบียน  
> **ระยะเวลาเก็บ:** สถานพยาบาลต้องเก็บไม่น้อยกว่า 5 ปี (ข้อบังคับ กสธ.)

| เอกสาร | วิธีขอ | ใช้เพื่อ |
|--------|--------|---------|
| บันทึกการรักษา (OPD/IPD notes) | ยื่นคำขอเป็นหนังสือแนบสำเนาบัตรประชาชน | พิสูจน์ขั้นตอนการรักษา |
| ผลการตรวจทางห้องปฏิบัติการ (Lab results) | รวมในคำขอเวชระเบียน | หลักฐานสภาพร่างกาย ณ เวลารักษา |
| ผลภาพถ่ายรังสี / MRI / CT scan | ขอทั้ง film และ report | พยานหลักฐานสำคัญ |
| บันทึกการผ่าตัด (Operative notes) | | ขั้นตอนที่แพทย์ทำ |
| บันทึกการให้ยา (Medication administration record) | | ยาที่ใช้ ขนาด เวลา |
| บันทึกพยาบาล (Nursing notes) | | สัญญาณชีพ อาการ การเปลี่ยนแปลง |
| ใบยินยอมรับการรักษา / ผ่าตัด (Consent forms) | | พิสูจน์ว่าแพทย์แจ้งความเสี่ยงครบหรือไม่ |
| ใบรับรองแพทย์ (Medical certificate) | | สรุปการวินิจฉัยและการรักษา |
| ใบมรณบัตร (ถ้าเสียชีวิต) | สำนักงานเขต/อำเภอ | ระบุสาเหตุการตาย |
| รายงานการชันสูตรพลิกศพ (Autopsy report) | สถาบันนิติเวชวิทยา / กรมแพทย์ทหารบก | พิสูจน์สาเหตุการตายที่แท้จริง |

**หมายเหตุสำคัญ:** หากสถานพยาบาลปฏิเสธหรือล่าช้า ให้ยื่นคำขอเป็นลายลักษณ์อักษรและเก็บหลักฐานการยื่น — ใช้เป็นข้อโต้แย้งภายหลังได้

### 2.2 หลักฐานค่าใช้จ่าย / ความเสียหายทางการเงิน

| เอกสาร | ใช้เพื่อ |
|--------|---------|
| ใบเสร็จค่ารักษาพยาบาลทุกใบ | คำนวณค่าเสียหายทางทรัพย์สิน |
| ใบเสร็จค่าใช้จ่ายในการรักษาต่อเนื่อง | รวมถึงค่าฟื้นฟูสมรรถภาพ |
| หลักฐานรายได้ก่อนเกิดเหตุ (สลิปเงินเดือน/หนังสือรับรองรายได้) | คำนวณค่าขาดรายได้ |
| หลักฐานรายได้หลังเกิดเหตุ (ถ้ายังทำงานได้บางส่วน) | |
| ใบเสร็จค่าดูแลผู้ป่วยที่บ้าน / ค่าจ้างผู้ดูแล | |
| ใบเสร็จอุปกรณ์การแพทย์ที่ซื้อเอง | เช่น วีลแชร์ อุปกรณ์ช่วยฟื้นฟู |

### 2.3 หลักฐานอื่น

| เอกสาร | หมายเหตุ |
|--------|---------|
| ภาพถ่ายบาดแผล / สภาพร่างกาย | ถ่ายตั้งแต่แรก ระบุวันที่ |
| บันทึกการสื่อสารกับโรงพยาบาล | อีเมล LINE ข้อความ |
| ชื่อพยานที่อยู่ในห้องรักษา | ญาติ พยาบาล |
| ข้อร้องเรียนถึงโรงพยาบาล (ถ้ามี) | และคำตอบที่ได้รับ |

## ขั้นที่ 3 — การวิเคราะห์คดี (Case Analysis)

### 3.1 เกณฑ์ประเมินว่าควรฟ้องหรือไม่ (Go/No-Go Criteria)

คดีทางการแพทย์ต้องพิสูจน์ **4 องค์ประกอบ** (เหมือนละเมิดทั่วไป ป.พ.พ. มาตรา 420):

| องค์ประกอบ | คำถามที่ต้องตอบ | แหล่งพิสูจน์ |
|-----------|---------------|-------------|
| **1. หน้าที่ดูแล (Duty of Care)** | แพทย์/โรงพยาบาลมีหน้าที่ดูแลผู้ป่วยรายนี้หรือไม่? | เวชระเบียน ใบรับตัว |
| **2. ละเมิดมาตรฐาน (Breach of Standard)** | การรักษาต่ำกว่ามาตรฐานวิชาชีพ (Standard of Care) หรือไม่? | ความเห็นผู้เชี่ยวชาญ แนวปฏิบัติ ราชวิทยาลัย |
| **3. ความเชื่อมโยง (Causation)** | ความผิดพลาดนั้นเป็นสาเหตุ**โดยตรง**ของความเสียหายหรือไม่? | ผู้เชี่ยวชาญ + เวชระเบียน |
| **4. ความเสียหาย (Damages)** | มีความเสียหายที่วัดเป็นตัวเงินได้หรือไม่? | ค่ารักษา ค่าขาดรายได้ ความเจ็บปวด |

### 3.2 บันทึกการวิเคราะห์ภายใน (Internal Analysis Record)

| ฟิลด์ | รายละเอียด |
|-------|-----------|
| มาตรฐานวิชาชีพที่เกี่ยวข้อง (Standard of Care reference) | เช่น แนวปฏิบัติราชวิทยาลัย แนวทาง WHO/สธ. |
| ความเห็นผู้เชี่ยวชาญเบื้องต้น | แพทย์เฉพาะทางสาขาที่เกี่ยวข้อง |
| ระดับความผิดพลาด | ชัดเจน / เป็นไปได้ / ไม่ชัดเจน |
| ความแข็งแกร่งของ causation | แข็งแกร่ง / ปานกลาง / อ่อนแอ |
| ความเสียหายที่คำนวณได้ (เบื้องต้น) | |
| ค่าใช้จ่ายในการดำเนินคดี (ประมาณ) | |
| คำแนะนำ: ฟ้อง / ไม่ฟ้อง / เจรจา / ร้องเรียน | |
| เหตุผลประกอบคำแนะนำ | |

## ขั้นที่ 4 — ช่องทางดำเนินการ (Options Before Filing)

### 4.1 เจรจากับสถานพยาบาล (Out-of-Court Settlement)

- บันทึก: วันที่ ผู้ร่วมเจรจา ข้อเสนอที่ได้รับ
- ถ้าบรรลุข้อตกลง: ทำสัญญาประนีประนอมยอมความ (ป.พ.พ. ม.850)
- กำหนดเงื่อนไข: จำนวนเงิน วิธีชำระ เงื่อนไขไม่ฟ้อง

### 4.2 ร้องเรียนแพทยสภา (Thai Medical Council Complaint)

> **ช่องทาง:** ยื่นเรื่องต่อ**แพทยสภา** (ม.49 พ.ร.บ.วิชาชีพเวชกรรม พ.ศ. 2525)  
> **ผล:** ลงโทษทางวิชาชีพแพทย์ (ไม่ใช่ค่าเสียหายทางแพ่ง)  
> **ประโยชน์:** ผลการสอบสวนอาจเป็นพยานในคดีแพ่งได้

| ฟิลด์บันทึก | รายละเอียด |
|------------|-----------|
| วันที่ยื่นร้องเรียน | |
| เลขที่รับเรื่อง | |
| ผลการพิจารณา | |
| วันที่ได้รับผล | |

### 4.3 ร้องเรียน สปสช. / กองทุนชดเชยผู้ได้รับผลเสียจากบริการสาธารณสุข

> **มาตรา 41 พ.ร.บ.หลักประกันสุขภาพแห่งชาติ พ.ศ. 2545** — กรณีผู้ป่วยสิทธิบัตรทอง  
> ชดเชยได้โดยไม่ต้องพิสูจน์ความผิด (no-fault compensation) สูงสุด **400,000 บาท**

| ฟิลด์บันทึก | รายละเอียด |
|------------|-----------|
| สิทธิการรักษาของผู้ป่วย | บัตรทอง / ประกันสังคม / ราชการ / เอกชน |
| วันที่ยื่นขอ ม.41 | |
| ผลการพิจารณา | |
| จำนวนเงินชดเชย | |
| รับชดเชยแล้วส่งผลต่อสิทธิฟ้องหรือไม่ | ต้องพิจารณาก่อนรับ — อาจตัดสิทธิฟ้องเพิ่ม |

## ขั้นที่ 5 — ข้อมูลเฉพาะในคดีทางการแพทย์ (Medical-Specific Case Fields)

### 5.1 ข้อมูลทางการแพทย์ที่ต้องบันทึก

| ฟิลด์ | รายละเอียด | เหตุผล |
|-------|-----------|--------|
| วินิจฉัยโรคเริ่มต้น (Initial diagnosis) | | ตรวจสอบว่าวินิจฉัยถูกต้องหรือไม่ |
| วินิจฉัยโรคสุดท้าย (Final/correct diagnosis) | | เปรียบเทียบ |
| หัตถการที่ทำ (Procedures performed) | | ว่าทำถูกต้องตามมาตรฐานหรือไม่ |
| ยาที่ใช้ + ขนาด (Medications & dosages) | | ตรวจสอบความถูกต้อง |
| ผลข้างเคียงที่เกิดขึ้น (Adverse events) | | |
| การแจ้งความเสี่ยง (Informed consent content) | | ตรวจสอบว่าแจ้งครบหรือไม่ |
| ผู้เชี่ยวชาญที่ปรึกษา (Specialists consulted) | | |
| เหตุการณ์ฉุกเฉินระหว่างรักษา (Adverse events timeline) | เวลาแต่ละเหตุการณ์ | สร้าง timeline |

### 5.2 ความเสียหายเฉพาะทางการแพทย์

| ประเภทความเสียหาย | ฟิลด์ที่ต้องบันทึก |
|-----------------|-----------------|
| ค่ารักษาพยาบาล | ยอดทั้งหมด แยกตามสถานพยาบาล |
| ค่ารักษาต่อเนื่อง (อนาคต) | ความเห็นแพทย์เรื่องค่าใช้จ่ายอนาคต |
| ค่าขาดรายได้ | รายได้ก่อน-หลัง ระยะเวลาหยุดงาน |
| ค่าขาดรายได้ถาวร (กรณีพิการ) | อัตราร้อยละที่สูญเสียสมรรถภาพ |
| ค่าดูแลตลอดชีวิต (กรณีพิการถาวร) | คาดการณ์จากผู้เชี่ยวชาญ |
| ค่าเสียหายทางจิตใจ (Pain & Suffering) | ป.พ.พ. ม.446 |
| ค่าอุปการะ (กรณีเสียชีวิต) | ทายาทที่มีสิทธิ — ป.พ.พ. ม.443 |
| ค่าปลงศพ (กรณีเสียชีวิต) | ป.พ.พ. ม.443 |

### 5.3 อายุความที่ต้องระวัง

| กรณี | อายุความ | นับจาก | อ้างอิง |
|-----|---------|--------|---------|
| ละเมิด (รู้ตัวผู้ทำ) | **1 ปี** | วันที่รู้ถึงการละเมิดและรู้ตัวผู้ทำ | ป.พ.พ. ม.448 |
| ละเมิด (ไม่รู้ตัวผู้ทำ) | **10 ปี** | วันเกิดเหตุละเมิด | ป.พ.พ. ม.448 |
| ผิดสัญญา (ถ้าฟ้องรูปสัญญา) | **10 ปี** | วันที่รู้ว่าผิดสัญญา | ป.พ.พ. ม.193/30 |
| คดีปกครอง (โรงพยาบาลรัฐ) | **1 ปี** | วันที่รู้ความเสียหาย | พ.ร.บ.ศาลปกครองฯ ม.51 |
| อาญา (ฐานประมาทเป็นเหตุให้ผู้อื่นถึงแก่ความตาย) | **10 ปี** | วันเกิดเหตุ | ป.อ. ม.95 |

> **คำเตือน:** สำหรับคดีที่โรงพยาบาลเป็นของรัฐ อาจต้องฟ้องทั้งทางแพ่งและทางปกครองควบคู่กัน และอายุความทางปกครอง (1 ปี) สั้นกว่ามาก

### 5.4 การเลือกช่องทางการฟ้อง (Jurisdictional Choice)

| ช่องทาง | ฟ้องใคร | ศาลที่ยื่น | ข้อดี | ข้อเสีย |
|--------|---------|----------|------|--------|
| **คดีแพ่ง** | แพทย์ + โรงพยาบาล | ศาลแพ่ง / ศาลจังหวัด | เรียกค่าเสียหายได้เต็ม | ต้องพิสูจน์ความผิด |
| **คดีปกครอง** | หน่วยงานรัฐ (ถ้าโรงพยาบาลรัฐ) | ศาลปกครอง | พิสูจน์ง่ายกว่า (รับผิดโดยองค์กร) | ค่าเสียหายอาจน้อยกว่า |
| **คดีอาญา** | แพทย์เป็นการส่วนตัว | ศาลอาญา | กดดันให้เจรจา | ต้องพิสูจน์เจตนา/ประมาทเลินเล่อ |
| **ร้องเรียนแพทยสภา** | แพทย์ | แพทยสภา | ไม่ต้องพิสูจน์แบบคดี | ไม่ได้ค่าเสียหาย |
| **ม.41 สปสช.** | ไม่มีจำเลย (no-fault) | สปสช. | เร็ว ไม่ต้องพิสูจน์ | จำกัด 400,000 บาท |

## ขั้นที่ 6 — ข้อมูลสำหรับยื่นฟ้อง (Filing Information)

เมื่อตัดสินใจฟ้อง ให้ใช้ข้อมูลจากส่วนที่ 1–5 ร่วมกับ field มาตรฐานตาม [คู่มือ field ทั่วไป](./thai-case-fields.md) และเพิ่มเติมดังนี้:

### 6.1 จำเลยที่เป็นได้ในคดีทางการแพทย์

| จำเลย | กรณีที่ฟ้อง | ฐาน |
|------|-----------|-----|
| แพทย์ผู้รักษา | ความผิดพลาดส่วนตัว | ป.พ.พ. ม.420 (ละเมิด) |
| โรงพยาบาลเอกชน | รับผิดในฐานนายจ้าง | ป.พ.พ. ม.425 |
| โรงพยาบาลรัฐ | รับผิดโดยองค์กร | พ.ร.บ.ความรับผิดทางละเมิดของเจ้าหน้าที่ พ.ศ. 2539 |
| บริษัทผู้ผลิตอุปกรณ์ | ถ้าอุปกรณ์บกพร่อง | ป.พ.พ. ม.420 + พ.ร.บ.คุ้มครองผู้บริโภค |
| บริษัทผู้ผลิตยา | ถ้ายาบกพร่อง / ไม่แจ้งเตือน | ป.พ.พ. ม.420 + พ.ร.บ.ยา |

### 6.2 พยานผู้เชี่ยวชาญ (Expert Witnesses) — สำคัญมาก

| ฟิลด์ | รายละเอียด |
|-------|-----------|
| ชื่อผู้เชี่ยวชาญ | |
| สาขาความเชี่ยวชาญ | ต้องตรงกับประเด็นในคดี |
| คุณสมบัติ (credentials) | วุฒิการศึกษา ตำแหน่ง ประสบการณ์ |
| ราชวิทยาลัย/สมาคมที่สังกัด | |
| ความเห็นในคดีนี้ (Opinion) | สรุปความเห็น — ต้องตอบ 4 องค์ประกอบ |
| รูปแบบการให้ความเห็น | หนังสือ / มาให้การในศาล |

### 6.3 Checklist เอกสารก่อนยื่นฟ้อง

- [ ] เวชระเบียนครบถ้วน (OPD/IPD/Lab/X-ray)
- [ ] ใบมรณบัตร / รายงานชันสูตร (ถ้าเสียชีวิต)
- [ ] หลักฐานค่าใช้จ่ายทุกรายการ
- [ ] ความเห็นผู้เชี่ยวชาญ (ลายลักษณ์อักษร)
- [ ] Timeline เหตุการณ์ (เรียงตามเวลา)
- [ ] คำนวณอายุความและยืนยันว่ายังไม่ขาด
- [ ] ตรวจสอบว่ารับเงิน ม.41 แล้วหรือไม่ (กระทบสิทธิ)
- [ ] ตรวจสอบว่ามีการร้องเรียนแพทยสภาและผลเป็นอย่างไร
- [ ] คำนวณทุนทรัพย์และค่าธรรมเนียมศาล
- [ ] ใบแต่งทนายความ (ลงนามโดยลูกค้า)

## เปรียบเทียบกับบริษัทประกัน (Insurance Company vs Law Firm)

> **อ้างอิง:** MSIG Thailand (msig-thai.com), Salesforce Insurance Claims Data Model (industry standard), เอกสารศิริราช/มหิดล

### ข้อมูลที่บริษัทประกันเก็บต่อ 1 Claim

บริษัทประกันภัยแยก entity ออกเป็น 3 ชั้น — สำนักงานกฎหมายควรออกแบบ schema แบบเดียวกัน:

### Entity 1: Case (เทียบกับ Claim)

| ฟิลด์ | ประเภท | หมายเหตุ |
|-------|--------|---------|
| เลขคดีสำนักงาน | Text | รหัสภายใน generate อัตโนมัติ |
| วันที่รับเรื่อง | Date | วันแรกที่รับ intake |
| วันที่เปิดเป็นคดี | Date | วันที่ตัดสินใจรับเป็น case |
| ประเภทคดี | Enum | แพ่ง / อาญา / ปกครอง / ทางการแพทย์ ฯลฯ |
| ประเภทย่อย | Text | เช่น "ละเมิดทางการแพทย์ — ผ่าตัด" |
| สถานะ | Enum | Intake / ประเมิน / ดำเนินคดี / เจรจา / ปิด |
| ผลคดี | Enum | ชนะ / แพ้ / เจรจายอม / ถอนฟ้อง / อยู่ระหว่าง |
| ศาลที่ยื่น | Text | |
| เลขคดีดำ / เลขคดีแดง | Text | กำหนดโดยศาล |
| อายุความหมดเมื่อ | Date | คำนวณและล็อกไว้ตั้งแต่รับเรื่อง |
| ทนายหลัก | FK → User | |
| มูลค่าความเสียหายที่เรียกร้อง | Number | |
| มูลค่าที่ได้รับจริง (ถ้าปิดแล้ว) | Number | |

| เบอร์โทร / อีเมล | Text | |
| ทนายความของฝ่ายตรงข้าม | Text | ถ้าทราบ |

### Entity 4: Case Item / รายการ (เทียบกับ Claim Item)

> ใช้ติดตามค่าใช้จ่าย, หัตถการ, หรือรายการเรียกร้องแต่ละรายการแยกกัน

| ฟิลด์ | ประเภท | หมายเหตุ |
|-------|--------|---------|
| ประเภทรายการ | Enum | ค่าธรรมเนียมศาล / ค่าผู้เชี่ยวชาญ / ค่ารักษาพยาบาล / ค่าขาดรายได้ / อื่นๆ |
| คำอธิบาย | Text | เช่น "ค่าผ่าตัดสมอง วันที่ 3 ม.ค. 2567" |
| จำนวนเงิน | Number | |
| วันที่เกิดรายการ | Date | |
| เอกสารประกอบ | File | ใบเสร็จ / ใบรับรอง |
| สถานะ | Enum | รอเรียกร้อง / เรียกร้องแล้ว / ได้รับแล้ว / ปฏิเสธ |

**สิ่งที่ประกันเก็บแต่ทนายอาจยังขาด:**

| ฟิลด์ประกัน | ทนายควรเก็บด้วย | เหตุผล |
|-----------|--------------|--------|
| Record integrity flag | สถานะความสมบูรณ์เวชระเบียน + วันที่ตรวจสอบ | เวชระเบียนที่ถูกแก้ไขใช้เป็นหลักฐานความไม่สุจริตได้ |
| Document status ต่อรายการ | checklist เอกสาร + สถานะ (ได้รับ/รอ/ขาด) | ประกันติดตาม document ทุกชิ้น ทนายควรทำเช่นกัน |
| Autopsy/police report certified flag | ใบมรณบัตร + รายงานชันสูตร certified แล้วหรือไม่ | MSIG กำหนดว่าต้อง certified โดยเจ้าหน้าที่ |
| Claim line items (แยกต่อหัตถการ) | รายการค่าใช้จ่ายแยกต่อ procedure | ใช้ตอบโต้ข้อโต้แย้งแต่ละรายการ |

### Field พิเศษสำหรับคดีทางการแพทย์ (จากงานวิจัย)

**1. สถานะเวชระเบียน — สำคัญที่สุดในคดีทางการแพทย์ไทย**

> ศาลไทยให้น้ำหนักเวชระเบียนสูงกว่าพยานบุคคล หลักที่ว่า *"the medical record never dies"* เป็นที่ยอมรับในการพิจารณาคดี  
> การแก้ไข ปลอมแปลง หรือทำลายเวชระเบียน = หลักฐานความไม่สุจริต อาจนำไปสู่คดีอาญา  
> *(อ้างอิง: เอกสารคณะแพทยศาสตร์ศิริราชพยาบาล มหาวิทยาลัยมหิดล)*

| ฟิลด์ | ประเภท | หมายเหตุ |
|-------|--------|---------|
| วันที่ได้รับเวชระเบียนต้นฉบับ | Date | บันทึกทันทีที่รับ |
| เวชระเบียนต้นฉบับหรือสำเนา | Enum | ต้นฉบับ / สำเนารับรอง / สำเนาธรรมดา |
| พบร่องรอยการแก้ไข | Boolean | ✓ ถ้าพบการขีดฆ่า ลบ หรือเพิ่มเติม |
| รายละเอียดการแก้ไขที่พบ | Text | ระบุหน้า วันที่ ลักษณะการแก้ไข |
| วันที่ตรวจสอบความสมบูรณ์ | Date | |
| ผู้ตรวจสอบ | FK → User | |

**2. เอกสารกรณีเสียชีวิต (ตามมาตรฐานบริษัทประกัน MSIG)**

| เอกสาร | ต้องการ | หมายเหตุ |
|--------|--------|---------|
| รายงานชันสูตรพลิกศพ | บังคับ | ต้องได้รับการรับรองโดยเจ้าหน้าที่ |
| รายงานตำรวจ | บังคับ | ต้องได้รับการรับรองโดยเจ้าหน้าที่ |
| ใบมรณบัตร | บังคับ | |
| หลักฐานสาเหตุการตายที่แท้จริง | บังคับ | อาจต่างจากที่ระบุในใบมรณบัตร |

### กรมธรรม์ประกันวิชาชีพแพทย์ (Medical Professional Liability)

ถ้าแพทย์/โรงพยาบาลมีประกันนี้ บริษัทประกันจะเข้ามาเจรจาแทน — ทนายต้องบันทึก:

| ฟิลด์ | หมายเหตุ |
|-------|---------|
| ชื่อบริษัทประกัน | |
| เลขกรมธรรม์ | ถ้าทราบ — ขอจากโรงพยาบาลได้ |
| วงเงินความรับผิด (limit of liability) | กำหนดเพดานการเจรจา |
