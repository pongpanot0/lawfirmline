# Annual Case Summary Export — Spec สำหรับบัญชี

> **วันที่จัดทำ:** 2026-07-28  
> **รูปแบบ:** Excel (.xlsx)  
> **ช่วงเวลา:** รายปีบัญชี (กำหนดวันเริ่ม–สิ้นสุดได้เอง)  
> **ผู้ใช้งาน:** ฝ่ายบัญชี / หุ้นส่วน

---

## โครงสร้าง Excel (Sheet แยกตามหมวด)

ไฟล์ 1 ไฟล์มี **5 Sheet**:

| Sheet | เนื้อหา |
|-------|--------|
| `หน้าปก` | สรุปตัวเลขสำคัญ (KPIs) ทั้งปีในหน้าเดียว |
| `รายรับ-ค่าทนาย` | รายการค่าทนายทุก invoice แยกตามคดี |
| `ค่าใช้จ่าย` | ค่าธรรมเนียมศาลและค่าใช้จ่ายอื่นตามคดี |
| `ลูกหนี้ค้างชำระ` | Invoice ที่ยังไม่ได้รับชำระ ณ วันปิดปีบัญชี |
| `สถิติคดี` | จำนวนและสถานะคดีในรอบปี |

| พารามิเตอร์ | ค่า | หมายเหตุ |

## หมายเหตุสำหรับนักพัฒนา

- ใช้ **วันที่ชำระจริง** (payment date) ไม่ใช่วันที่ออก Invoice เป็นเกณฑ์จัดรอบรายรับ
- Outstanding คือ Invoice ที่ `status = "ค้างชำระ"` และ `invoiceDate ≤ periodEnd`
- ค่าใช้จ่ายที่ยังค้างเรียกคืนจากลูกค้า ไม่ถือเป็นรายรับ — แสดงแยกใน Sheet 3
- ชื่อ Sheet ภาษาไทยได้เลย บัญชีเปิดอ่านง่ายกว่า
- แถวสีสลับ (zebra stripes) + freeze row แรก ทุก Sheet
