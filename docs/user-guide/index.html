เริ่มต้นใช้งาน

มือถือ

เข้าสู่ระบบ

ใช้อีเมลและรหัสผ่านเดียวกับบนเว็บ บัญชีสร้างโดยเจ้าของสำนักงาน ถ้ายังไม่มีให้ขอคำเชิญจากเจ้าของสำนักงาน

  1. กรอก "อีเมล" ของบัญชีสำนักงาน
  2. กรอก "รหัสผ่าน" (แตะรูปตาเพื่อดูรหัสที่พิมพ์)
  3. แตะ "เข้าสู่ระบบ" ถ้าระบบขอ "รหัสยืนยัน 6 หลัก" ให้กรอกแล้วแตะ "ยืนยันรหัส"
  4. ลืมรหัส แตะ "ลืมรหัสผ่าน" แล้วกรอกอีเมลเพื่อรับลิงก์ตั้งรหัสใหม่
มือถือ

แท็บ วันนี้ — หน้าแรกหลังเข้าสู่ระบบ

สรุปสิ่งที่ต้องทำวันนี้ในจอเดียว ทั้งงานเกินกำหนด นัดวันนี้ คิวตัดสินใจ และทางลัดไปทุกเมนู แถบด้านล่างมี 5 แท็บ: วันนี้ / คดี / ปฏิทิน / งาน / ทีม

  1. อ่าน "เกินกำหนด" และ "นัดวันนี้" ก่อนเริ่มงาน
  2. แตะ "เลขา" เพื่อพิมพ์หรือพูดถามข้อมูลคดี
  3. แตะ "สรุปประจำวัน" (เจ้าของ/ผู้จัดการสำนักงาน) ดูงานค้างของทีม
  4. แตะไอคอนกระดิ่งเพื่อดูการแจ้งเตือน ไอคอนตารางคือ "เมนูเพิ่มเติม"
  5. ใช้ "ทางลัด" ไป ค้นไฟล์ · ค้นอีเมล · ขอลา · รับเคส · ค่าใช้จ่าย
มือถือ

เมนู อื่น ๆ

รวมเมนูที่ไม่อยู่บนแถบล่าง แบ่งเป็น งานสำนักงาน / เอกสารและข้อมูล / บัญชีและการตั้งค่า

  1. จากหน้า วันนี้ แตะ "เมนูเพิ่มเติม"
  2. งานสำนักงาน: ขอลา, ชุดเบิก, ลูกความ, ค่าใช้จ่าย, ยืนยันเวลา, รับเคสใหม่
  3. เอกสารและข้อมูล: ค้นหาไฟล์, ค้นหาอีเมล, รอเอกสารจากภายนอก, รายงาน, คลังความรู้
  4. ด้านล่างสุดมี "ออกจากระบบ" และ "ลบบัญชีและข้อมูล"

คดี

มือถือ

แท็บ คดี — รายการคดี

ดูคดีทั้งหมดที่คุณเข้าถึงได้ ค้นหาและกรองตามสถานะ แตะการ์ดเพื่อเปิดแฟ้มคดี

  1. แตะแท็บ "คดี"
  2. พิมพ์เลขคดี ชื่อคดี หรือชื่อลูกความในช่องค้นหา
  3. เลือกตัวกรอง ทั้งหมด / เปิดอยู่ / ปิดแล้ว
  4. แตะการ์ดคดีเพื่อเปิดรายละเอียด
  5. แตะ "+ รับเคส" มุมขวาบนเพื่อเปิดคดีใหม่
มือถือ

แฟ้มคดี

ข้อมูลทุกอย่างของคดีเดียว แบ่งแท็บ ภาพรวม / นัดหมาย / งาน / เอกสาร / อีเมล

  1. "ภาพรวม" ดูคนหลัก คนรอง ลูกความ ศาล เลขคดี และคู่ความ
  2. "นัดหมาย" เพิ่มนัด หรือเปิด Court Day ของนัดศาล
  3. "งาน" เพิ่มงานหรือเปิดงานในคดี
  4. "เอกสาร" แนบเอกสารด้วยการถ่ายรูป สร้างจากแบบสำเร็จ หรือบันทึกเอกสารที่รอจากภายนอก
  5. แตะ "แก้ไข" มุมขวาบนเพื่อแก้ข้อมูลคดี; ปิดคดีได้จากปุ่ม "ปิดคดี · ตรวจรายการค้าง"
มือถือ

รับเคสใหม่

เปิดคดีใหม่จากมือถือได้ทันที กรอกเฉพาะช่องที่มี * ก็บันทึกได้ ข้อมูลอื่นเติมทีหลัง

  1. กรอก "ชื่อคดี"
  2. เลือก "คนรับผิดชอบหลัก" และ "คนรอง" (ถ้ามี)
  3. พิมพ์ชื่อเพื่อค้นหา "ลูกความ" หรือสร้างใหม่
  4. ถ้ามี เติมคู่ความ ศาล ประเภทคดี และไฟล์
  5. แตะ "บันทึกเคส"
มือถือ

ลูกความ

สมุดรายชื่อลูกความ ใช้หาเบอร์โทร/อีเมล และคดีของแต่ละราย (เพิ่มลูกความใหม่ทำบนเว็บ)

  1. เปิดจาก อื่น ๆ → ลูกความ
  2. พิมพ์ชื่อในช่อง "ค้นหาชื่อลูกความ"
  3. แตะชื่อเพื่อดูรายละเอียด
มือถือ

รายละเอียดลูกความ

ผู้ติดต่อทุกคนของลูกความพร้อมเบอร์และอีเมล และรายการคดีที่เปิดอยู่/ปิดแล้ว

  1. แตะเบอร์โทรเพื่อโทรออกทันที
  2. แตะอีเมลเพื่อเปิดแอปอีเมล
  3. แตะคดีในส่วน "คดี" เพื่อเปิดแฟ้มคดี

ปฏิทินและวันขึ้นศาล

มือถือ

แท็บ ปฏิทิน

ปฏิทินรายเดือน (ปี พ.ศ.) วันที่มีจุดคือมีนัด แตะวันเพื่อดูนัดของวันนั้น

  1. แตะลูกศรเพื่อเปลี่ยนเดือน
  2. แตะวันที่เพื่อดูรายการนัด
  3. แตะนัดศาลแล้วเลือก "เปิดวันขึ้นศาล" หรือ "เปิดทีมที่ไปด้วย"
  4. แตะ "+ เพิ่มนัด" เพื่อสร้างนัดในวันที่เลือก
มือถือ

เพิ่มนัดหมาย

สร้างนัดศาล นัดลูกความ หรือวันครบกำหนด พร้อมจัดทีมที่ไปด้วย ระบบเตือนถ้าคนในทีมลาวันนั้น

  1. เลือก "คดี" และ "ประเภท" (นัดศาล / นัดลูกความ / ครบกำหนด / อื่นๆ)
  2. กรอก "ชื่อนัดหมาย" เช่น นัดสืบพยานโจทก์ และเลือกศาล
  3. เลือกวันและเวลา
  4. เลือกคนหลักและคนที่ไปด้วย แล้วติ๊ก "ตรวจแล้ว · ยืนยันบันทึกทีมนี้"
  5. แตะ "บันทึกนัดหมาย"
มือถือ

วันขึ้นศาล (Court Day)

ผู้ช่วยสำหรับวันนัดศาล แบ่ง 3 ช่วง: ก่อนไป → ที่ศาล → เติมที่สำนักงาน ร่างเก็บในเครื่องอัตโนมัติ ผลนัดบันทึกจริงเมื่อกดยืนยันเท่านั้น

  1. "ก่อนไป" ติ๊กเช็คลิสต์: ตรวจเอกสาร ยืนยันทีม ตรวจสถานที่และเวลา
  2. "ที่ศาล" จดสั้น ๆ ระหว่างพิจารณา
  3. "เติมที่สำนักงาน" กรอกผลนัด นัดครั้งหน้า งานที่ต้องทำต่อ และใบเสร็จ
  4. แตะ "ตรวจทานและยืนยันผลนัด" แล้ว "ยืนยันผลนัด"
  5. ผู้ช่วยดูได้อย่างเดียว ทนาย/เจ้าของแก้ไขได้

งาน

มือถือ

แท็บ งาน

กล่องงานของคุณ แยกมุมมอง งานของฉัน / งานที่ฉันสร้าง / รอฉันตรวจ (เจ้าของมี ต้องตาม และ ยังไม่มีคนรับ เพิ่ม)

  1. เลือกมุมมองด้านบน
  2. แตะงานเพื่อเปิดหน้าทำงาน
  3. ติ๊กช่องหน้างานเมื่อเสร็จ (งานที่รอตรวจติ๊กจากรายการไม่ได้)
  4. แตะ "เพิ่มงาน" เพื่อสร้างงานใหม่
มือถือ

เพิ่มงาน / มอบหมายงาน

สร้างงานใหม่โดยเริ่มจาก ชื่องาน กับ ผู้รับผิดชอบ รายละเอียดอื่นซ่อนไว้ในส่วนเพิ่มเติม

  1. กรอก "ชื่องาน" เช่น ร่างคำให้การ
  2. เลือก "ผู้รับผิดชอบ" (แตะ "ช่วยเลือกคน" เพื่อเทียบภาระงานทีม)
  3. ตั้ง "กำหนดส่ง": ไม่กำหนด / วันนี้ / พรุ่งนี้ / เลือกวัน
  4. ถ้าต้องตรวจก่อนปิด ตั้งผู้ตรวจในส่วนเพิ่มเติม
  5. แตะ "+ เพิ่มงาน"
มือถือ

หน้าทำงาน

ทำงานหนึ่งชิ้นจนจบ: รับงาน แนบผลงาน รายงานความคืบหน้า แจ้งจุดติดขัด แล้วส่งตรวจ

  1. แตะ "รับงานนี้" เมื่อเริ่มทำ
  2. แนบไฟล์ใน "ผลงานและไฟล์แนบ"
  3. เขียน "รายงานความคืบหน้า" (ทำแล้ว / เหลืออะไร / ติดอะไร)
  4. ติดขัดให้แตะ "แจ้งเอกสารขาด / จุดติดขัด"
  5. แตะ "ส่งตรวจงาน" หรือ "บันทึกว่างานเสร็จ"; ผู้ตรวจเลือก ผ่าน หรือ ส่งกลับแก้ไข
มือถือ

ยืนยันเวลา

ระบบเสนอรายการเวลาทำงานของวันจากนัด งาน อีเมล ให้ติ๊กยืนยันแทนการจดเอง

  1. เลือกวันที่ด้านบน
  2. ติ๊กรายการที่ทำจริงและปรับจำนวนชั่วโมง
  3. แตะ "เพิ่มเวลา" ถ้ามีงานที่ไม่อยู่ในรายการ
  4. แตะ "ยืนยัน N รายการ"

เอกสาร

มือถือ

แนบเอกสารเข้าคดี

ถ่ายรูปเอกสารหรือเลือกไฟล์ในเครื่อง ส่งเข้าแฟ้มคดีโดยตรง

  1. จากแฟ้มคดี แท็บ เอกสาร แตะ "แนบเอกสาร"
  2. แตะ "แนบไฟล์หรือรูป" แล้วถ่ายรูปหรือเลือกไฟล์
  3. แตะ "ส่ง N ไฟล์เข้าคดี" (ถ้าส่งไม่ครบ แตะ "ส่งไฟล์ที่เหลือ")
มือถือ

สร้างเอกสารจากแบบ

สร้างไฟล์ Word จากแบบเอกสารของสำนักงาน ข้อมูลคดีเติมให้อัตโนมัติ

  1. เลือก "แบบเอกสาร"
  2. ตรวจร่างและเติมช่องที่ระบบแจ้งว่า "ยังต้องเติม"
  3. แตะ "สร้างไฟล์ DOCX เก็บในคดี"
มือถือ

รอเอกสารจากภายนอก

จดรายการเอกสารที่รอจากลูกความหรือหน่วยงาน พร้อมวันติดตาม ไม่ให้ลืมทวง

  1. แตะ "เพิ่มรายการเอกสารที่รอ"
  2. กรอก เอกสารที่รอ, รอจากใคร, วันติดตามครั้งถัดไป
  3. เมื่อได้รับ แตะ "ได้รับ … แล้ว" แล้วแนบเข้าคดี
มือถือ

ค้นหาไฟล์

ค้นชื่อไฟล์ในทุกคดีและงานที่คุณมีสิทธิ์

  1. พิมพ์ชื่อไฟล์บางส่วน
  2. แตะผลลัพธ์เพื่อเปิดไฟล์ หรือ "เข้าแฟ้มคดี"
มือถือ

ค้นหาอีเมล

ค้นอีเมลจากทุกคดีที่เข้าถึงได้ ด้วยชื่อลูกความ อีเมล เลขคดี หรือชื่อไฟล์แนบ

  1. พิมพ์อย่างน้อย 2 ตัวอักษร
  2. แตะผลลัพธ์ที่ผูกคดีเพื่อเปิดอีเมล (อีเมลที่ยังไม่ผูกคดีเปิดดูบนเว็บ)
มือถือ

คลังความรู้

อ่านสรุปคดี แนวคำพิพากษา กลยุทธ์ และบทเรียนที่สำนักงานบันทึกไว้ (เพิ่มรายการบนเว็บ)

  1. ค้นหาหรือเลือกหมวด
  2. แตะรายการเพื่ออ่านต่อ หรือ "เปิดคดี" ที่เกี่ยวข้อง
มือถือ

เลขา — ถามข้อมูลด้วยเสียงหรือข้อความ

ถามเรื่องคดี เอกสาร หรือนัดหมายด้วยภาษาปกติ ระบบตอบเป็นการ์ดที่แตะเปิดได้

  1. แตะ "แตะเพื่อพูด" แล้วพูดคำถาม หรือพิมพ์ในช่อง "ถามเลขา…"
  2. แตะ "ส่ง"
  3. แตะการ์ดคำตอบเพื่อเปิดคดี นัด หรือเอกสาร

ค่าใช้จ่ายและการลา

มือถือ

ค่าใช้จ่าย

บันทึกค่าใช้จ่ายหน้างาน เก็บเป็นร่างไว้ก่อน แล้วเลือกรวมส่งเบิกเป็นชุด

  1. แตะ "เพิ่มค่าใช้จ่าย"
  2. รายการที่บันทึกแล้วอยู่ใน "บันทึกแล้ว · รอส่งเบิก"
  3. ติ๊กรายการที่จะเบิก แล้วแตะ "ส่งเบิกชุดที่เลือก" → "ส่งชุดนี้"
มือถือ

เพิ่มค่าใช้จ่าย

กรอกรายการค่าใช้จ่ายพร้อมถ่ายใบเสร็จ ร่างเก็บในเครื่องอัตโนมัติแม้สัญญาณหลุด

  1. เลือก "เบิกค่าอะไร" (อื่นๆ ต้องใส่รายละเอียด)
  2. กรอก "จำนวนเงิน (บาท)" และ "วันที่จ่าย"
  3. แตะ "ถ่ายใบเสร็จ" หรือ "เลือกรูป" และเลือกคดี (ถ้ามี)
  4. แตะ "บันทึกค่าใช้จ่าย" หรือ "เก็บเป็นร่างแล้วออก"
มือถือ

ชุดเบิก

ติดตามสถานะชุดเบิก: รออนุมัติ / อนุมัติ · รอจ่าย / จ่ายแล้ว / ไม่อนุมัติ เจ้าของสำนักงานเห็นชุดของทั้งทีม

  1. เลือกตัวกรองสถานะ
  2. แตะชุดเพื่อดูรายการและใบเสร็จ
  3. เจ้าของ: แตะ "อนุมัติทั้งชุด" / "ไม่อนุมัติทั้งชุด" แล้วยืนยัน และ "บันทึกว่าจ่ายเงินชุดนี้แล้ว" เมื่อจ่าย

ส่งคำขอลาและดูสถานะ ลาป่วยบันทึกอนุมัติทันที ลากิจ/ลาพักร้อนรอเจ้าของสำนักงานอนุมัติ

  1. เลือกประเภท ลาป่วย / ลากิจ / ลาพักร้อน
  2. เลือก "วันที่ลา" (เปิด "ลาหลายวัน" ถ้าลาต่อเนื่อง)
  3. แตะ "ส่งคำขอลา" → "ส่งคำขอ"
  4. ดูสถานะใน "คำขอของฉัน"

ทีมและเจ้าของสำนักงาน

มือถือ

แท็บ ทีม

ภาระงานรายคน เรียงจากงานมากไปน้อย เห็นใครมีงานเกินกำหนดหรือมีนัดวันนี้

  1. ดูตัวเลข งานเปิดทั้งทีม และ นัดศาล 7 วัน
  2. แตะ "งาน" / "คดี" / "นัดหมาย" ใต้ชื่อเพื่อกรองข้อมูลของคนนั้น
  3. แตะการ์ดเพื่อดูรายละเอียดสมาชิก
  4. แตะ "ดูภาระงานทีมล่วงหน้า 7 วัน" ก่อนมอบหมายงาน
มือถือ

ภาระงานทีม 7 วัน

ตารางงาน นัด และวันลาของแต่ละคนล่วงหน้า 7 วัน ใช้เลือกคนรับงานใหม่

  1. เลือก "เริ่มดูตั้งแต่วันที่"
  2. เรียง "ภาระมากก่อน" หรือ "ภาระน้อยก่อน"
  3. แตะคนเพื่อดูงานรายชิ้น ย้ายงาน หรือมอบหมายเพิ่ม
มือถือ

สรุปประจำวัน

สำหรับเจ้าของและผู้จัดการสำนักงาน สรุปงานค้าง งานเลยกำหนด และผู้รับผิดชอบของวัน

  1. เลือกวันที่
  2. อ่านยอด งานค้าง / เลยกำหนด
  3. แตะรายการเพื่อเปิดงานหรือคดี
มือถือ

คิวตัดสินใจวันนี้

รวมเรื่องที่รอเจ้าของ/ผู้จัดการตัดสินใจ: งานรอตรวจ ลารออนุมัติ เบิกรออนุมัติ และงานที่ต้องเข้าไปช่วย

  1. เลือกตัวกรองด้านบน
  2. คำขอลา: แตะ "เทียบกำลังคนช่วงวันลา" แล้ว "อนุมัติคำขอลา" หรือ "ไม่อนุมัติ"
  3. แตะงานเพื่อเปิดดูและช่วยแก้
มือถือ

เงินสำนักงาน / ลูกหนี้

ภาพรวมเงินรายเดือน: ลูกหนี้ เงินรับแล้ว วางบิลแล้ว ยังไม่วางบิล (เจ้าของและผู้จัดการสำนักงาน)

  1. เลือกเดือนด้วยลูกศร
  2. ดู "ยอดค้างทั้งหมด" และรายการ "ต้องตาม"
  3. แตะใบแจ้งหนี้เพื่อบันทึกวางบิล รับเงินจริง หรือการติดตาม
  4. งานที่ยังไม่วางบิล แตะ "สร้างร่างใบแจ้งหนี้"
มือถือ

รายงาน

ตัวชี้วัดของสำนักงาน (หรือเฉพาะคดีของคุณ ถ้าไม่ใช่เจ้าของ): อัตราเก็บเงิน หนี้ค้าง ผลคดี ระยะเวลาเฉลี่ย

  1. เปิดจาก อื่น ๆ → รายงาน
  2. แตะ "การเงินสำนักงาน" เพื่อไปหน้าลูกหนี้
มือถือ

งานพักไว้

งานที่พักไว้เพราะรอลูกความ ศาล หรือเอกสาร เรียงตามวันติดตาม (ปลดพักงานทำบนเว็บ)

  1. เปิดจาก อื่น ๆ → งานพักไว้
  2. แตะงานเพื่อดูผู้รับผิดชอบและผู้ติดตาม

มือถือ

การแจ้งเตือน

งานที่ได้รับมอบหมาย นัดที่เปลี่ยน และข้อความจากลูกความ แยก ล่าสุด กับ รอจัดการ

  1. แตะกระดิ่งบนหน้า วันนี้
  2. แท็บ "รอจัดการ" คือเรื่องที่ยังต้องทำ
  3. แตะรายการเพื่อเปิดเรื่องนั้น
  4. แตะไอคอนปรับค่าเพื่อเลือกช่องทางแจ้งเตือน
มือถือ

ตั้งค่า

เลือกว่าเรื่องไหนให้เด้งในแอปหรือส่ง LINE และปรับขนาดตัวอักษรทั้งแอป

  1. เปิด/ปิด "แอป" และ "LINE" ของแต่ละหมวด (งาน คดี นัดหมาย ลูกความ …)
  2. เลือกขนาดตัวอักษร ปกติ / ใหญ่ / ใหญ่มาก / ใหญ่พิเศษ
  3. ถ้าขึ้น "ยังไม่เชื่อม LINE" ให้เชื่อมผ่าน LINE OA ของสำนักงานก่อน
มือถือ

บัญชีของฉัน

แก้ชื่อที่แสดงในทีมและเปลี่ยนรหัสผ่าน

  1. แก้ "ชื่อ" / "นามสกุล" แล้วแตะ "บันทึกชื่อของฉัน"
  2. แตะ "เปลี่ยนรหัสผ่าน" กรอกรหัสปัจจุบันและรหัสใหม่ (อย่างน้อย 8 ตัวอักษร)
  3. หลังเปลี่ยนรหัส ต้องเข้าสู่ระบบใหม่
  4. "ลบบัญชีและข้อมูลส่วนตัว" เป็นการส่งคำขอให้สำนักงานตรวจก่อน ไม่ลบทันที

LINE Official Account

นอกจากเปิดเว็บ พนักงานยังสั่งงานผ่านแชท LINE OA ของสำนักงานได้เลย — สร้างคดี เพิ่มงาน บันทึกค่าใช้จ่าย หรือดูงานวันนี้ โดยพิมพ์คำสั่งหรือแตะปุ่มในแชท ไม่ต้องเปิดแอปเว็บก็ได้ ระบบยังส่งแจ้งเตือนนัดหมายล่วงหน้า 3 วันก่อนถึงวันนัดให้ทาง LINE โดยอัตโนมัติหลังเชื่อมต่อบัญชีแล้ว

ขั้นตอนที่ 1 — เพิ่มเพื่อนและเชื่อมต่อบัญชี LINE (ทำครั้งเดียว)

ก่อนสั่งงานผ่านแชทได้ ต้องมี LINE Official Account ของสำนักงานก่อน (แอดมินตั้งค่า Channel ID/Secret ที่หน้า ตั้งค่า → การเชื่อมต่อ → LINE Messaging API — ถ้าเห็นข้อความ "ระบบ LINE ยังไม่ได้ตั้งค่า" แปลว่ายังไม่มีใครตั้งค่าส่วนนี้ ต้องให้แอดมินไปสร้าง Channel ใน LINE Developers Console ก่อน แล้วกรอก Channel ID/Secret/Access Token)

  1. เข้าเว็บแอป ไปที่หน้า ตั้งค่า (/settings) → หัวข้อ การเชื่อมต่อ → กดปุ่ม "เชื่อมต่อ LINE" ใต้หัวข้อ "เชื่อมต่อ LINE ส่วนตัว" (ดูสไลด์ 23 — ตั้งค่า)
  2. หน้าจะแสดง "1. เพิ่มเพื่อน Official Account [ที่นี่]" — กดลิงก์นี้เพื่อเปิด LINE แล้วกด Add friend เพิ่มบัญชีสำนักงานเป็นเพื่อน (ถ้าเพิ่มเพื่อนไว้แล้วข้ามขั้นนี้ได้เลย)
  3. กลับมาที่เว็บ จะเห็น "2. ส่งรหัสด้านล่างในแชท LINE" พร้อมรหัสรูปแบบ LF-XXXXXX (กด "คัดลอก" ได้) — รหัสมีอายุ 15 นาที ถ้าหมดอายุกด "สร้างรหัสใหม่"
  4. เปิดแชท LINE Official Account ที่เพิ่งเพิ่มเพื่อน แล้วพิมพ์/วางรหัสนั้นส่งเข้าไปในแชท
  5. บอทตอบ "✅ เชื่อมต่อสำเร็จ! สวัสดีคุณ …คุณจะได้รับแจ้งเตือนนัดหมายล่วงหน้า 3 วันก่อนถึงวันนัด" — เสร็จแล้ว ใช้งานได้ทันที

เมนูหลัก

ทักบอทด้วยคำว่า "เมนู" เมื่อไหร่ก็ได้เพื่อกลับมาที่เมนูรูปภาพด้านบน (3 ปุ่มที่เห็นในรูป: สร้าง Case / เพิ่ม Task / สร้าง Todo) และมีปุ่มลัดเพิ่มเติมใต้เมนูอีก 3 ปุ่ม: 💸 ค่าใช้จ่าย, 💰 เบิกล่วงหน้า, 📊 งานวันนี้

ระหว่างทำรายการค้างอยู่ พิมพ์ "เมนู" เพื่อกลับหน้าแรก หรือ "ยกเลิก" เพื่อเลิกทำรายการนั้นได้ทุกเมื่อ

📋 สร้าง Case

พิมพ์ "สร้าง Case" หรือแตะปุ่มบนเมนูรูปภาพ

  1. บอทถาม "ชื่อเรื่อง/หัวข้อคดีคืออะไรครับ?" — พิมพ์หัวข้อคดี
  2. "ลูกความชื่ออะไรครับ? (พิมพ์ชื่อเพื่อค้นหา)" — พิมพ์ชื่อ บอทจะค้นในรายชื่อลูกค้าที่มีอยู่ให้เลือก หรือกด "ไม่เจอ" เพื่อใช้ชื่อที่พิมพ์ไปตรง ๆ
  3. "มีผู้รับผิดชอบร่วมไหมครับ? (เลือกได้หลายคน)" — เลือกทนาย/ผู้ช่วยที่ดูแลร่วม แล้วกด "พอแล้ว"
  4. "มีรายละเอียดเพิ่มเติมไหมครับ?" — พิมพ์รายละเอียดหรือกด "ไม่ระบุ"
  5. บอทสรุปข้อมูลทั้งหมดให้ตรวจ กด "ยืนยัน" เพื่อสร้างคดี หรือกดหัวข้อที่ต้องการแก้ก่อน

✅ เพิ่ม Task

พิมพ์ "เพิ่ม Task" หรือแตะปุ่มบนเมนูรูปภาพ

  1. "ชื่องานที่จะมอบหมายคืออะไรครับ?" — พิมพ์ชื่องาน
  2. บอทให้ "เลือกคดีครับ" — พิมพ์ชื่อ/เลขคดีเพื่อค้นหา หรือกด "นอกคดี" ถ้าเป็นงานที่ไม่ผูกกับคดีไหน
  3. "กำหนดส่ง" — เลือกวันครบกำหนด
  4. "มอบหมายให้ใครครับ?" — เลือกผู้รับผิดชอบ
  5. ตรวจสรุปแล้วกด "ยืนยัน" — งานจะไปโผล่ในหน้า งานที่ต้องทำ/รายละเอียดคดี ทันที

📝 สร้าง Todo

พิมพ์ "สร้าง Todo" หรือแตะปุ่มบนเมนูรูปภาพ

  1. "สร้าง Todo ใหม่ — ชื่องานคืออะไรครับ?" — พิมพ์ชื่องานส่วนตัว (ไม่ผูกกับคดี)
  2. "กำหนดส่ง" — เลือกวันครบกำหนด (ข้ามได้)
  3. "มอบหมายให้ใครครับ?" — ปกติจะเป็นตัวเอง หรือมอบให้คนอื่นได้
  4. กด "ยืนยัน" — ไปโผล่ในหน้า งานส่วนตัว (/todos) ของผู้รับ

💸 บันทึกค่าใช้จ่าย

พิมพ์ "บันทึกค่าใช้จ่าย" หรือแตะชิป "💸 ค่าใช้จ่าย" ใต้เมนู

  1. "จะกรอกเองหรือให้ AI อ่านจากรูปใบเสร็จครับ?" — เลือก "AI อ่านจากรูป" แล้วส่งรูปใบเสร็จ หรือเลือก "กรอกเอง"
  2. ถ้าส่งรูป AI จะอ่านยอดเงินให้อัตโนมัติ ถ้าอ่านไม่ได้บอทจะถามยอดเงินเอง
  3. "ค่าอะไรครับ? (เช่น ค่าส่งเอกสาร)" — พิมพ์รายละเอียดค่าใช้จ่าย
  4. "ผูกกับคดีไหนครับ?" — พิมพ์ชื่อคดีเพื่อค้นหา หรือกด "ข้าม" ถ้าเป็นค่าใช้จ่ายทั่วไปของสำนักงาน
  5. กด "ยืนยัน" — รายการจะเข้าไปเป็นสถานะร่างในหน้า ค่าใช้จ่าย (/expenses) รอส่งขออนุมัติ
