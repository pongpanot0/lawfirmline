LINE

ใช้งานผ่าน LINE — คุยกับบอทของสำนักงานแทนเปิดเว็บ

LINE Official Account

นอกจากเปิดเว็บ พนักงานยังสั่งงานผ่านแชท LINE OA ของสำนักงานได้เลย — สร้างคดี เพิ่มงาน บันทึกค่าใช้จ่าย หรือดูงานวันนี้ โดยพิมพ์คำสั่งหรือแตะปุ่มในแชท ไม่ต้องเปิดแอปเว็บก็ได้ ระบบยังส่งแจ้งเตือนนัดหมายล่วงหน้า 3 วันก่อนถึงวันนัดให้ทาง LINE โดยอัตโนมัติหลังเชื่อมต่อบัญชีแล้ว

ขั้นตอนที่ 1 — เพิ่มเพื่อนและเชื่อมต่อบัญชี LINE (ทำครั้งเดียว)

ก่อนสั่งงานผ่านแชทได้ ต้องมี LINE Official Account ของสำนักงานก่อน (แอดมินตั้งค่า Channel ID/Secret ที่หน้า ตั้งค่า → การเชื่อมต่อ → LINE Messaging API — ถ้าเห็นข้อความ "ระบบ LINE ยังไม่ได้ตั้งค่า" แปลว่ายังไม่มีใครตั้งค่าส่วนนี้ ต้องให้แอดมินไปสร้าง Channel ใน LINE Developers Console ก่อน แล้วกรอก Channel ID/Secret/Access Token)

  1. เข้าเว็บแอป ไปที่หน้า ตั้งค่า (/settings) → หัวข้อ การเชื่อมต่อ → กดปุ่ม "เชื่อมต่อ LINE" ใต้หัวข้อ "เชื่อมต่อ LINE ส่วนตัว" (ดูสไลด์ 23 — ตั้งค่า)
  2. หน้าจะแสดง "1. เพิ่มเพื่อน Official Account [ที่นี่]" — กดลิงก์นี้เพื่อเปิด LINE แล้วกด Add friend เพิ่มบัญชีสำนักงานเป็นเพื่อน (ถ้าเพิ่มเพื่อนไว้แล้วข้ามขั้นนี้ได้เลย)
  3. กลับมาที่เว็บ จะเห็น "2. ส่งรหัสด้านล่างในแชท LINE" พร้อมรหัสรูปแบบ LF-XXXXXX (กด "คัดลอก" ได้) — รหัสมีอายุ 15 นาที ถ้าหมดอายุกด "สร้างรหัสใหม่"
  4. เปิดแชท LINE Official Account ที่เพิ่งเพิ่มเพื่อน แล้วพิมพ์/วางรหัสนั้นส่งเข้าไปในแชท
  5. บอทตอบ "✅ เชื่อมต่อสำเร็จ! สวัสดีคุณ …คุณจะได้รับแจ้งเตือนนัดหมายล่วงหน้า 3 วันก่อนถึงวันนัด" — เสร็จแล้ว ใช้งานได้ทันที

เมนูหลัก

ทักบอทด้วยคำว่า "เมนู" เมื่อไหร่ก็ได้เพื่อกลับมาที่เมนูรูปภาพด้านบน (3 ปุ่มที่เห็นในรูป: สร้าง Case / เพิ่ม Task / สร้าง Todo) และมีปุ่มลัดเพิ่มเติมใต้เมนูอีก 3 ปุ่ม: 💸 ค่าใช้จ่าย, 💰 เบิกล่วงหน้า, 📊 งานวันนี้

ระหว่างทำรายการค้างอยู่ พิมพ์ "เมนู" เพื่อกลับหน้าแรก หรือ "ยกเลิก" เพื่อเลิกทำรายการนั้นได้ทุกเมื่อ

ขั้นตอนที่ 2 — ใช้แต่ละคำสั่ง

📋 สร้าง Case

พิมพ์ "สร้าง Case" หรือแตะปุ่มบนเมนูรูปภาพ

  1. บอทถาม "ชื่อเรื่อง/หัวข้อคดีคืออะไรครับ?" — พิมพ์หัวข้อคดี
  2. "ลูกความชื่ออะไรครับ? (พิมพ์ชื่อเพื่อค้นหา)" — พิมพ์ชื่อ บอทจะค้นในรายชื่อลูกค้าที่มีอยู่ให้เลือก หรือกด "ไม่เจอ" เพื่อใช้ชื่อที่พิมพ์ไปตรง ๆ
  3. "มีผู้รับผิดชอบร่วมไหมครับ? (เลือกได้หลายคน)" — เลือกทนาย/ผู้ช่วยที่ดูแลร่วม แล้วกด "พอแล้ว"
  4. "มีรายละเอียดเพิ่มเติมไหมครับ?" — พิมพ์รายละเอียดหรือกด "ไม่ระบุ"
  5. บอทสรุปข้อมูลทั้งหมดให้ตรวจ กด "ยืนยัน" เพื่อสร้างคดี หรือกดหัวข้อที่ต้องการแก้ก่อน

✅ เพิ่ม Task

พิมพ์ "เพิ่ม Task" หรือแตะปุ่มบนเมนูรูปภาพ

  1. "ชื่องานที่จะมอบหมายคืออะไรครับ?" — พิมพ์ชื่องาน
  2. บอทให้ "เลือกคดีครับ" — พิมพ์ชื่อ/เลขคดีเพื่อค้นหา หรือกด "นอกคดี" ถ้าเป็นงานที่ไม่ผูกกับคดีไหน
  3. "กำหนดส่ง" — เลือกวันครบกำหนด
  4. "มอบหมายให้ใครครับ?" — เลือกผู้รับผิดชอบ
  5. ตรวจสรุปแล้วกด "ยืนยัน" — งานจะไปโผล่ในหน้า งานที่ต้องทำ/รายละเอียดคดี ทันที

📝 สร้าง Todo

พิมพ์ "สร้าง Todo" หรือแตะปุ่มบนเมนูรูปภาพ

  1. "สร้าง Todo ใหม่ — ชื่องานคืออะไรครับ?" — พิมพ์ชื่องานส่วนตัว (ไม่ผูกกับคดี)
  2. "กำหนดส่ง" — เลือกวันครบกำหนด (ข้ามได้)
  3. "มอบหมายให้ใครครับ?" — ปกติจะเป็นตัวเอง หรือมอบให้คนอื่นได้
  4. กด "ยืนยัน" — ไปโผล่ในหน้า งานส่วนตัว (/todos) ของผู้รับ

💸 บันทึกค่าใช้จ่าย

พิมพ์ "บันทึกค่าใช้จ่าย" หรือแตะชิป "💸 ค่าใช้จ่าย" ใต้เมนู

  1. "จะกรอกเองหรือให้ AI อ่านจากรูปใบเสร็จครับ?" — เลือก "AI อ่านจากรูป" แล้วส่งรูปใบเสร็จ หรือเลือก "กรอกเอง"
  2. ถ้าส่งรูป AI จะอ่านยอดเงินให้อัตโนมัติ ถ้าอ่านไม่ได้บอทจะถามยอดเงินเอง
  3. "ค่าอะไรครับ? (เช่น ค่าส่งเอกสาร)" — พิมพ์รายละเอียดค่าใช้จ่าย
  4. "ผูกกับคดีไหนครับ?" — พิมพ์ชื่อคดีเพื่อค้นหา หรือกด "ข้าม" ถ้าเป็นค่าใช้จ่ายทั่วไปของสำนักงาน
  5. กด "ยืนยัน" — รายการจะเข้าไปเป็นสถานะร่างในหน้า ค่าใช้จ่าย (/expenses) รอส่งขออนุมัติ

💰 เบิกล่วงหน้า

พิมพ์ "เบิกล่วงหน้า" หรือแตะชิป "💰 เบิกล่วงหน้า" ใต้เมนู (เฉพาะเจ้าของสำนักงาน)

  1. "จ่ายเงินสำรองล่วงหน้าให้ใครครับ?" — เลือกสมาชิกในทีมที่จะรับเงินสำรอง
  2. "จำนวนเงินเท่าไหร่ครับ?" — พิมพ์จำนวนเงิน (ตัวเลขมากกว่า 0)
  3. "หมายเหตุครับ (หรือกด "ข้าม")" — ใส่เหตุผล/รายละเอียด
  4. กด "ยืนยัน" — ผู้รับจะได้ข้อความ LINE แจ้งทันทีว่า "💰 คุณได้รับเงินสำรองจ่าย…"

📊 งานของฉันวันนี้

พิมพ์ "งานของฉันวันนี้" ตรง ๆ หรือแตะชิป "📊 งานวันนี้" ใต้เมนู

  1. บอทตอบกลับสรุปนัดและงานที่ครบกำหนดวันนี้ทันที — เนื้อหาเดียวกับหน้า วันของฉัน (/my-day) บนเว็บ แต่ดูได้จากแชทโดยไม่ต้องเปิดแอป
