# Microsoft 365 — ส่วน C: ส่ง/ตอบอีเมลจากระบบ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A lawyer composes a new email or replies to a case email from inside the case, it goes out from **their own** Microsoft 365 mailbox (so it sits in their Outlook Sent Items), and it shows up in the case "อีเมล" tab right away.

**Architecture:** Five Graph primitives are added to `OutlookGraphClient` (create draft, create reply draft, patch draft, add file attachment, send). A new `OutlookSendService` builds one draft per send: a real Outlook reply (`createReply`/`createReplyAll`) when the source message lives in the sender's own connected mailbox, otherwise a brand-new message. It attaches case `Document`s as inline `fileAttachment`s (≤ 3 MB each), sends, then records the sent message through Phase 0's `OutlookSyncService.upsertGraphMessage({ direction: 'OUTBOUND', caseId, createThreadIfMissing: true })` and writes an `AuditLog` row. Later Sent Items sync skips it because `messageKey = internetMessageId` is the same. It is exposed as `GET/POST /cases/:caseId/outbound-email/*` behind `JwtAuthGuard + CaseAccessGuard`. On the web, `CaseEmailComposer.tsx` is a side drawer with a confirmation modal. Phase B's `CaseEmailPanel` and the `/email-intake/[threadId]` page open it.

**Tech Stack:** NestJS + Prisma (Postgres) in `apps/api`, Next.js in `apps/web`, Microsoft Graph v1.0 over `fetch` (no SDK), Jest for the API, `node --test` for web lib helpers.

**Spec:** `docs/superpowers/specs/2026-10-13-microsoft365-integration-design.md` (ส่วน C only)

**Depends on:** `docs/superpowers/plans/2026-10-13-m365-0-foundation-calendar-teams.md` (Phase 0: `GraphHttp`, `MailboxConnection.userId`, `EmailThread.caseId`/`mailboxConnectionId`, `EmailMessage.graphMessageId`/`toAddresses`/`ccAddresses`/`bodyHtml`, `OutlookConnectionsService.findActiveForUser`, public `OutlookSyncService.upsertGraphMessage`) and `docs/superpowers/plans/2026-10-13-m365-b-case-email.md` (Phase B: case "อีเมล" tab `apps/web/src/components/cases/CaseEmailPanel.tsx` with thread list + thread view, `caseId` on the web thread types). ## Global Constraints

- Scope is **ส่วน C only**. Do not change calendar, Teams, folder linking or OneDrive code.
- **No migration.** Phase C uses only Phase 0 columns and the existing `AuditLog` table. (Timestamp `20261013160000` is reserved for C. Leave it unused.)
- Send **only** from the current user's own connection: `OutlookConnectionsService.findActiveForUser(user.id)`. Never use another user's connection or token, including when replying to a message that arrived in a colleague's mailbox.
- Reply rule: if the source `EmailMessage.thread.mailboxConnectionId === <sender's active connection id>` **and** `graphMessageId` is set, use `POST /me/messages/{id}/createReply` (or `createReplyAll`) → `PATCH` body/recipients/subject → attachments → `POST /me/messages/{id}/send`. Otherwise (or when Graph answers 404 for the source) send a new message from the sender's mailbox, linked to the same case. The UI pre-fills `Re: {subject}` and the original sender. Comparing connection ids is stricter than comparing `connection.userId == user.id`. A user with two mailboxes cannot `createReply` on a message id from the other one.
- New-message Graph flow: `POST /me/messages` (returns `id`, `conversationId`, `internetMessageId`) → `POST /me/messages/{id}/attachments` per file → `POST /me/messages/{id}/send`. Every draft-creating call sends `Prefer: IdType="ImmutableId"`, so the id we store survives the move from Drafts to Sent Items.
- After a successful send, record with `OutlookSyncService.upsertGraphMessage({ firmId, connectionId, accessToken, message, direction: 'OUTBOUND', caseId, createThreadIfMissing: true })`. Then write `AuditLog { action: 'CASE_EMAIL_SENT', metadata: { caseId, threadId, mode, from, to, cc, subject, documentIds, replyToMessageId, clientRequestId } }` with `prisma.auditLog.create`. That is the house pattern; `AuditLogService` only lists. Once Microsoft has accepted the send, failures in either step are logged and **never** turned into an error response.
- Validation (API DTO **and** web): every address is a valid email; at least 1 `to`; `to + cc` ≤ **50** after case-insensitive de-duplication; `subject` and `body` non-blank after trim; `subject` ≤ 255 chars; ≤ 10 attachments; each attachment ≤ **3 MB** (`3 * 1024 * 1024` bytes); attachments ≤ 15 MB in total (base64 adds ~33% and Exchange caps a message at ~35 MB). An oversized file is rejected **before any Graph call** with: `ไฟล์ "{filename}" ใหญ่เกิน 3 MB แนบตรงไม่ได้ — ใช้ลิงก์ OneDrive แทน`.
- The body is typed as plain text and sent as HTML: `escapeHtml` (exported from `apps/api/src/notifications/email.service.ts`), with newlines turned into `<br>`. Never pass user HTML through.
- Case access: the controller uses `@UseGuards(JwtAuthGuard, CaseAccessGuard)` (the guard reads `params.caseId`). A reply source message must belong to a thread whose `caseId` equals the route `caseId`, otherwise 404. Attached documents must have `caseId` equal to the route `caseId`, otherwise 404.
- Double-send safety: the web disables the send button and sends a per-compose `clientRequestId` (uuid). The API refuses a key that is in flight in this process or already in `AuditLog`, with 409 `อีเมลนี้ส่งไปแล้ว`.
- No AI anywhere in this feature. No separate approval step: the confirmation dialog is the only gate.
- All UI text is Thai. API base path: `/cases/:caseId/outbound-email`. It is deliberately not `/cases/:caseId/emails`, so it cannot collide with Phase B's `GET /cases/:caseId/emails/:threadId`.
- API tests: `pnpm --filter api exec jest --config jest.config.js <paths>` (mock Prisma by hand, mock `global.fetch` for Graph, no real Microsoft calls). Web lib tests: `cd apps/web && node --test --experimental-strip-types <path> && cd ../..`. Typecheck: `pnpm --filter api exec tsc --noEmit -p tsconfig.json` and `pnpm --filter web exec tsc --noEmit`.
- Call git as `/usr/bin/git`. End every commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Microsoft sent the mail, but recording or the audit row then fails.** The API must still answer 200 `{ recorded: false }`, never a 500 that invites the lawyer to send again. Test: Task 2, "still reports success when recording the sent mail fails".
2. **Double-click, or a retry after a slow response, sends twice.** Test: Task 2, "refuses a clientRequestId that is already being sent" and "refuses a clientRequestId already in the audit log".
3. **Replying to a message from a colleague's mailbox, or one moved/deleted in Outlook (Graph 404).** It must fall back to a new message from the sender's own mailbox, never act on someone else's mailbox, and never fail outright. Test: Task 3, "colleague's mailbox → new message" and "Graph 404 on createReply → new message".
4. **A file over 3 MB, or a document id from another case.** It must be refused before any Graph call, so no orphan draft lands in Outlook, and the message must point to OneDrive. Test: Task 2, "rejects a document over 3 MB before touching Graph" and "rejects a document that is not in this case".
5. **A connection made before `Mail.Send` was granted (Graph 401/403).** The lawyer gets "connect Microsoft 365 again", not a generic failure. Test: Task 2, "asks to reconnect when Graph refuses with 403".

```ts
/** The writable subset of a Graph message that sending needs. */
export interface GraphOutgoingMessage {
  subject?: string;
  body?: { contentType: 'HTML' | 'Text'; content: string };
  toRecipients?: GraphRecipient[];
  ccRecipients?: GraphRecipient[];
}

export interface GraphFileAttachmentInput {
  name: string;
  contentType: string;
  /** base64 — Graph accepts inline file attachments up to 3 MB. */
  contentBytes: string;
}

/**
 * Immutable ids survive the Drafts → Sent Items move, so the id stored on the
 * EmailMessage still works for a later createReply.
 */
const IMMUTABLE_ID_HEADERS = { Prefer: 'IdType="ImmutableId"' };
```

Add these methods inside `class OutlookGraphClient`. Phase 0 injected `GraphHttp` into this class, and the code below calls it `this.http`. If Phase 0 gave the field another name, use that name.

```ts
  /** New draft in the signed-in user's Drafts folder — the first step of every send. */
  createDraftMessage(accessToken: string, message: GraphOutgoingMessage): Promise<GraphMessage> {
    return this.http.request<GraphMessage>(accessToken, '/me/messages', {
      method: 'POST',
      headers: IMMUTABLE_ID_HEADERS,
      body: JSON.stringify(message),
    });
  }

  /** Reply draft that stays in the original Outlook conversation (quoted history included by Graph). */
  createReplyDraft(accessToken: string, messageId: string, replyAll: boolean): Promise<GraphMessage> {
    const action = replyAll ? 'createReplyAll' : 'createReply';
    return this.http.request<GraphMessage>(accessToken, `/me/messages/${encodeURIComponent(messageId)}/${action}`, {
      method: 'POST',
      headers: IMMUTABLE_ID_HEADERS,
      body: '{}',
    });
  }

  updateDraft(accessToken: string, messageId: string, patch: GraphOutgoingMessage): Promise<GraphMessage> {
    return this.http.request<GraphMessage>(accessToken, `/me/messages/${encodeURIComponent(messageId)}`, {
      method: 'PATCH',
      headers: IMMUTABLE_ID_HEADERS,
      body: JSON.stringify(patch),
    });
  }

  async addFileAttachment(accessToken: string, messageId: string, file: GraphFileAttachmentInput): Promise<void> {
    await this.http.request(accessToken, `/me/messages/${encodeURIComponent(messageId)}/attachments`, {
      method: 'POST',
      body: JSON.stringify({ '@odata.type': '#microsoft.graph.fileAttachment', ...file }),
    });
  }

  /** Graph answers 202 with no body; the message moves to Sent Items. */
  async sendDraft(accessToken: string, messageId: string): Promise<void> {
    await this.http.request(accessToken, `/me/messages/${encodeURIComponent(messageId)}/send`, { method: 'POST' });
  }
```

```ts
import { BadRequestException, ConflictException, Injectable, Logger, NotFoundException } from '@nestjs/common';
import { AuthUser } from '@lawfirm/shared';
import { PrismaService } from '../prisma/prisma.module';
import { FileStorageService } from '../common/services/file-storage.service';
import { escapeHtml } from '../notifications/email.service';
import {
  GraphApiError,
  GraphFileAttachmentInput,
  GraphMessage,
  GraphRecipient,
  OutlookGraphClient,
} from './outlook-graph.client';
import { OutlookConnectionsService } from './outlook-connections.service';
import { OutlookSyncService } from './outlook-sync.service';
import { SendCaseEmailDto } from './dto/send-case-email.dto';

export const MAX_RECIPIENTS = 50;
export const MAX_ATTACHMENT_BYTES = 3 * 1024 * 1024;
/** base64 inflates ~33% and Exchange caps a message near 35 MB. */
export const MAX_TOTAL_ATTACHMENT_BYTES = 15 * 1024 * 1024;
export const CASE_EMAIL_SENT = 'CASE_EMAIL_SENT';

export type SendMode = 'NEW' | 'REPLY' | 'REPLY_AS_NEW';

export interface SendCaseEmailResult {
  mode: SendMode;
  threadId: string | null;
  /** false = Microsoft sent it, but writing it into the case's email tab failed. */
  recorded: boolean;
}

export interface RecipientOption {
  name: string;
  email: string;
  source: 'CLIENT_CONTACT' | 'PARTICIPANT';
  group: string;
}

type ClientWithContacts = { name: string; contacts: { name: string; email: string | null }[] } | null;

export interface RecipientSourceCase {
  client: ClientWithContacts;
  additionalClients: { client: ClientWithContacts }[];
  customers: { customer: ClientWithContacts }[];
  participants: { name: string; email: string | null }[];
}

/** Everyone in the case with an email address, client contacts first, one entry per address. */
export function buildRecipientOptions(c: RecipientSourceCase): RecipientOption[] {
  const byEmail = new Map<string, RecipientOption>();
  const add = (name: string, email: string | null, source: RecipientOption['source'], group: string) => {
    const address = email?.trim();
    if (!address || byEmail.has(address.toLowerCase())) return;
    byEmail.set(address.toLowerCase(), { name, email: address, source, group });
  };
  const clients = [c.client, ...c.additionalClients.map((x) => x.client), ...c.customers.map((x) => x.customer)];
  for (const client of clients) {
    for (const contact of client?.contacts ?? []) add(contact.name, contact.email, 'CLIENT_CONTACT', client!.name);
  }
  for (const participant of c.participants) add(participant.name, participant.email, 'PARTICIPANT', 'คู่ความ');
  return [...byEmail.values()];
}

function uniqueAddresses(list: string[]): string[] {
  const seen = new Set<string>();
  return list
    .map((address) => address.trim())
    .filter((address) => {
      const key = address.toLowerCase();
      if (!address || seen.has(key)) return false;
      seen.add(key);
      return true;
    });
}

const recipients = (addresses: string[]): GraphRecipient[] => addresses.map((address) => ({ emailAddress: { address } }));
const textToHtml = (text: string) => `<div>${escapeHtml(text).replace(/\r?\n/g, '<br>')}</div>`;

interface OutgoingMail {
  to: string[];
  cc: string[];
  subject: string;
  html: string;
}

interface LoadedAttachment {
  documentId: string;
  file: GraphFileAttachmentInput;
}

/**
 * Sends case email from the signed-in user's OWN Microsoft mailbox — never a
 * colleague's — and files the sent message under the case right away
 * (Sent Items sync later dedups on internetMessageId).
 */
@Injectable()
export class OutlookSendService {
  private readonly logger = new Logger(OutlookSendService.name);
  // ponytail: per-process guard for a double-click racing the audit-log check; a second API instance would need a DB unique key.
  private readonly inFlight = new Set<string>();

  constructor(
    private prisma: PrismaService,
    private connections: OutlookConnectionsService,
    private graph: OutlookGraphClient,
    private sync: OutlookSyncService,
    private fileStorage: FileStorageService,
  ) {}

  async composeOptions(user: AuthUser, caseId: string) {
    const contacts = { select: { name: true, email: true } } as const;
    const clientSelect = { select: { name: true, contacts } } as const;
    const [connection, legalCase] = await Promise.all([
      this.connections.findActiveForUser(user.id),
      this.prisma.case.findFirst({
        where: { id: caseId, firmId: user.firmId },
        select: {
          ownRef: true,
          client: clientSelect,
          additionalClients: { select: { client: clientSelect } },
          customers: { select: { customer: clientSelect } },
          participants: { select: { name: true, email: true } },
        },
      }),
    ]);
    if (!legalCase) throw new NotFoundException('ไม่พบคดีนี้');
    return {
      mailboxAddress: connection?.mailboxAddress ?? null,
      ownRef: legalCase.ownRef,
      recipients: buildRecipientOptions(legalCase),
    };
  }

  async send(user: AuthUser, caseId: string, dto: SendCaseEmailDto): Promise<SendCaseEmailResult> {
    const key = dto.clientRequestId ? `${user.id}:${dto.clientRequestId}` : null;
    if (key) {
      if (this.inFlight.has(key)) throw new ConflictException('อีเมลนี้ส่งไปแล้ว');
      this.inFlight.add(key);
    }
    try {
      if (dto.clientRequestId && (await this.alreadySent(user, dto.clientRequestId))) {
        throw new ConflictException('อีเมลนี้ส่งไปแล้ว');
      }
      return await this.sendOnce(user, caseId, dto);
    } finally {
      if (key) this.inFlight.delete(key);
    }
  }

  private async alreadySent(user: AuthUser, clientRequestId: string): Promise<boolean> {
    const row = await this.prisma.auditLog.findFirst({
      where: {
        firmId: user.firmId,
        userId: user.id,
        action: CASE_EMAIL_SENT,
        metadata: { path: ['clientRequestId'], equals: clientRequestId },
      },
      select: { id: true },
    });
    return !!row;
  }

  private async sendOnce(user: AuthUser, caseId: string, dto: SendCaseEmailDto): Promise<SendCaseEmailResult> {
    const to = uniqueAddresses(dto.to);
    const cc = uniqueAddresses(dto.cc ?? []).filter((address) => !to.some((t) => t.toLowerCase() === address.toLowerCase()));
    const subject = dto.subject.trim();
    const body = dto.body.trim();
    if (to.length === 0) throw new BadRequestException('ต้องมีผู้รับอย่างน้อย 1 คน');
    if (to.length + cc.length > MAX_RECIPIENTS) {
      throw new BadRequestException(`ผู้รับรวม (ถึง + สำเนา) ได้ไม่เกิน ${MAX_RECIPIENTS} คน`);
    }
    if (!subject || !body) throw new BadRequestException('กรุณาใส่หัวเรื่องและเนื้อหา');

    const connection = await this.connections.findActiveForUser(user.id);
    if (!connection) {
      throw new BadRequestException('ยังไม่ได้เชื่อมต่อ Microsoft 365 — เชื่อมต่อในหน้าตั้งค่าก่อนส่งอีเมล');
    }

    // Load and size-check every file BEFORE any Graph call, so a refused file never leaves a half-built draft in Outlook.
    const attachments = await this.loadAttachments(caseId, dto.documentIds ?? []);
    const accessToken = await this.connections.getValidAccessToken(connection.id);
    const mail: OutgoingMail = { to, cc, subject, html: textToHtml(body) };

    let draft: GraphMessage;
    let mode: SendMode;
    try {
      ({ draft, mode } = await this.createDraft(accessToken, mail));
      for (const { file } of attachments) {
        await this.graph.addFileAttachment(accessToken, draft.id, file);
      }
      await this.graph.sendDraft(accessToken, draft.id);
    } catch (error) {
      this.logger.warn(`Case ${caseId}: sending email via connection ${connection.id} failed: ${error}`);
      if (error instanceof GraphApiError && (error.status === 401 || error.status === 403)) {
        throw new BadRequestException('Microsoft ไม่อนุญาตให้ส่งอีเมลจากบัญชีนี้ — กรุณาเชื่อมต่อ Microsoft 365 ใหม่ในหน้าตั้งค่า');
      }
      throw new BadRequestException('ส่งอีเมลไม่สำเร็จ — ถ้ามีร่างค้างในโฟลเดอร์ Drafts ของ Outlook ลบหรือส่งจาก Outlook ได้');
    }

    // Microsoft has the mail now. Nothing below may turn this into an error — a 500 here invites a second send.
    let threadId: string | null = null;
    try {
      const recorded = await this.sync.upsertGraphMessage({
        firmId: user.firmId,
        connectionId: connection.id,
        accessToken,
        message: {
          ...draft,
          from: { emailAddress: { name: `${user.firstName} ${user.lastName}`.trim(), address: connection.mailboxAddress } },
          toRecipients: recipients(to),
          ccRecipients: recipients(cc),
          body: draft.body ?? { contentType: 'html', content: mail.html },
          receivedDateTime: new Date().toISOString(),
          // ponytail: outbound attachments are case Documents already — not stored a second time as EmailAttachment.
          hasAttachments: false,
        },
        direction: 'OUTBOUND',
        caseId,
        createThreadIfMissing: true,
      });
      threadId = recorded?.threadId ?? null;
    } catch (error) {
      this.logger.error(`Case ${caseId}: email ${draft.internetMessageId} was sent but recording it failed: ${error}`);
    }

    try {
      await this.prisma.auditLog.create({
        data: {
          firmId: user.firmId,
          userId: user.id,
          action: CASE_EMAIL_SENT,
          metadata: {
            caseId,
            threadId,
            mode,
            from: connection.mailboxAddress,
            to,
            cc,
            subject,
            documentIds: attachments.map((a) => a.documentId),
            replyToMessageId: dto.replyToMessageId ?? null,
            clientRequestId: dto.clientRequestId ?? null,
          },
        },
      });
    } catch (error) {
      this.logger.error(`Case ${caseId}: email sent but audit log write failed: ${error}`);
    }

    return { mode, threadId, recorded: threadId !== null };
  }

  private async createDraft(accessToken: string, mail: OutgoingMail): Promise<{ draft: GraphMessage; mode: SendMode }> {
    const draft = await this.graph.createDraftMessage(accessToken, {
      subject: mail.subject,
      body: { contentType: 'HTML', content: mail.html },
      toRecipients: recipients(mail.to),
      ccRecipients: recipients(mail.cc),
    });
    return { draft, mode: 'NEW' };
  }

  private async loadAttachments(caseId: string, documentIds: string[]): Promise<LoadedAttachment[]> {
    const ids = [...new Set(documentIds)];
    if (ids.length === 0) return [];
```

```ts
    connectionId: string,
    source: ReplySource | null,
    replyAll: boolean,

      try {
        const reply = await this.graph.createReplyDraft(accessToken, source.graphMessageId, replyAll);
        const draft = await this.graph.updateDraft(accessToken, reply.id, {

          body: { contentType: 'HTML', content: prependToHtml(reply.body?.content, mail.html) },
          toRecipients: recipients(mail.to),
          ccRecipients: recipients(mail.cc),
        });
        return { draft, mode: 'REPLY' };
      } catch (error) {
        if (!(error instanceof GraphApiError && error.status === 404)) throw error;
        this.logger.warn(`Reply source ${source.id} is gone from the mailbox — sending as a new message`);
      }
    }

    const draft = await this.graph.createDraftMessage(accessToken, {

      body: { contentType: 'HTML', content: mail.html },
      toRecipients: recipients(mail.to),
      ccRecipients: recipients(mail.cc),
    });
```

```ts
export const MAX_EMAIL_RECIPIENTS = 50;

const EMAIL_PATTERN = /^[^\s@<>(),;:"[\]]+@[^\s@<>(),;:"[\]]+\.[^\s@<>(),;:"[\]]+$/;

export interface ReplySourceMessage {
  id: string;
  fromAddress: string | null;
  toAddresses?: string[];
  ccAddresses?: string[];
}

export function parseAddressList(text: string): string[] {
  const seen = new Set<string>();
  const out: string[] = [];
  for (const raw of text.split(/[\s,;]+/)) {
    const address = raw.trim().replace(/^<|>$/g, '');
    const key = address.toLowerCase();
    if (!address || seen.has(key)) continue;
    seen.add(key);
    out.push(address);
  }
  return out;
}

export function appendAddress(text: string, email: string): string {
  if (parseAddressList(text).some((a) => a.toLowerCase() === email.toLowerCase())) return text;
  return [text.trim(), email].filter(Boolean).join(', ');
}

/** First problem as a Thai sentence, or null when the email may be sent. Mirrors the API's SendCaseEmailDto rules. */
export function composeError(input: { to: string[]; cc: string[]; subject: string; body: string }): string | null {
  if (input.to.length === 0) return 'กรุณาใส่ผู้รับอย่างน้อย 1 คน';
  const invalid = [...input.to, ...input.cc].filter((a) => !EMAIL_PATTERN.test(a));
  if (invalid.length) return `อีเมลไม่ถูกต้อง: ${invalid.join(', ')}`;
  if (input.to.length + input.cc.length > MAX_EMAIL_RECIPIENTS) {
    return `ผู้รับรวม (ถึง + สำเนา) ได้ไม่เกิน ${MAX_EMAIL_RECIPIENTS} คน`;
  }
  if (!input.subject.trim()) return 'กรุณาใส่หัวเรื่อง';
  if (!input.body.trim()) return 'กรุณาใส่เนื้อหา';
  return null;
}

export function newSubject(ownRef: string): string {
  return ownRef ? `[${ownRef}] ` : '';
}

export function replySubject(subject: string): string {
  const trimmed = subject.trim();
  return /^re:/i.test(trimmed) ? trimmed : `Re: ${trimmed}`;
}

export function replyRecipients(
  message: ReplySourceMessage,
  replyAll: boolean,
  ownAddress: string | null,
): { to: string[]; cc: string[] } {
  const own = (ownAddress ?? '').toLowerCase();
  const fromIsOwn = !!message.fromAddress && message.fromAddress.toLowerCase() === own;
  const to = fromIsOwn
    ? (message.toAddresses ?? []).filter((a) => a.toLowerCase() !== own)
    : message.fromAddress
      ? [message.fromAddress]
      : [];
  if (!replyAll) return { to, cc: [] };
  const taken = new Set(to.map((a) => a.toLowerCase()));
  const cc = [...(message.toAddresses ?? []), ...(message.ccAddresses ?? [])].filter((a) => {
    const key = a.toLowerCase();
    if (key === own || taken.has(key)) return false;
    taken.add(key);
    return true;
  });
  return { to, cc };
}
```

```tsx
'use client';

import { useEffect, useRef, useState } from 'react';
import { Paperclip } from 'lucide-react';

import { useAuth } from '@/lib/auth';
import { publishActionFeedback } from '@/lib/action-feedback';
import { api, type CaseEmailComposeOptions, type DocumentItem, type SendCaseEmailResult } from '@/lib/api';
import {
  appendAddress,
  composeError,
  newSubject,
  parseAddressList,
  replyRecipients,
  replySubject,
  type ReplySourceMessage,
} from '@/lib/case-email-compose';

export type CaseEmailComposerMode =
  | { kind: 'new' }
  | { kind: 'reply'; replyAll: boolean; threadSubject: string; message: ReplySourceMessage };

/**
 * เขียน/ตอบอีเมลจากกล่อง Microsoft 365 ของผู้ใช้เอง — เปิดจากแท็บอีเมลคดี และหน้า thread ที่ผูกคดีแล้ว

export function CaseEmailComposer({
  caseId,
  mode,
  onClose,
  onSent,
}: {
  caseId: string;
  mode: CaseEmailComposerMode | null;
  onClose: () => void;
  onSent?: (result: SendCaseEmailResult) => void;
}) {
  const { token } = useAuth();
  const [options, setOptions] = useState<CaseEmailComposeOptions | null>(null);
  const [documents, setDocuments] = useState<DocumentItem[]>([]);
  const [toText, setToText] = useState('');
  const [ccText, setCcText] = useState('');
  const [subject, setSubject] = useState('');
  const [body, setBody] = useState('');
  const [documentIds, setDocumentIds] = useState<string[]>([]);
  const [confirming, setConfirming] = useState(false);
  const [sending, setSending] = useState(false);
  const [error, setError] = useState('');
  const requestKey = useRef('');
  const inFlight = useRef(false);

  useEffect(() => {
    if (!mode || !token) return;
    let cancelled = false;
    setOptions(null);
    setError('');
    setBody('');
    setDocumentIds([]);
    setConfirming(false);
    requestKey.current = '';
    Promise.all([api.getCaseEmailComposeOptions(token, caseId), api.getDocuments(token, caseId)])
      .then(([loaded, docs]) => {
        if (cancelled) return;
        setOptions(loaded);
        setDocuments(docs);
        if (mode.kind === 'reply') {
          const prefill = replyRecipients(mode.message, mode.replyAll, loaded.mailboxAddress);
          setToText(prefill.to.join(', '));
          setCcText(prefill.cc.join(', '));
          setSubject(replySubject(mode.threadSubject));
        } else {
          setToText('');
          setCcText('');
          setSubject(newSubject(loaded.ownRef));
        }
      })
      .catch((err) => {
        if (!cancelled) setError(err instanceof Error ? err.message : 'โหลดข้อมูลไม่สำเร็จ');
      });
    return () => {
      cancelled = true;
    };
  }, [mode, token, caseId]);

  const to = parseAddressList(toText);
  const cc = parseAddressList(ccText);
  const attached = documents.filter((d) => documentIds.includes(d.id));

  const review = () => {
    const problem = composeError({ to, cc, subject, body });
    setError(problem ?? '');
    if (!problem) setConfirming(true);
  };

  const send = async () => {
    if (!token || !mode || inFlight.current) return;
    inFlight.current = true;
    setSending(true);
    setError('');
    if (!requestKey.current) requestKey.current = crypto.randomUUID();
    try {
      const result = await api.sendCaseEmail(token, caseId, {
        to,
        cc,
        subject: subject.trim(),
        body,
        documentIds,
        ...(mode.kind === 'reply' ? { replyToMessageId: mode.message.id, replyAll: mode.replyAll } : {}),
        clientRequestId: requestKey.current,
      });
      requestKey.current = '';
      publishActionFeedback(
        'success',
        result.recorded ? 'ส่งอีเมลแล้ว' : 'ส่งอีเมลแล้ว แต่บันทึกเข้าแท็บอีเมลไม่สำเร็จ — ดูได้ใน Sent Items ของ Outlook',
      );
      setConfirming(false);
      onSent?.(result);
      onClose();
    } catch (err) {
      setConfirming(false);
      setError(err instanceof Error ? err.message : 'ส่งอีเมลไม่สำเร็จ');
    } finally {
      inFlight.current = false;
      setSending(false);
    }
  };

  const connect = async () => {
    if (!token) return;
    const { url } = await api.getOutlookConnectUrl(token);
    window.location.assign(url);
  };

  const title = mode?.kind === 'reply' ? (mode.replyAll ? 'ตอบกลับทั้งหมด' : 'ตอบกลับ') : 'เขียนอีเมล';

  return (
    <SideDrawer open={!!mode} title={title} onClose={() => !sending && onClose()}>
      {!options && !error && <p className="text-sm text-muted-foreground">กำลังโหลด…</p>}
      {!options && error && <p role="alert" className="rounded-lg bg-destructive/10 p-3 text-sm text-destructive">{error}</p>}

      {options && !options.mailboxAddress && (
        <div className="space-y-3 rounded-lg border border-dashed p-4 text-sm">
          <p>ส่งอีเมลจากระบบได้เมื่อเชื่อมต่อกล่องจดหมาย Microsoft 365 ของคุณเองก่อน อีเมลจะออกจากชื่อคุณและอยู่ใน Sent Items ของ Outlook</p>
          <Button onClick={() => void connect()}>เชื่อมต่อ Microsoft 365</Button>
        </div>
      )}

      {options?.mailboxAddress && (
        <div className="space-y-4">
          <p className="text-xs text-muted-foreground">ส่งจาก: {options.mailboxAddress}</p>

          <label className="block space-y-1 text-sm">
            <span className="font-medium">ถึง</span>
            <Input value={toText} onChange={(e) => setToText(e.target.value)} placeholder="อีเมล คั่นด้วย , หรือ ;" />
          </label>
          <label className="block space-y-1 text-sm">
            <span className="font-medium">สำเนา (CC)</span>
            <Input value={ccText} onChange={(e) => setCcText(e.target.value)} placeholder="ไม่บังคับ" />
          </label>

          {options.recipients.length > 0 && (
            <div className="space-y-1">
              <p className="text-xs font-medium text-muted-foreground">ผู้ติดต่อในคดี</p>
              <ul className="max-h-40 space-y-1 overflow-y-auto text-sm">
                {options.recipients.map((r) => (
                  <li key={r.email} className="flex items-center justify-between gap-2">

                      {r.name} &lt;{r.email}&gt; <span className="text-xs text-muted-foreground">· {r.group}</span>

                      }
                    />
                    <Paperclip className="h-3 w-3 shrink-0" aria-hidden />

              </div>
            </fieldset>
          )}

          {error && <p role="alert" className="rounded-lg bg-destructive/10 p-3 text-sm text-destructive">{error}</p>}

          <div className="flex justify-end gap-2">
            <Button variant="outline" onClick={onClose} disabled={sending}>
              ยกเลิก
            </Button>
            <Button onClick={review} disabled={sending}>
              ตรวจทานก่อนส่ง
            </Button>
          </div>
        </div>
      )}

      <Modal
        open={confirming}
        onClose={() => !sending && setConfirming(false)}
        closeOnBackdrop={!sending}
        className="max-w-lg"
        ariaLabel="ยืนยันการส่งอีเมล"
      >
        <h2 className="text-lg font-semibold">ยืนยันการส่งอีเมล</h2>
        <dl className="mt-3 space-y-2 text-sm">
          <div>
            <dt className="text-muted-foreground">จาก</dt>
            <dd>{options?.mailboxAddress}</dd>
          </div>
          <div>
            <dt className="text-muted-foreground">ถึง ({to.length})</dt>
            <dd className="break-all">{to.join(', ')}</dd>
          </div>
          {cc.length > 0 && (
            <div>
              <dt className="text-muted-foreground">สำเนา ({cc.length})</dt>
              <dd className="break-all">{cc.join(', ')}</dd>

          <div>

  );
}
```
