# Microsoft 365 — ส่วน D: เอกสาร OneDrive/SharePoint ในคดี Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Link a OneDrive/SharePoint folder to a case, show its files live in the case documents tab (open in Office online / import as a case document), let a lawyer edit a system `.docx/.xlsx/.pptx` in Office online and pull the result back as a new version, and warn before a disconnect orphans those links.

**Architecture:** A new `GraphDriveClient` (on top of Phase 0's `GraphHttp`) wraps the few drive calls. `CaseDriveService` owns case ↔ folder links (`CaseExternalLink` kind `DRIVE_FOLDER`, from Phase B) and always reads the folder with the **linking user's** token, but only after the case-access guard passed and only for items whose parent is the linked folder. `DocumentOfficeService` keeps one `DocumentOfficeLink` per system document (upload → `webUrl`, pull → `DocumentsService.uploadNewVersion`). Both live in a new `CaseDriveModule` that imports `OutlookIntegrationModule` + `DocumentsModule`, so no module cycle is introduced. Web: a "OneDrive" section + folder picker in `CaseDocumentsPanel`, Office buttons per document, a disconnect warning in settings, and a OneDrive tab on Phase B's folder-matching page.

**Tech Stack:** NestJS + Prisma (Postgres) in `apps/api`, Next.js in `apps/web`, Microsoft Graph v1.0 (raw `fetch` via `GraphHttp`), Jest for API tests, `node --test` for web lib helpers.

**Spec:** `docs/superpowers/specs/2026-10-13-microsoft365-integration-design.md` — **ส่วน D only**.

**Depends on:** `docs/superpowers/plans/2026-10-13-m365-0-foundation-calendar-teams.md` and `docs/superpowers/plans/2026-10-13-m365-b-case-email.md` — both merged before Task 1.

## Review Focus

1. **An item id that is not in the linked folder** (any other file in the linker's OneDrive, or an id like `../me`) must be refused before anything is downloaded — the linker's token must never become a window into their whole drive. Test: Task 1 "rejects id … that could change the Graph path" + Task 2 "refuses an item outside the linked folder".
2. **Thai filename on "ดึงเวอร์ชันล่าสุดกลับ"** must stay Thai: `uploadNewVersion` runs `decodeUploadFilename` (latin1 → UTF-8), so a raw UTF-8 name would turn into ASCII garbage. Test: Task 3 "keeps a Thai filename".
3. **Edited in both places** (new system version uploaded *and* unpulled Word-online edits) must refuse to overwrite the online edits with a 409 and Thai guidance. Test: Task 3 "refuses to overwrite unpulled Office edits".
4. **Own Ref with `/` or `:`** (e.g. `2569/0012`) must create `Samnuan/2569_0012`, not a nested folder or a Graph 400. Test: Task 1 `ensureFolderPath` + `safeDriveName`.
5. **Linker disconnected / token refresh failed** must show `ผู้ผูก folder ตัดการเชื่อมต่อแล้ว` without a Graph call or a 500, and an Office link whose uploader disconnected must start a fresh copy as the caller. Test: Task 2 "reports DISCONNECTED" + Task 3 "starts a fresh copy when the uploader disconnected".

```ts
import { BadRequestException, Injectable } from '@nestjs/common';
import { GraphApiError, GraphHttp } from './graph-http';

export interface DriveItem {
  id: string;
  name: string;
  size?: number;
  webUrl: string;
  lastModifiedDateTime: string;
  file?: { mimeType?: string };
  folder?: { childCount?: number };
  parentReference?: { driveId?: string; id?: string; path?: string };
  lastModifiedBy?: { user?: { displayName?: string } };
  /** Set on "shared with me" entries: the real item, living in someone else's drive. */
  remoteItem?: DriveItem;
}

export interface GraphSite {
  id: string;
  displayName: string;
  webUrl: string;
}

export interface GraphDrive {
  id: string;
  name: string;
  driveType: string;
  webUrl: string;
}

/** Graph's simple PUT upload takes at most 4 MB; anything bigger needs an upload session. */
export const SMALL_UPLOAD_MAX_BYTES = 4 * 1024 * 1024;
/** Upload-session chunks must be multiples of 320 KiB (Graph rule); 10 × 320 KiB ≈ 3.1 MB per PUT. */
export const UPLOAD_CHUNK_BYTES = 10 * 320 * 1024;

const ITEM_SELECT = 'id,name,size,webUrl,lastModifiedDateTime,file,folder,parentReference,lastModifiedBy';
const GRAPH_ID = /^[A-Za-z0-9!_-]+$/;
const SITE_ID = /^[A-Za-z0-9.,-]+$/;

/** Ids come from the browser; Graph's own id alphabet only, so a value can never add or climb path segments. */
function graphId(id: string): string {
  if (!GRAPH_ID.test(id)) throw new BadRequestException('รหัส OneDrive ไม่ถูกต้อง');
  return id;
}

function driveBase(driveId: string): string {
  return driveId === 'me' ? '/me/drive' : `/drives/${graphId(driveId)}`;
}

function itemPath(driveId: string, itemId: string): string {
  return itemId === 'root' ? `${driveBase(driveId)}/root` : `${driveBase(driveId)}/items/${graphId(itemId)}`;
}

/** OneDrive rejects `" * : < > ? / \ |` and leading/trailing spaces or dots in a name. */
export function safeDriveName(name: string): string {
  const cleaned = name
    .replace(/["*:<>?/\\|]/g, '_')
    .replace(/^[\s.]+|[\s.]+$/g, '')
    .slice(0, 200);
  return cleaned || 'untitled';
}

/**
 * The OneDrive/SharePoint calls ส่วน D needs, on top of GraphHttp (auth header, 429/503 retry,
 * paging). Every call runs with a delegated token, so it sees exactly what that user sees.
 */
@Injectable()
export class GraphDriveClient {
  constructor(private readonly http: GraphHttp) {}

  async listChildren(token: string, driveId: string, itemId: string): Promise<DriveItem[]> {
    return this.http.paginate<DriveItem>(token, `${itemPath(driveId, itemId)}/children?$top=200&$select=${ITEM_SELECT}`);
  }

  async getItem(token: string, driveId: string, itemId: string): Promise<DriveItem> {
    return this.http.request<DriveItem>(token, `${itemPath(driveId, itemId)}?$select=${ITEM_SELECT}`);
  }

  async sharedWithMe(token: string): Promise<DriveItem[]> {
    return this.http.paginate<DriveItem>(token, '/me/drive/sharedWithMe');
  }

  async searchSites(token: string, query: string): Promise<GraphSite[]> {
    const res = await this.http.request<{ value: GraphSite[] }>(
      token,
      `/sites?search=${encodeURIComponent(query)}&$select=id,displayName,webUrl`,
    );
    return res.value;
  }

  async listSiteDrives(token: string, siteId: string): Promise<GraphDrive[]> {
    if (!SITE_ID.test(siteId) || siteId.includes('..')) throw new BadRequestException('รหัส SharePoint site ไม่ถูกต้อง');
    const res = await this.http.request<{ value: GraphDrive[] }>(token, `/sites/${siteId}/drives?$select=id,name,driveType,webUrl`);
    return res.value.filter((drive) => drive.driveType === 'documentLibrary');
  }

  async downloadContent(token: string, driveId: string, itemId: string): Promise<Buffer> {
    return this.http.requestBuffer(token, `${itemPath(driveId, itemId)}/content`);
  }

  /** New file ≤ 4 MB. A name clash gets renamed by OneDrive ("x 1.docx") instead of overwriting someone's file. */
  async uploadSmall(token: string, driveId: string, parentId: string, name: string, body: Buffer, contentType: string): Promise<DriveItem> {
    return this.http.putBuffer<DriveItem>(
      token,
      `${itemPath(driveId, parentId)}:/${encodeURIComponent(safeDriveName(name))}:/content?@microsoft.graph.conflictBehavior=rename`,
      body,
      contentType,
    );
  }

  /** `{ parentId, name }` = new file (renamed on clash); `{ itemId }` = overwrite that item's content. */
  async createUploadSession(
    token: string,
    driveId: string,
    target: { parentId: string; name: string } | { itemId: string },
  ): Promise<string> {
    const isReplace = 'itemId' in target;
    const path = isReplace
      ? `${itemPath(driveId, target.itemId)}/createUploadSession`
      : `${itemPath(driveId, target.parentId)}:/${encodeURIComponent(safeDriveName(target.name))}:/createUploadSession`;
    const body = isReplace ? {} : { item: { '@microsoft.graph.conflictBehavior': 'rename' } };
    const res = await this.http.request<{ uploadUrl: string }>(token, path, { method: 'POST', body: JSON.stringify(body) });
    return res.uploadUrl;
  }

  /**
   * PUTs `body` to a pre-authenticated upload URL in 320 KiB-aligned chunks. Deliberately raw `fetch`
   * without the Authorization header: Graph documents that sending it to the upload URL can 401.
   */
  async uploadChunks(uploadUrl: string, body: Buffer): Promise<DriveItem> {
    let result: DriveItem | null = null;
    for (let start = 0; start < body.length; start += UPLOAD_CHUNK_BYTES) {
      const end = Math.min(start + UPLOAD_CHUNK_BYTES, body.length) - 1;
      const res = await fetch(uploadUrl, {
        method: 'PUT',
        headers: { 'Content-Range': `bytes ${start}-${end}/${body.length}` },
        body: body.subarray(start, end + 1),
      });
      if (!res.ok) {
        const text = await res.text().catch(() => '');
        throw new GraphApiError(res.status, `Upload chunk ${start}-${end} failed: ${res.status} ${text.slice(0, 300)}`);
      }
      if (res.status === 200 || res.status === 201) result = (await res.json()) as DriveItem;
    }
    if (!result) throw new GraphApiError(500, 'Upload session finished without returning the file');
    return result;
  }

  /** New file in a folder: simple PUT up to 4 MB, upload session above that. */
  async upload(token: string, driveId: string, parentId: string, name: string, body: Buffer, contentType: string): Promise<DriveItem> {
    if (body.length <= SMALL_UPLOAD_MAX_BYTES) return this.uploadSmall(token, driveId, parentId, name, body, contentType);
    return this.uploadChunks(await this.createUploadSession(token, driveId, { parentId, name }), body);
  }

  /** Overwrite an existing file — same item id, so the Office-online link keeps working. */
  async replaceContent(token: string, driveId: string, itemId: string, body: Buffer, contentType: string): Promise<DriveItem> {
    if (body.length <= SMALL_UPLOAD_MAX_BYTES) {
      return this.http.putBuffer<DriveItem>(token, `${itemPath(driveId, itemId)}/content`, body, contentType);
    }
    return this.uploadChunks(await this.createUploadSession(token, driveId, { itemId }), body);
  }

  /** `['Samnuan', ownRef]` → `/me/drive/root:/Samnuan/{ownRef}`, creating each missing level. */
  async ensureFolderPath(token: string, segments: string[]): Promise<DriveItem> {
    let parentId = 'root';
    let folder: DriveItem | null = null;
    for (const segment of segments) {
      folder = await this.getOrCreateFolder(token, parentId, safeDriveName(segment));
      parentId = folder.id;
    }
    if (!folder) throw new BadRequestException('ไม่ได้ระบุ folder');
    return folder;
  }

  private async getOrCreateFolder(token: string, parentId: string, name: string): Promise<DriveItem> {
    const childPath = `${itemPath('me', parentId)}:/${encodeURIComponent(name)}`;
    try {
      return await this.http.request<DriveItem>(token, childPath);
    } catch (error) {
      if (!(error instanceof GraphApiError) || error.status !== 404) throw error;
    }
    try {
      return await this.http.request<DriveItem>(token, `${itemPath('me', parentId)}/children`, {
        method: 'POST',
        body: JSON.stringify({ name, folder: {}, '@microsoft.graph.conflictBehavior': 'fail' }),
      });
    } catch (error) {
      // Another request created it between our GET and POST.
      if (error instanceof GraphApiError && error.status === 409) return this.http.request<DriveItem>(token, childPath);
      throw error;
    }
  }
}
```

```ts
import { BadRequestException, ForbiddenException, HttpException, NotFoundException, ServiceUnavailableException } from '@nestjs/common';
import { GraphApiError } from '../graph/graph-http';

export const DRIVE_DISCONNECTED_MESSAGE = 'ผู้ผูก folder ตัดการเชื่อมต่อแล้ว';

/** Thai guidance for a failed OneDrive call — shown in the case documents tab and returned by actions. */
export function driveErrorMessage(error: unknown): string {
  if (error instanceof GraphApiError) {
    if (error.status === 401) return 'การเชื่อมต่อ Microsoft หมดอายุ — เจ้าของบัญชีต้องเชื่อมต่อใหม่ที่หน้าตั้งค่า';
    if (error.status === 403) {
      return 'บัญชี Microsoft ที่ใช้ไม่มีสิทธิ์ในไฟล์/folder นี้ — ขอให้เจ้าของแชร์ให้ใน OneDrive หรือใช้ "นำเข้าเป็นเอกสารคดี"';
    }
    if (error.status === 404) return 'ไม่พบไฟล์/folder นี้ใน OneDrive แล้ว (อาจถูกย้าย ลบ หรือเลิกแชร์) — ผูก folder ใหม่';
    if (error.status === 429 || error.status >= 500) return 'Microsoft ไม่ตอบสนองชั่วคราว — ลองใหม่อีกครั้งในอีกสักครู่';
  }
  if (error instanceof HttpException) return error.message;
  return 'เรียก OneDrive ไม่สำเร็จ';
}

/** Graph failure → matching Nest exception with Thai guidance; Nest exceptions pass through untouched. */
export function toDriveHttpError(error: unknown): HttpException {
  if (error instanceof HttpException) return error;
  const message = driveErrorMessage(error);
  if (error instanceof GraphApiError) {
    if (error.status === 403) return new ForbiddenException(message);
    if (error.status === 404) return new NotFoundException(message);
    if (error.status === 401) return new BadRequestException(message);
  }
  return new ServiceUnavailableException(message);
}

/** For `.catch(rethrowDriveError)` on Graph calls made inside request handlers. */
export function rethrowDriveError(error: unknown): never {
  throw toDriveHttpError(error);
}
```

```ts
@Injectable()
export class CaseDriveService {
  constructor(
    private prisma: PrismaService,
    private connections: OutlookConnectionsService,
    private drive: GraphDriveClient,
    private documents: DocumentsService,
  ) {}

  /** "ใครเปิด/ดาวน์โหลดไฟล์คดีนี้" must be answerable for OneDrive files too. */
  async audit(user: AuthUser, action: DriveAuditAction, metadata: Record<string, unknown>) {
    await this.prisma.auditLog.create({
      data: { firmId: user.firmId, userId: user.id, action, metadata: metadata as never },
    });
  }

  /** The caller's own Microsoft token — picking folders and creating copies is always done as yourself. */
  async ownToken(user: AuthUser): Promise<{ connectionId: string; token: string }> {
    const connection = await this.connections.findActiveForUser(user.id);
    if (!connection) throw new BadRequestException(NO_MICROSOFT_CONNECTION_MESSAGE);
    return { connectionId: connection.id, token: await this.connections.getValidAccessToken(connection.id) };
  }

  findLink(caseId: string) {
    return this.prisma.caseExternalLink.findFirst({ where: { caseId, kind: DRIVE_FOLDER } });
  }

  /** Token of a stored connection, or null once its owner disconnected or the refresh failed. */
  async tokenForConnection(connectionId: string): Promise<string | null> {
    const connection = await this.prisma.mailboxConnection.findUnique({ where: { id: connectionId }, select: { status: true } });
    if (connection?.status !== MailboxConnectionStatus.ACTIVE) return null;
    try {
      return await this.connections.getValidAccessToken(connectionId);
    } catch {
      return null;
    }
  }

  async linkFolder(user: AuthUser, caseId: string, dto: { driveId: string; itemId: string }) {
    const { connectionId, token } = await this.ownToken(user);
    const item = await this.drive.getItem(token, dto.driveId, dto.itemId).catch(rethrowDriveError);
    if (!item.folder) throw new BadRequestException('เลือกได้เฉพาะ folder');
    const driveId = item.parentReference?.driveId;
    if (!driveId) throw new BadRequestException('ไม่พบ drive ของ folder นี้');

    const taken = await this.prisma.caseExternalLink.findUnique({
      where: { connectionId_kind_externalId: { connectionId, kind: DRIVE_FOLDER, externalId: item.id } },
    });
    if (taken && taken.caseId !== caseId) throw new ConflictException('folder นี้ผูกกับคดีอื่นอยู่แล้ว');

    const link = await this.prisma.$transaction(async (tx) => {
      // One drive folder per case: the documents tab and "เปิดแก้ใน Word" need a single target.
      await tx.caseExternalLink.deleteMany({ where: { caseId, kind: DRIVE_FOLDER } });
      return tx.caseExternalLink.create({
        data: {
          firmId: user.firmId,
          caseId,
          connectionId,
          kind: DRIVE_FOLDER,
          externalId: item.id,
          driveId,
          displayPath: driveDisplayPath(item),
          linkedById: user.id,
        },
      });
    });
    await this.audit(user, 'DRIVE_FOLDER_LINKED', { caseId, linkId: link.id, displayPath: link.displayPath });
    return link;
  }

  async unlinkFolder(user: AuthUser, caseId: string): Promise<{ unlinked: boolean }> {
    const { count } = await this.prisma.caseExternalLink.deleteMany({ where: { caseId, kind: DRIVE_FOLDER } });
    if (count) await this.audit(user, 'DRIVE_FOLDER_UNLINKED', { caseId });
    return { unlinked: count > 0 };
  }

  /** Live listing (nothing cached), read with the linker's token; everyone with case access may see it. */
  async listCaseFolder(user: AuthUser, caseId: string): Promise<CaseDriveListing> {
    const link = await this.findLink(caseId);
    if (!link?.driveId) return { state: 'NO_LINK', message: null, link: null, items: [] };

    const linker = await this.prisma.user.findUnique({
      where: { id: link.linkedById },
      select: { firstName: true, lastName: true },
    });
    const view = {
      id: link.id,
      displayPath: link.displayPath,
      linkedBy: linker ? `${linker.firstName} ${linker.lastName}` : null,
      isMine: link.linkedById === user.id,
    };

    const token = await this.tokenForConnection(link.connectionId);
    if (!token) {
      return { state: 'DISCONNECTED', message: `${DRIVE_DISCONNECTED_MESSAGE} — ผูก folder ใหม่ด้วยบัญชี Microsoft ของคุณ`, link: view, items: [] };
    }
    try {
      const items = await this.drive.listChildren(token, link.driveId, link.externalId);
      await this.audit(user, 'DRIVE_FOLDER_VIEWED', { caseId, linkId: link.id });
      return { state: 'OK', message: null, link: view, items: items.map(toItemView) };
    } catch (error) {
      return { state: 'ERROR', message: driveErrorMessage(error), link: view, items: [] };
    }
  }

  private async activeLink(caseId: string) {
    const link = await this.findLink(caseId);
    if (!link?.driveId) throw new NotFoundException('คดีนี้ยังไม่ได้ผูก folder OneDrive');
    const token = await this.tokenForConnection(link.connectionId);
    if (!token) throw new BadRequestException(DRIVE_DISCONNECTED_MESSAGE);
    return { link, token, driveId: link.driveId };
  }

  /**
   * An item id sent by the browser, accepted only if it sits directly in the case's linked folder —
   * the linker's token must not become a window into the rest of their OneDrive.
   */
  private async linkedItem(caseId: string, itemId: string) {
    const { link, token, driveId } = await this.activeLink(caseId);
    const item = await this.drive.getItem(token, driveId, itemId).catch(rethrowDriveError);
    if (item.parentReference?.id !== link.externalId) throw new NotFoundException('ไม่พบไฟล์นี้ใน folder ที่ผูกกับคดี');
    return { token, driveId, item };
  }

  async openItem(user: AuthUser, caseId: string, itemId: string): Promise<{ webUrl: string }> {
    const { item } = await this.linkedItem(caseId, itemId);
    await this.audit(user, 'DRIVE_FILE_OPENED', { caseId, itemId, name: item.name });
    return { webUrl: item.webUrl };
  }

  async importItem(user: AuthUser, caseId: string, itemId: string) {
    const { token, driveId, item } = await this.linkedItem(caseId, itemId);
    return this.importDriveFile(user, caseId, token, driveId, item);
  }

  /** "นำเข้าไฟล์ทั้ง folder" — offered before a disconnect so the files outlive the link. */
  async importAll(user: AuthUser, caseId: string): Promise<{ imported: number; skipped: string[] }> {
    const { link, token, driveId } = await this.activeLink(caseId);
    const items = await this.drive.listChildren(token, driveId, link.externalId).catch(rethrowDriveError);
    let imported = 0;
    const skipped: string[] = [];
    for (const item of items) {
      if (!item.file) continue;
      if ((item.size ?? 0) > DRIVE_IMPORT_MAX_BYTES) {
        skipped.push(item.name);
        continue;
      }
      await this.importDriveFile(user, caseId, token, driveId, item);
      imported += 1;
    }
    return { imported, skipped };
  }

  private async importDriveFile(user: AuthUser, caseId: string, token: string, driveId: string, item: DriveItem) {
    if (!item.file) throw new BadRequestException('นำเข้าได้เฉพาะไฟล์ ไม่ใช่ folder');
    if ((item.size ?? 0) > DRIVE_IMPORT_MAX_BYTES) throw new BadRequestException('ไฟล์ใหญ่เกิน 100 MB — ใช้ "เปิดใน Office ออนไลน์" แทน');
    const buffer = await this.drive.downloadContent(token, driveId, item.id).catch(rethrowDriveError);
    const document = await this.documents.createFromBuffer(user, caseId, {
      filename: item.name,
      buffer,
      mimeType: item.file.mimeType ?? 'application/octet-stream',
    });
    await this.audit(user, 'DRIVE_FILE_IMPORTED', { caseId, itemId: item.id, name: item.name, documentId: document.id });
    return document;
  }

  // --- folder picker (caller's own connection) ---

  async pickerChildren(user: AuthUser, driveId: string, itemId: string): Promise<DrivePickerItem[]> {
    const { token } = await this.ownToken(user);
    const items = await this.drive.listChildren(token, driveId, itemId).catch(rethrowDriveError);
    return items.map(toPickerItem).filter((item): item is DrivePickerItem => item !== null);
  }

  async pickerShared(user: AuthUser): Promise<DrivePickerItem[]> {
    const { token } = await this.ownToken(user);
    const items = await this.drive.sharedWithMe(token).catch(rethrowDriveError);
    return items.map(toPickerItem).filter((item): item is DrivePickerItem => item !== null);
  }

  async pickerSites(user: AuthUser, query: string): Promise<GraphSite[]> {
    const { token } = await this.ownToken(user);
    return this.drive.searchSites(token, query).catch(rethrowDriveError);
  }

  async pickerSiteDrives(user: AuthUser, siteId: string): Promise<GraphDrive[]> {
    const { token } = await this.ownToken(user);
    return this.drive.listSiteDrives(token, siteId).catch(rethrowDriveError);
  }
}
```

```ts
import { BadRequestException, ConflictException, Injectable, NotFoundException } from '@nestjs/common';
import { AuthUser } from '@lawfirm/shared';
import { PrismaService } from '../../prisma/prisma.module';
import { DocumentsService } from '../../documents/documents.service';
import { FileStorageService } from '../../common/services/file-storage.service';
import { DriveItem, GraphDriveClient } from '../graph/graph-drive.client';
import { GraphApiError } from '../graph/graph-http';
import { CaseDriveService } from './case-drive.service';
import { driveErrorMessage, toDriveHttpError } from './drive-errors';

/** Files Office for the web can edit. */
export const OFFICE_EDITABLE = /\.(docx|xlsx|pptx)$/i;

const UPLOADER_GONE_MESSAGE = 'ผู้เปิดแก้ใน Office ออนไลน์ตัดการเชื่อมต่อแล้ว — ดึงกลับไม่ได้ ให้เปิดแก้ใหม่จากเวอร์ชันในระบบ';
const BOTH_EDITED_MESSAGE =
  'มีการแก้ทั้งในระบบและใน Office ออนไลน์ — กด "ดึงเวอร์ชันล่าสุดกลับ" ก่อน แล้วค่อยเปิดแก้อีกครั้ง';

export interface DocumentOfficeLinkView {
  documentId: string;
  webUrl: string;
  uploadedVersion: number;
  lastModifiedDateTime: string | null;
  hasNewerEdits: boolean;
  error: string | null;
}

/**
 * When we last synced. Microsoft's clock and ours drift a little; the later of the two means a file
 * we just uploaded never shows up as "แก้ใน Word ล่าสุด" by itself.
 */
export function syncStamp(item: { lastModifiedDateTime: string }, now = new Date()): Date {
  return new Date(Math.max(now.getTime(), Date.parse(item.lastModifiedDateTime) || 0));
}

/**
 * `uploadNewVersion` expects a Multer file and runs `decodeUploadFilename` (latin1 → UTF-8) on its
 * name, so encode the name the way Multer would or Thai names come out as garbage.
 */
export function asUploadedFile(filename: string, buffer: Buffer, mimeType: string): Express.Multer.File {
  return {
    originalname: Buffer.from(filename, 'utf8').toString('latin1'),
    buffer,
    mimetype: mimeType,
    size: buffer.length,
  } as Express.Multer.File;
}

@Injectable()
export class DocumentOfficeService {
  constructor(
    private prisma: PrismaService,
    private caseDrive: CaseDriveService,
    private drive: GraphDriveClient,
    private documents: DocumentsService,
    private fileStorage: FileStorageService,
  ) {}

  private async loadDocument(caseId: string, documentId: string) {
    const document = await this.prisma.document.findFirst({
      where: { id: documentId, caseId },
      include: { officeLink: true, case: { select: { ownRef: true } } },
    });
    if (!document?.case) throw new NotFoundException('ไม่พบเอกสาร');
    return { ...document, case: document.case };
  }

  /** "เปิดแก้ใน Word ออนไลน์": make sure OneDrive holds the latest system version, return its webUrl. */
  async open(user: AuthUser, caseId: string, documentId: string): Promise<{ webUrl: string }> {
    const doc = await this.loadDocument(caseId, documentId);
    if (!OFFICE_EDITABLE.test(doc.filename)) {
      throw new BadRequestException('เปิดแก้ใน Office ออนไลน์ได้เฉพาะไฟล์ .docx .xlsx .pptx');
    }
    try {
      const link = doc.officeLink;
      const linkToken = link ? await this.caseDrive.tokenForConnection(link.connectionId) : null;

      if (link && linkToken) {
        let webUrl = link.webUrl;
        if (doc.version > link.uploadedVersion) {
          const current = await this.drive.getItem(linkToken, link.driveId, link.itemId);
          if (Date.parse(current.lastModifiedDateTime) > link.updatedAt.getTime()) throw new ConflictException(BOTH_EDITED_MESSAGE);
          const buffer = await this.fileStorage.getBuffer(doc.storagePath);
          const item = await this.drive.replaceContent(linkToken, link.driveId, link.itemId, buffer, doc.mimeType);
          await this.prisma.documentOfficeLink.update({
            where: { id: link.id },
            data: { uploadedVersion: doc.version, webUrl: item.webUrl, updatedAt: syncStamp(item) },
          });
          webUrl = item.webUrl;
        }
        await this.caseDrive.audit(user, 'DOCUMENT_OFFICE_OPENED', { caseId, documentId, version: doc.version });
        return { webUrl };
      }

      // No copy yet, or its uploader disconnected (their copy can no longer be read back): new copy as the caller.
      const { connectionId, token } = await this.caseDrive.ownToken(user);
      const buffer = await this.fileStorage.getBuffer(doc.storagePath);
      const item = await this.uploadCopy(token, caseId, doc.case.ownRef, doc.filename, buffer, doc.mimeType);
      const driveId = item.parentReference?.driveId;
      if (!driveId) throw new BadRequestException('OneDrive ไม่ได้ส่งรหัส drive กลับมา');
      const data = {
        connectionId,
        driveId,
        itemId: item.id,
        webUrl: item.webUrl,
        uploadedVersion: doc.version,
        updatedAt: syncStamp(item),
      };
      await this.prisma.documentOfficeLink.upsert({ where: { documentId }, create: { documentId, ...data }, update: data });
      await this.caseDrive.audit(user, 'DOCUMENT_OFFICE_OPENED', { caseId, documentId, version: doc.version });
      return { webUrl: item.webUrl };
    } catch (error) {
      throw toDriveHttpError(error);
    }
  }

  /** Into the case's linked folder when the caller may write there, else OneDrive ของฉัน/Samnuan/{ownRef}. */
  private async uploadCopy(token: string, caseId: string, ownRef: string, filename: string, buffer: Buffer, mimeType: string): Promise<DriveItem> {
    const link = await this.caseDrive.findLink(caseId);
    if (link?.driveId) {
      try {
        return await this.drive.upload(token, link.driveId, link.externalId, filename, buffer, mimeType);
      } catch (error) {
        if (!(error instanceof GraphApiError) || (error.status !== 403 && error.status !== 404)) throw error;
      }
    }
    const folder = await this.drive.ensureFolderPath(token, ['Samnuan', ownRef]);
    return this.drive.upload(token, 'me', folder.id, filename, buffer, mimeType);
  }

  /** "ดึงเวอร์ชันล่าสุดกลับ": Office edits → new DocumentVersion through the normal upload path. */
  async pull(user: AuthUser, caseId: string, documentId: string): Promise<{ updated: boolean; version: number }> {
    const doc = await this.loadDocument(caseId, documentId);
    const link = doc.officeLink;
    if (!link) throw new NotFoundException('เอกสารนี้ยังไม่เคยเปิดแก้ใน Office ออนไลน์');
    const token = await this.caseDrive.tokenForConnection(link.connectionId);
    if (!token) throw new BadRequestException(UPLOADER_GONE_MESSAGE);
    try {
      const item = await this.drive.getItem(token, link.driveId, link.itemId);
      if (Date.parse(item.lastModifiedDateTime) <= link.updatedAt.getTime()) return { updated: false, version: doc.version };
      const buffer = await this.drive.downloadContent(token, link.driveId, link.itemId);
      const updated = await this.documents.uploadNewVersion(
        user,
        caseId,
        documentId,
        asUploadedFile(doc.filename, buffer, doc.mimeType),
        'ดึงจาก Office ออนไลน์',
      );
      await this.prisma.documentOfficeLink.update({
        where: { id: link.id },
        data: { uploadedVersion: updated.version, updatedAt: syncStamp(item) },
      });
      await this.caseDrive.audit(user, 'DOCUMENT_OFFICE_PULLED', { caseId, documentId, version: updated.version });
      return { updated: true, version: updated.version };
    } catch (error) {
      throw toDriveHttpError(error);
    }
  }

  /** Per-document Office status for the documents tab ("แก้ใน Word ล่าสุด {เวลา}"). */
  async listForCase(caseId: string): Promise<DocumentOfficeLinkView[]> {
    const links = await this.prisma.documentOfficeLink.findMany({ where: { document: { caseId } } });
    return Promise.all(
      links.map(async (link): Promise<DocumentOfficeLinkView> => {
        const base = { documentId: link.documentId, webUrl: link.webUrl, uploadedVersion: link.uploadedVersion };
        const token = await this.caseDrive.tokenForConnection(link.connectionId);
        if (!token) return { ...base, lastModifiedDateTime: null, hasNewerEdits: false, error: UPLOADER_GONE_MESSAGE };
        try {
          const item = await this.drive.getItem(token, link.driveId, link.itemId);
          return {
            ...base,
            lastModifiedDateTime: item.lastModifiedDateTime,
            hasNewerEdits: Date.parse(item.lastModifiedDateTime) > link.updatedAt.getTime(),
            error: null,
          };
        } catch (error) {
          return { ...base, lastModifiedDateTime: null, hasNewerEdits: false, error: driveErrorMessage(error) };
        }
      }),
    );
  }
}
```

```ts
/** View helpers for the OneDrive section and the per-document Office buttons (M365 ส่วน D). */

const OFFICE_EDITABLE = /\.(docx|xlsx|pptx)$/i;

export function isOfficeEditable(filename: string): boolean {
  return OFFICE_EDITABLE.test(filename);
}

export function officeAppName(filename: string): 'Word' | 'Excel' | 'PowerPoint' {
  if (/\.xlsx$/i.test(filename)) return 'Excel';
  if (/\.pptx$/i.test(filename)) return 'PowerPoint';
  return 'Word';
}

export function formatFileSize(bytes: number | null): string {
  if (bytes == null) return '';
  if (bytes < 1024) return `${bytes} B`;
  if (bytes < 1024 * 1024) return `${Math.round(bytes / 1024)} KB`;
  return `${(bytes / (1024 * 1024)).toFixed(1)} MB`;
}

/** `13 ต.ค. 15:30` in Bangkok time, whatever the viewer's device zone. */
export function driveDateTime(iso: string): string {
  return new Intl.DateTimeFormat('th-TH', {
    timeZone: 'Asia/Bangkok',
    day: 'numeric',
    month: 'short',
    hour: '2-digit',
    minute: '2-digit',
  }).format(new Date(iso));
}

/** "แก้ใน Word ล่าสุด …" — only while Office holds edits that were not pulled back yet. */
export function officeEditedHint(
  filename: string,
  link: { lastModifiedDateTime: string | null; hasNewerEdits: boolean } | undefined,
): string | null {
  if (!link?.hasNewerEdits || !link.lastModifiedDateTime) return null;
  return `แก้ใน ${officeAppName(filename)} ล่าสุด ${driveDateTime(link.lastModifiedDateTime)} — ยังไม่ได้ดึงกลับ`;
}

/**
 * Opens the tab synchronously (so popup blockers treat it as the click) and points it at the URL
 * the API returns after its audit/upload. Closes the blank tab again if the call fails.
 */
export async function openInNewTab(load: () => Promise<string>): Promise<void> {
  const tab = window.open('', '_blank');
  if (tab) tab.opener = null;
  try {
    const url = await load();
    if (tab) tab.location.href = url;
    else window.location.href = url;
  } catch (error) {
    tab?.close();
    throw error;
  }
}
```

```tsx
  const [listing, setListing] = useState<CaseDriveListing | null>(null);
  const [loading, setLoading] = useState(true);
  const [busyId, setBusyId] = useState<string | null>(null);
  const [pickerOpen, setPickerOpen] = useState(false);
  const [error, setError] = useState('');
  const [notice, setNotice] = useState('');

  const load = () => {
    if (!token) return;
    setLoading(true);
    setError('');
    api
      .getCaseDrive(token, caseId)
      .then(setListing)
      .catch((e) => setError(e instanceof ApiError ? e.message : 'โหลดรายการ OneDrive ไม่สำเร็จ'))
      .finally(() => setLoading(false));
  };

  useEffect(load, [token, caseId]);

  const openItem = async (item: DriveItemView) => {
    if (!token) return;
    setError('');
    try {
      await openInNewTab(async () => (await api.openCaseDriveItem(token, caseId, item.id)).webUrl);
    } catch (e) {
      setError(e instanceof ApiError ? e.message : 'เปิดไฟล์ไม่สำเร็จ');
    }
  };

  const importItem = async (item: DriveItemView) => {
    if (!token) return;
    setBusyId(item.id);
    setError('');
    setNotice('');
    try {
      await api.importCaseDriveItem(token, caseId, item.id);
      setNotice(`นำเข้า "${item.name}" เป็นเอกสารคดีแล้ว`);
      onImported();
    } catch (e) {
      setError(e instanceof ApiError ? e.message : 'นำเข้าไม่สำเร็จ');
    } finally {
      setBusyId(null);
    }
  };

  const importAll = async () => {
    if (!token || !window.confirm('นำเข้าไฟล์ทั้งหมดใน folder นี้เป็นเอกสารคดี?')) return;
    setBusyId('*');
    setError('');
    setNotice('');
    try {
      const result = await api.importCaseDriveFolder(token, caseId);
      setNotice(
        `นำเข้าแล้ว ${result.imported} ไฟล์` +
          (result.skipped.length ? ` — ข้าม ${result.skipped.length} ไฟล์ที่ใหญ่เกิน 100 MB: ${result.skipped.join(', ')}` : ''),
      );
      onImported();
    } catch (e) {
      setError(e instanceof ApiError ? e.message : 'นำเข้าไม่สำเร็จ');
    } finally {
      setBusyId(null);
    }
  };

  const linkFolder = async (folder: DrivePickerItem) => {
    if (!token) return;
    await api.linkCaseDriveFolder(token, caseId, folder.driveId, folder.id);
    setPickerOpen(false);
    load();
  };

  const unlink = async () => {
    if (!token || !window.confirm('ยกเลิกการผูก folder นี้กับคดี? (ไฟล์ใน OneDrive ไม่ถูกลบ)')) return;
    try {
      await api.unlinkCaseDriveFolder(token, caseId);
      load();
    } catch (e) {
      setError(e instanceof ApiError ? e.message : 'ยกเลิกการผูกไม่สำเร็จ');
    }
  };

  const hasFiles = listing?.state === 'OK' && listing.items.some((item) => !item.isFolder);

  return (
    <div className="mb-6 rounded-xl border bg-card p-6 shadow-soft">
      <div className="mb-3 flex flex-wrap items-start justify-between gap-2">
        <div className="min-w-0">
          <h2 className="font-semibold text-foreground">OneDrive</h2>
          {listing?.link && (
            <p className="break-all text-xs text-muted-foreground">
              {listing.link.displayPath}
              {listing.link.linkedBy ? ` · ผูกโดย ${listing.link.linkedBy}` : ''}
            </p>
          )}
        </div>
        <div className="flex flex-wrap gap-2">
          {listing?.link && (
            <button type="button" onClick={load} className="inline-flex items-center gap-1 rounded-lg border px-2.5 py-1 text-xs hover:bg-accent">
              <RefreshCw className="h-3.5 w-3.5" />
              รีเฟรช
            </button>
          )}
          {hasFiles && (
            <button
              type="button"
              onClick={importAll}
              disabled={busyId === '*'}
              className="inline-flex items-center gap-1 rounded-lg border px-2.5 py-1 text-xs hover:bg-accent disabled:opacity-50"
            >
              <FileDown className="h-3.5 w-3.5" />
              {busyId === '*' ? 'กำลังนำเข้า…' : 'นำเข้าไฟล์ทั้ง folder'}
            </button>
          )}
          <button
            type="button"
            onClick={() => setPickerOpen(true)}
            className="inline-flex items-center gap-1 rounded-lg border px-2.5 py-1 text-xs font-medium hover:bg-accent"
          >
            <Link2 className="h-3.5 w-3.5" />
            {listing?.link ? 'เปลี่ยน folder' : 'ผูก folder OneDrive'}
          </button>
          {listing?.link && (
            <button type="button" onClick={unlink} className="rounded-lg border px-2.5 py-1 text-xs hover:bg-accent">
              ยกเลิกการผูก
            </button>
          )}
        </div>
      </div>

      {error && <p className="mb-2 text-sm text-destructive">{error}</p>}
      {notice && <p className="mb-2 text-sm text-emerald-700 dark:text-emerald-300">{notice}</p>}
      {loading && <p className="text-sm text-muted-foreground">กำลังโหลดจาก OneDrive…</p>}

      {!loading && listing?.state === 'NO_LINK' && (
        <p className="text-sm text-muted-foreground">
          ยังไม่ได้ผูก folder — กด &quot;ผูก folder OneDrive&quot; เพื่อแสดงไฟล์คดีจาก OneDrive/SharePoint ที่นี่
        </p>
      )}

      {!loading && listing && (listing.state === 'DISCONNECTED' || listing.state === 'ERROR') && (
        <p className="rounded-lg border border-amber-300 bg-amber-50 px-3 py-2 text-sm text-amber-800 dark:border-amber-800 dark:bg-amber-950/30 dark:text-amber-200">
          {listing.message}
        </p>
      )}

      {!loading && listing?.state === 'OK' && (
        <div className="space-y-2">
          {listing.items.length === 0 && <p className="text-sm text-muted-foreground">folder นี้ยังไม่มีไฟล์</p>}
          {listing.items.map((item) => (
            <div
              key={item.id}
              className="flex flex-col gap-2 rounded-lg border px-3 py-2 text-sm sm:flex-row sm:items-center sm:justify-between"
            >
              <div className="min-w-0">
                <p className="flex items-center gap-1.5 break-all font-medium">
                  {item.isFolder && <Folder className="h-4 w-4 shrink-0 text-muted-foreground" />}
                  {item.name}
                </p>
                <p className="text-xs text-muted-foreground">
                  {[formatFileSize(item.size), item.lastModifiedBy, driveDateTime(item.lastModifiedDateTime)].filter(Boolean).join(' · ')}
                </p>
              </div>
              <div className="flex flex-wrap gap-2">
                <button
                  type="button"
                  onClick={() => openItem(item)}
                  className="inline-flex items-center gap-1 rounded-lg border px-2.5 py-1 text-xs font-medium hover:bg-accent"
                >
                  <ExternalLink className="h-3.5 w-3.5" />
                  {item.isFolder ? 'เปิดใน OneDrive' : 'เปิดใน Office ออนไลน์'}
                </button>
                {!item.isFolder && (
                  <button
                    type="button"
                    onClick={() => importItem(item)}
                    disabled={busyId === item.id}
                    className="inline-flex items-center gap-1 rounded-lg border px-2.5 py-1 text-xs font-medium hover:bg-accent disabled:opacity-50"
                  >
                    <FileDown className="h-3.5 w-3.5" />
                    {busyId === item.id ? 'กำลังนำเข้า…' : 'นำเข้าเป็นเอกสารคดี'}
                  </button>
                )}
              </div>
            </div>
          ))}
          <p className="text-xs text-muted-foreground">
            ถ้า Microsoft แจ้งว่าไม่มีสิทธิ์เปิดไฟล์ ให้ขอผู้ผูก folder แชร์ให้ใน OneDrive หรือกด &quot;นำเข้าเป็นเอกสารคดี&quot;
          </p>
        </div>
      )}

      <DriveFolderPicker open={pickerOpen} title="เลือก folder OneDrive ของคดี" onClose={() => setPickerOpen(false)} onPick={linkFolder} />
    </div>
  );
}
```

```tsx
'use client';

import { useState } from 'react';
import { useAuth } from '@/lib/auth';
import { api, ApiError, CaseMatchSuggestion, DrivePickerItem } from '@/lib/api';
import { DriveFolderPicker } from '@/components/drive/DriveFolderPicker';
import { FolderMatchTable } from '@/components/settings/FolderMatchTable';

/**
 * OneDrive/SharePoint tab of "จับคู่ folder": choose the parent folder that holds one folder per case,
 * review suggested cases (same matcher as Outlook), confirm — nothing is linked before "ยืนยัน".
 */
export function DriveFolderMatchingTab() {
  const { token } = useAuth();
  const [pickerOpen, setPickerOpen] = useState(false);
  const [parent, setParent] = useState<DrivePickerItem | null>(null);
  const [rows, setRows] = useState<Array<{ folder: DrivePickerItem; suggestions: CaseMatchSuggestion[] }>>([]);
  const [loading, setLoading] = useState(false);
  const [confirming, setConfirming] = useState(false);
  const [message, setMessage] = useState('');

  const choose = async (folder: DrivePickerItem) => {
    if (!token) return;
    setPickerOpen(false);
    setParent(folder);
    setLoading(true);
    setMessage('');
    try {
      setRows(await api.getDriveFolderSuggestions(token, folder.driveId, folder.id));
    } catch (e) {
      setMessage(e instanceof ApiError ? e.message : 'โหลด folder ไม่สำเร็จ');
    } finally {
      setLoading(false);
    }
  };

  const confirm = async (picks: Array<{ key: string; caseId: string }>) => {
    if (!token) return;
    setConfirming(true);
    const failed: string[] = [];
    for (const pick of picks) {
      const row = rows.find((r) => r.folder.id === pick.key);
      if (!row) continue;
      try {
        await api.linkCaseDriveFolder(token, pick.caseId, row.folder.driveId, row.folder.id);
      } catch (e) {
        failed.push(`${row.folder.name}: ${e instanceof ApiError ? e.message : 'ผูกไม่สำเร็จ'}`);
      }
    }
    setConfirming(false);
    setMessage(
      failed.length
        ? `ผูกแล้ว ${picks.length - failed.length} folder — ไม่สำเร็จ: ${failed.join(' · ')}`
        : `ผูกแล้ว ${picks.length} folder`,
    );
  };

  return (
    <div className="space-y-4">
      <div className="flex flex-wrap items-center gap-2">
        <button type="button" onClick={() => setPickerOpen(true)} className="rounded-lg border px-3 py-1.5 text-sm hover:bg-accent">
          {parent ? 'เปลี่ยน folder หลัก' : 'เลือก folder หลักที่เก็บ folder คดี'}
        </button>
        {parent && <span className="text-sm text-muted-foreground">{parent.name}</span>}
      </div>
      {message && <p className="text-sm text-muted-foreground">{message}</p>}
      {loading && <p className="text-sm text-muted-foreground">กำลังจับคู่…</p>}
      {!loading && parent && (
        <FolderMatchTable
          rows={rows.map((row) => ({ key: row.folder.id, folderName: row.folder.name, suggestions: row.suggestions }))}
          confirming={confirming}
          onConfirm={confirm}
        />
      )}
      <DriveFolderPicker
        open={pickerOpen}
        title="เลือก folder หลัก (ที่มี folder ย่อยแยกตามคดี)"
        onClose={() => setPickerOpen(false)}
        onPick={choose}
      />
    </div>
  );
}
```
