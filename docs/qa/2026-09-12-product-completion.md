# Samnuan — แผนส่งมอบส่วนที่เหลือ

คำขอ: ทำต่อให้ครบทั้ง 7 หัวข้อ โดย UX ใช้งานง่าย และพิสูจน์ flow จริง

สถานะนี้แยกสิ่งที่ทำแล้วออกจากสิ่งที่ยังต้องตรวจ ไม่ใช้จำนวนหน้าหรือเมนูแทนความสำเร็จ

| ส่วน | เกณฑ์เสร็จ | สถานะ |
| --- | --- | --- |
| สมัครและเข้าใช้ | สมัคร → สำนักงาน → login → ทีม; สิทธิ์และข้อผิดพลาด | ผ่าน E2E รอบก่อน |
| My Day | ข้อมูลจริง, ผู้รับผิดชอบ, เหตุผล, กำหนด, action; ไม่แสดงงานปิดแล้ว | กำลังทำ |
| แฟ้มไปศาล | เตรียม → บันทึก → งานต่อเนื่องแบบ transaction; offline เปิดไฟล์และกู้ draft ได้ | online ผ่าน; offline ค้าง |
| กำหนดและความรับผิดชอบ | รับงาน, เตือน/ยกระดับ, แหล่งวันที่, preview เลื่อนวัน, audit | ค้าง |
| Portal | สนทนา/ส่งไฟล์เพิ่ม, วันที่ขอแยกวันที่ตกลง, ผู้ติดต่อทดแทนแบบจำกัดสิทธิ์ | ตรวจแล้ว พบช่องว่าง |
| Playbooks | รุ่นเผยแพร่คงที่, preview, apply ซ้ำไม่เกิดงานซ้ำ, ไม่เปลี่ยนคดีเก่าเงียบ ๆ | ค้าง |
| AI ที่ตรวจสอบแหล่งได้ | document/version/page, สถานะทนายตรวจ, แหล่งเปลี่ยนแจ้งเตือน, fixture ไทย | กำลังปรับ text ingestion |
| เริ่มใช้และนำเข้าข้อมูล | ความคืบหน้าจากข้อมูลจริง, preview ผิด/ซ้ำ, commit, undo เฉพาะ batch ที่ยังปลอดภัย | ค้าง |
| พื้นฐานระบบ | ตรวจ session/MFA, สิทธิ์ไฟล์/export, audit, restore, error monitoring | ค้างตรวจ |

## หลักการทดสอบ

ใช้สำนักงานและบัญชีทดสอบเฉพาะ ลบเฉพาะ fixture ของรอบนั้น ไม่ส่งข้อความจริง ไม่เรียก AI เสียเงิน ไม่ deploy และไม่ใช้ข้อมูลจริงเป็น fixture ทดสอบการข้ามสำนักงาน/ผู้ไม่มีสิทธิ์และ concurrency ในจุดที่มีการเขียนข้อมูลสำคัญ พร้อมตรวจมือถือและภาษาไทย/อังกฤษ
