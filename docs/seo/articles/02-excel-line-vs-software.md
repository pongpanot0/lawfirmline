# สำนักงานกฎหมายเล็กใช้ Excel กับ LINE กลุ่มพอไหม? 6 สัญญาณว่าถึงเวลาใช้โปรแกรมจัดการคดี

ถ้าสำนักงานมีทนาย 1–2 คนและมีคดีที่ยังไม่ปิดไม่ถึง 15–20 คดี ใช้ Excel คู่กับ LINE กลุ่มก็ยังพอไหว แต่เมื่อมีคนแก้ไฟล์เดียวกันหลายคน หรือต้องย้อนหาข้อมูลในแชตบ่อย ความเสี่ยงที่จะพลาดนัดหรือพลาดกำหนดเวลาจะเพิ่มขึ้นเร็วกว่าจำนวนคดี บทความนี้สรุปสัญญาณที่บอกว่าถึงเวลาเปลี่ยนแล้ว

## Excel กับ LINE กลุ่มดีตรงไหน

ทั้งสองอย่างฟรี ทุกคนใช้เป็นอยู่แล้ว และเริ่มใช้ได้ทันที สำหรับสำนักงานที่เพิ่งเปิด การจดคดีลงตารางและคุยงานในกลุ่ม LINE ถือเป็นจุดเริ่มต้นที่สมเหตุสมผล ปัญหาจะเกิดขึ้นเมื่อสำนักงานโตขึ้น

## 6 สัญญาณว่า Excel กับ LINE เริ่มเอาไม่อยู่

### 1. มีไฟล์ Excel คดีหลายเวอร์ชัน
เช่น "คดี_ล่าสุด.xlsx" กับ "คดี_ล่าสุด_แก้แล้ว.xlsx" และไม่มีใครแน่ใจว่าไฟล์ไหนถูก นั่นแปลว่าทีมไม่มีข้อมูลชุดเดียวที่ทุกคนเชื่อถือได้

### 2. ต้องเลื่อนแชตย้อนหลังเพื่อหาวันนัดหรือเอกสาร
ถ้าวันนัดศาลหรือรูปคำสั่งศาลอยู่ในแชต LINE เมื่อหลายสัปดาห์ก่อน ข้อมูลนั้นแทบหายไปแล้ว พอคนที่ส่งข้อความลาออก ข้อมูลส่วนนั้นก็หายไปด้วย

### 3. หัวหน้าต้องเดินถามทีละคนว่างานถึงไหน
ถ้าการประชุมเช้าวันจันทร์หมดไปกับการไล่ถามสถานะงาน แทนการตัดสินใจเรื่องคดี แสดงว่าสำนักงานยังไม่มีที่ให้เห็นภาพรวมงานของทีม

### 4. นัดศาลชน หรือรู้ตัวช้าว่าคนที่ต้องไปศาลลาวันนั้น
เมื่อนัดศาลอยู่ในปฏิทินส่วนตัวของแต่ละคน การรับนัดใหม่ในห้องพิจารณาจะต้องโทรถามคนอื่นก่อนทุกครั้ง

### 5. ลูกความโทรมาถามสถานะคดีวันละหลายสาย
แต่ละสายใช้เวลาไม่นาน แต่เมื่อมีหลายสาย ทีมก็ต้องหยุดงานที่ทำอยู่บ่อย และทนายต้องหาข้อมูลเดิมซ้ำทุกครั้ง

### 6. ต้องนับกำหนดเวลาด้วยปฏิทินกระดาษ
การนับวันยื่นคำให้การ อุทธรณ์ หรือฎีกาเอง ต้องคอยระวังวันหยุดราชการและวันที่ไม่มีในบางเดือน ([วิธีนับกำหนดเวลาคดีแพ่ง](/articles/civil-case-deadlines-thailand)) ถ้ามีคนเดียวที่นับเป็นและคนนั้นลา ความเสี่ยงจะอยู่ที่ทั้งสำนักงาน

ถ้าเจอตั้งแต่ 2 ข้อขึ้นไป โปรแกรมจัดการคดีมักคุ้มกว่าเวลาที่ทีมเสียไปในแต่ละเดือน

## ค่าใช้จ่ายของการไม่เปลี่ยน

ลองประเมินคร่าว ๆ ถ้าทีม 3 คนเสียเวลาวันละ 30 นาทีไปกับการไล่ถามสถานะ หาไฟล์ และตอบลูกความ เดือนหนึ่งจะเสียเวลาประมาณ 30 ชั่วโมง ค่าใช้จ่ายนี้สูงกว่าราคาโปรแกรมรายเดือนหลายเท่า ยังไม่นับความเสียหายถ้าพลาดกำหนดยื่นแม้แค่ครั้งเดียว

## ย้ายจาก Excel มาใช้โปรแกรมโดยไม่ต้องหยุดงาน

1. **เริ่มจากคดีที่ยังไม่ปิด** ไม่ต้องย้ายคดีเก่าทั้งหมดในวันแรก
2. **นำเข้าจาก Excel** โดยใช้เทมเพลตของระบบ แล้วตรวจคอลัมน์ชื่อคู่ความกับเลขคดีให้ถูกต้อง
3. **ใส่นัดศาลของ 60 วันข้างหน้า** ก่อนอย่างอื่น เพราะเป็นข้อมูลที่พลาดแล้วเสียหายที่สุด
4. **ย้ายการคุยงานเรื่องคดีออกจาก LINE กลุ่ม** แล้วใช้ LINE กลุ่มคุยเรื่องทั่วไปเท่านั้น
5. **เปิดพอร์ทัลลูกความ** ให้ลูกความ 2–3 รายที่ถามบ่อยที่สุดก่อน
