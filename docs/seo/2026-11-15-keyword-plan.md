แผนนี้เป็น input ให้ session "Samnuan.com SEO" ซึ่งเป็นเจ้าของ route ทั้งหมด (`/features/*` ใน PR 249, และ `/articles/*`, `/pricing`, `/en` ที่ยังไม่มีเจ้าของ; ตอนนี้ราคาอยู่ที่ `/#pricing` บนหน้าแรก)

  เมื่อ GSC มีข้อมูล impression แล้ว (ประมาณ 4–6 สัปดาห์หลัง deploy) ให้เรียงลำดับใหม่ตามข้อมูลจริง

## หน้าแรก (มีอยู่แล้ว) — คำหลักที่ควรถือไว้

`โปรแกรมจัดการคดี`, `ระบบจัดการสำนักงานกฎหมาย`, `โปรแกรมทนายความ`, `โปรแกรมบริหารสำนักงานกฎหมาย`
ควรมีคำเหล่านี้ใน title, H1 หรือย่อหน้าแรกอย่างน้อยคำละครั้ง ตอนนี้ title ใช้ "ระบบจัดการสำนักงานกฎหมาย" แล้ว แต่ยังไม่มีคำว่า "โปรแกรมจัดการคดี" ที่เป็นคำที่คนพิมพ์ค้นบ่อยกว่า

### กติกาเนื้อหา (ทั้ง landing page และบทความ)

- ตัวเลขราคาและจำนวนผู้ใช้ต้องดึงจาก `PLAN_CONFIG` ตอน build ห้าม hard-code ไว้ในเนื้อหา (ในร่างใช้ `{{price:TEAM}}` เป็นตัวแทน)
- ห้ามใส่ `aggregateRating` หรือรีวิวจนกว่าจะมีรีวิวจริง
- บทความกฎหมายต้องมีบรรทัดแจ้งว่าเป็นข้อมูลทั่วไป ไม่ใช่คำปรึกษา และระบุวันที่ตรวจทานล่าสุด (ใส่ `dateModified` ใน `Article` schema ด้วย)
- ทุกบทความต้องมีผู้เขียนหรือผู้ตรวจทานที่เป็นคนจริง เพราะเนื้อหากฎหมายเป็นหมวด YMYL ถ้ายังไม่มีทนายที่ยินยอมให้ใส่ชื่อ ให้ใช้ชื่อ "ทีม Samnuan" ไปก่อน ห้ามแต่งชื่อทนายขึ้นมาเอง
- ย่อหน้าแรกของแต่ละ H2 ต้องตอบคำถามได้ในตัว (40–60 คำ) เพื่อให้ AI ตัดไปอ้างอิงได้ทั้งย่อหน้า
