# Mobile redesign phase 2: role review and E2E (2026-11-15)

Simulator `Samnuan-E2E-Small` (iPhone, 375pt), dev client on Metro :8081, API from this branch on :3015, local DB.

## Test accounts (local DB only)

The local firm had only OWNER and ASSISTANT, so three accounts were added in the local database with the seed password:
`senior.e2e@lawfirm.test` (SENIOR_LAWYER), `lawyer.e2e@lawfirm.test` (LAWYER), `office.e2e@lawfirm.test` (OFFICE_MANAGER).
Senior and lawyer each got three self-assigned tasks: due today, overdue (13 Nov), and one finished today.

## Role review: what changed per role

| Role | Finding | Fix |
| --- | --- | --- |
| OWNER, OFFICE_MANAGER | Status strip showed only their own task states (all zero); team queues were gone | Office roles get "งานของฉันและทีม": ต้องทำ, กำลังทำ, รอฉันตรวจ, ต้องตาม, ไม่มีคนรับ |
| SENIOR_LAWYER | Own task listed twice: in "ทำต่อเลย" and in "งานครบกำหนดวันนี้" | Due-today list drops tasks already in "ทำต่อเลย" |
| SENIOR_LAWYER | 0 cases | By design: `viewAllCases` is OWNER + OFFICE_MANAGER only; the new account has no assignments |
| LAWYER, ASSISTANT | "พิจารณาเกลี่ยงาน" banner shown to people who cannot reassign | Banner and the 7-day button only for office roles and senior |
| All | "ส่งตรวจแล้ว" truncated in the strip | Label "รอตรวจ" |
| All | Status bar text unreadable once content scrolls under it | Navy backdrop behind the status bar on all tabs |
