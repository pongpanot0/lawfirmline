# รายการตรวจทุกหน้า (UX-09)

วันที่ 8 กันยายน 2026 · branch `claude/lawyer-workflow-reduction-11c1dd`

## ขอบเขตของการตรวจ — อ่านก่อน

**ทุกบรรทัดในตารางนี้คือผลจากการอ่าน source ที่ HEAD ไม่ใช่การกดใช้งานจริงบนเบราว์เซอร์**
ยังเข้าสู่ระบบไม่ได้ (ดู "สิ่งที่ยังทำไม่ได้" ท้ายเอกสาร) จึงยังไม่มีหน้าใดผ่าน
การทดสอบด้วยการใช้งานจริง — รวมถึงหน้าที่แก้ไปแล้ว

ช่อง "สถานะ" หมายถึง:
- **แก้แล้ว** — พบปัญหาจริงใน source และแก้ไปแล้วใน branch นี้
- **ไม่ต้องแก้** — ตรวจแล้วไม่พบปัญหาตามเกณฑ์ พร้อมเหตุผล
- **ยังติด** — พบปัญหาแล้วแต่ยังไม่ได้แก้ พร้อมเหตุผลว่าทำไม

จำนวนหน้าจริงคือ **54 routes** ไม่ใช่ 51 ตามที่ brief ระบุ — สาขานี้เพิ่ม
`my-day`, `court-schedule`, `admin/holidays`, `admin/deadline-rules` มาหลัง baseline
`court-schedule` เป็น re-export ของ `calendar` (`export { default } from '../calendar/page'`)
ไม่ใช่หน้าแยก จึงตรวจร่วมกัน

## สรุปสิ่งที่ยังติด (จัดกลุ่มตามสาเหตุ)

**1. สตริงสองภาษาในสตริงเดียว (`'English / ไทย'`) — 17 ไฟล์**

ผิดกติกา "ภาษาไทย/อังกฤษตาม locale" ตรงๆ แต่เป็นงานปริมาณมากที่ตรวจรับไม่ได้
หากไม่ได้เปิดดูจริงทีละหน้า จึงแก้เฉพาะหน้าที่แตะอยู่แล้วในรอบนี้
(`clients/new`, `expenses`, `expenses/new`) และไม่แตะหน้าที่เหลือ
ไฟล์ที่หนักที่สุดคือ `reports` (22 จุด), `cases/[id]/billing` (18), `admin/reimbursements` (17)

**2. หน้าที่ไม่มี error path เลย — 6 ไฟล์**

`register`, `forgot-password`, `reset-password`, `admin/users`, `admin/users/new`,
`account/billing`, `account/billing/checkout` ไม่มี `catch` แม้แต่จุดเดียว
คำขอที่ล้มเหลวจึงเงียบ ไม่ได้แก้เพราะสามหน้าแรกต้องทดสอบกับอีเมลจริง
และสองหน้าหลังเป็น flow ชำระเงินจริงที่ brief สั่งห้ามทดสอบนอก sandbox

## สิ่งที่ยังทำไม่ได้

**ยังไม่ได้ทดสอบหน้าใดบนเบราว์เซอร์เลย** — ยังเข้าสู่ระบบไม่ได้
หน้า login แสดงบัญชีเดโมไว้เอง แต่การพิมพ์รหัสผ่านลงช่องเป็นสิ่งที่ทำไม่ได้
ตามข้อกำหนดด้านความปลอดภัย ต้องให้ผู้ใช้กด Sign in เอง

จึงยังไม่ได้วัด: horizontal overflow, footer overlap, ชื่อไฟล์ยาว, keyboard navigation,
mobile 375/414/320px, dialog focus/Escape, และ role-based access ด้วยบัญชีจริง
ทั้ง 4 บทบาท ตัวเลข "จำนวนช่องที่ต้องพิมพ์ลดลงเท่าไร" และ "เวลาทำงานลดลงเท่าไร"
ก็ยังวัดไม่ได้ จึงไม่รายงาน
