> ข้อความคอลัมน์สุดท้ายคือ "คำสั่ง" ที่บอทจับ — ตรงกับ `MENU_SELECTION_MAP` และ `MENU_COMMAND` ใน `line-menu.ts` ถ้าเปลี่ยนคำต้องเปลี่ยนทั้งสองฝั่ง
> ปุ่ม "เบิกล่วงหน้า" ทุกคนเห็น แต่บอทเช็คสิทธิ์ — ไม่ใช่ Owner จะตอบว่าไม่มีสิทธิ์
> "งานของฉันวันนี้" ยังอยู่ในปุ่มตอบด่วนและพิมพ์เรียกได้ ส่วน "ลางาน" จะให้เลือก ลาป่วย/ลากิจ/พักร้อนในแชตส่วนตัว

## 4. วิธีตั้งค่า (ทำครั้งเดียวต่อ environment)

ภาพนี้มีแถบด้านล่าง จึงใช้สคริปต์ที่กำหนดพิกัดตรงกับภาพ แม่แบบ 6 ช่องแบบเท่ากันใน LINE Official Account Manager จะคลาดจากภาพนี้

```bash
node scripts/line-rich-menu.mjs apps/api/public/line-assets/rich-menu-leave.jpg --dry-run
LINE_CHANNEL_ACCESS_TOKEN=... node scripts/line-rich-menu.mjs apps/api/public/line-assets/rich-menu-leave.jpg
```

สคริปต์จะสร้างเมนู → อัปโหลดภาพ → ตั้งเป็น default ของทุกคนให้ครบ 3 ขั้น

ใช้ `LINE_CHANNEL_ACCESS_TOKEN` ตัวเดียวกับที่บอทใช้อยู่ · เปลี่ยนภาพภายหลัง = สร้างเมนูใหม่แล้วสลับ default (แก้ภาพบนเมนูเดิมไม่ได้)
เมนู default ผ่าน API มีลำดับแสดงก่อนเมนูที่ตั้งใน Manager; หากผู้ใช้บางคนมีเมนูเฉพาะบุคคล เมนูนั้นมีลำดับสูงกว่า default

**ก่อนตั้งเป็น default:** push/deploy API ที่รองรับคำสั่ง `ลางาน` และใช้ migration การลาให้เรียบร้อย แล้วจึงรันคำสั่งจริงด้านบน
