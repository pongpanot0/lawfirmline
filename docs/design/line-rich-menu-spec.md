# LINE Rich Menu — สเปกสำหรับทำรูป + วิธีตั้งค่า

อัปเดต: 2026-09-17 · ใช้กับ LINE Official Account ของสำนักงาน (บอทตัวเดียวกับที่ผูกบัญชีผ่าน "เชื่อมต่อ LINE")

## 1. ขนาดภาพ

- **2500 × 1686 px** (แบบเต็ม, สัดส่วนที่ LINE บังคับ) · JPEG หรือ PNG · ไฟล์ ≤ 1 MB
- แบ่งกริด **3 คอลัมน์ × 2 แถว** → ช่องละ **833×843 px** (คอลัมน์ขวาสุดกว้าง 834 px)

## 2. ผังปุ่มทั้ง 6 ช่อง

| ตำแหน่ง | ปุ่ม | ไอคอนแนะนำ | ข้อความที่ส่งเข้าแชทเมื่อกด |
|---|---|---|---|
| แถวบน-ซ้าย | เพิ่ม Task ในคดี | ✅ | `เพิ่ม Task` |
| แถวบน-กลาง | Todo ส่วนตัว | 📝 | `สร้าง Todo` |
| แถวบน-ขวา | รับเรื่องใหม่ (Intake) | 📋 | `สร้าง Case` |
| แถวล่าง-ซ้าย | บันทึกค่าใช้จ่าย | 💸 | `บันทึกค่าใช้จ่าย` |
| แถวล่าง-กลาง | เบิกล่วงหน้า | 💰 | `เบิกล่วงหน้า` |
| แถวล่าง-ขวา | งานของฉันวันนี้ | 📊 | `งานของฉันวันนี้` |

> ข้อความคอลัมน์สุดท้ายคือ "คำสั่ง" ที่บอทจับ — ตรงกับ `MENU_SELECTION_MAP` ใน `line-bot-router.service.ts` แล้ว ถ้าเปลี่ยนคำต้องเปลี่ยนทั้งสองฝั่ง (สคริปต์ `scripts/line-rich-menu.mjs` ก็ฝังคำสั่งชุดเดียวกัน)
> ปุ่ม "เบิกล่วงหน้า" ทุกคนเห็น แต่บอทเช็คสิทธิ์ — ไม่ใช่ Owner จะตอบว่าไม่มีสิทธิ์

## 3. แนวทางออกแบบภาพ

- พื้นหลังโทนเดียวกับแอป แบ่ง 6 ช่องด้วยเส้นบางๆ ให้เห็นขอบเขตการกดชัด
- แต่ละช่อง: ไอคอนใหญ่ตรงกลาง + ป้ายชื่อภาษาไทยตัวหนา ขนาดอ่านง่ายบนมือถือ (ตัวอักษร ≥ 60 px ในภาพจริง)
- ช่องแถวล่างคือของใหม่ — จะเน้นสี/ไฮไลต์ช่วงเปิดตัวก็ได้ ไม่บังคับ

## 5. วิธีตั้งค่า (ทำครั้งเดียวต่อ environment)

มี 2 ทาง เลือกทางเดียว:

**ทาง A — LINE Official Account Manager (ไม่ต้องเขียนโค้ด):**
[manager.line.biz](https://manager.line.biz) → เลือก OA → Rich menus → Create → อัปโหลดภาพ → เลือก template 6 ช่อง (3×2) → ตั้ง action แต่ละช่องเป็น **Text** ตามคอลัมน์ "ข้อความที่ส่งเข้าแชท" ข้างบน → ตั้ง Display period ยาวๆ → Save & แสดงเป็นเมนูหลัก

**ทาง B — สคริปต์ (แนะนำ):**

```bash
LINE_CHANNEL_ACCESS_TOKEN=... node scripts/line-rich-menu.mjs path/to/menu.png
```

สคริปต์จะสร้างเมนู → อัปโหลดภาพ → ตั้งเป็น default ของทุกคนให้ครบ 3 ขั้น (ตรวจ JSON ก่อนได้ด้วย `node scripts/line-rich-menu.mjs x --dry-run`)

ใช้ `LINE_CHANNEL_ACCESS_TOKEN` ตัวเดียวกับที่บอทใช้อยู่ · เปลี่ยนภาพภายหลัง = สร้างเมนูใหม่แล้วสลับ default (แก้ภาพบนเมนูเดิมไม่ได้)
