# Detail: งานมาก่อนข้อมูลประกอบ

ตรวจหน้าเดิมจริง: banner ทั่วไปไม่บอกงาน, checklist ติ๊กจบข้ามการตรวจ, งานขึ้นศาลไม่ตรงสถานะรับเรื่อง, ตัวกรองยังไม่ทำงาน, sidebar บีบรายการงาน

ปรับเฉพาะ mockup: สรุปงานค้าง/รอตรวจ/ติดขัดพร้อมมอบหมาย; งานแสดงคำสั่ง เจ้าของ กำหนดส่ง ผู้ตรวจ สิ่งที่ต้องส่ง; กรองตามคน/สถานะ; กล่องดำเนินการมีผลงาน ข้อแก้ไข เหตุติดขัด และประวัติ. สถานะเสร็จต้องผ่านรับงาน

ข้อมูลเดิมยังเข้าถึงผ่าน tabs/select: ข้อมูลคดี คู่ความ ประกันภัย Notice ข้อเท็จจริง/ฎีกา ปิดงาน บันทึก Playbook เอกสาร ค่าใช้จ่าย Cargo เฉพาะประเภท

Browser verification: สร้างงานพร้อมวันส่ง → ป้องกันส่งผลงานว่าง → ส่งผลงาน → รับงาน → กรองเสร็จแล้วพบ 1 รายการ. ส่งกลับแก้ไขพร้อมเหตุผล → กรองต้องแก้ไขพบ 1 รายการ. เอกสารเข้าถึงได้. ความกว้าง 320/375/414/768/1280 ไม่มี root overflow

ข้อจำกัด: ข้อมูลเก็บระหว่างเปิดหน้า รีโหลดคืนตัวอย่าง; ไม่มี backend notifications หรือ role authorization. เปิดคดีใหม่จากหน้า create จะเริ่มงานว่าง ไม่เติมงานจำลองให้คดีใหม่. งานตัวอย่างยังไม่กำหนดส่ง แสดงว่าไม่ระบุชัดเจน. ไม่อ้างเป็น production E2E
