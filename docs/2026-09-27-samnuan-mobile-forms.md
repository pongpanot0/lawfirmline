# Samnuan mobile — ฟอร์ม ทีม ไฟล์ และการค้นชื่อไฟล์

แก้ใน worktree `codex/mobile-court-workflow` ต่อจากหน้า Today และการมอบหมายงานเดิม ไม่เปลี่ยนโปรเจกต์หรือ checkout หลัก

## พฤติกรรมที่เปลี่ยน

- รับเคสสร้าง `/cases` จริง เลือกคนหลัก คนรองหลายคน ประเภทคดี ศาลจาก dropdown และแนบไฟล์/ถ่ายรูปได้ เส้นทาง intake เดิมส่งต่อเข้าฟอร์มนี้
- หน้าคดีมีแก้รายละเอียดและสถานะระหว่างดำเนินการ จัดทีมตามสิทธิ์ OWNER แสดงชื่อคนหลัก/รอง และมีปุ่มเพิ่มนัด เพิ่มงาน และเพิ่มเอกสาร เพิ่มปิดคดี/เก็บเข้าคลัง/เปิดคดีอีกครั้งตามสิทธิ์ API เว็บเดิม ก่อนปิดแสดงงาน นัดหมาย และเอกสารค้าง ต้องสรุปอย่างน้อย 10 ตัวอักษรและรับทราบของค้างก่อนยืนยัน
- เพิ่มงานเลือกผู้รับผิดชอบ วันครบกำหนด รายละเอียด และไฟล์ก่อนบันทึก งานเดิมแก้ไข มอบหมาย ส่งตรวจ รับ/ส่งกลับแก้ไข และเพิ่มความคิดเห็นได้ตามสิทธิ์ API เดิม
- เพิ่ม/แก้นัดเลือกศาล คนหลัก และผู้ร่วมได้รวมไม่เกิน 10 คน วันลาที่ตรงกับนัดแสดงคำเตือน การเลื่อนวัน/เวลาต้องระบุเหตุผล ตรวจผลกระทบ และยืนยันด้วย fingerprint จาก API
- เอกสารใช้ถ่ายรูปหรือแนบไฟล์ ไม่มีขั้นตอนสแกน/รวมภาพเป็น PDF ชื่อปุ่มค่าใช้จ่ายใช้ “เพิ่มค่าใช้จ่าย” การอนุมัติ/จ่ายชุดเบิกเดิมยังอยู่
- ค้นไฟล์ผ่าน API ใหม่ `/documents/files?q=&offset=` ใช้ filename contains แบบไม่แยกตัวพิมพ์เท่านั้น ไม่ค้น tag/เนื้อหาและไม่เรียก RAG รวมเอกสารคดี ไฟล์แนบงานในคดี และงานทั่วไปตามสิทธิ์เปิดคดี/งาน มี nextOffset โหลดครั้งละ 20 ไม่ตัดที่ 100 ผล แสดงชื่อไฟล์ คดี/งาน ขยายรายละเอียด รูป preview เปิดต้นฉบับและเข้าแฟ้ม/งานต้นทางได้ API `/documents/search` เดิมของเว็บยังคงเดิม
- ตั้งค่าตัวอักษร 4 ระดับ 100/120/140/160% บันทึกในโทรศัพท์และใช้กับข้อความ ช่องกรอก หัวหน้า และแท็บ ยังรองรับการขยายจากระบบโทรศัพท์
- ฟอร์มไม่ถูกข้อมูลที่โหลดใหม่ทับระหว่างกรอก ถ้าบันทึกคดี/งานสำเร็จแต่อัปโหลดบางไฟล์ไม่สำเร็จ คง ID เดิมและไฟล์ที่เหลือให้ลองส่งต่อ ไม่สร้างรายการใหม่จากการกดส่งต่อในฟอร์มเดียวกัน
- ฟอร์มคดี งาน นัดหมาย ค้นไฟล์ และปิดคดีเลื่อนช่องที่โฟกัสพ้นคีย์บอร์ดโดยคิดความสูงหัว navigation มีปุ่ม “เสร็จสิ้น” บนคีย์บอร์ด iOS dropdown/ตัวเลือกคดีใช้ safe area ของ modal และเว้นพื้นที่คีย์บอร์ด ชื่อคดียาวขึ้นหลายบรรทัดได้

## หลักฐานตรวจสอบ

ตรวจ mobile TypeScript และ `git diff --check` ผ่าน

Expo export สร้าง Hermes bundles ทั้ง Android และ iOS ผ่านโดยตั้ง `EXPO_PUBLIC_API_URL=https://api.samnuan.com` ระหว่างตรวจ พบเส้นทาง production `/users/members`, `/courts`, `/documents/search` และ `/case-types` ตอบ 401 เมื่อไม่มี token; นี่เป็นการตรวจ route/การป้องกันด้วย auth ไม่ใช่การยืนยัน payload หรือ workflow ของบัญชี production

`node apps/mobile/scripts/check-court-workflow.cjs` ผ่าน รวม contract ของไฟล์งาน ชื่อ MIME และ bytes ตลอดจน regression crash, ค่าใช้จ่าย, ชุดเบิก, วันเวลา และร่างเดิม

`node apps/mobile/scripts/check-mobile-forms.cjs /private/tmp/samnuan-mobile-e2e-fixture.json` ใช้ API/ฐานข้อมูลทดสอบที่ `127.0.0.1:3101` เท่านั้น ทดสอบสร้างคดีหลัก/รอง แก้คดี/ทีม/สถานะ อัปโหลดและดาวน์โหลด bytes ของไฟล์คดีและงาน ค้นชื่อบางส่วนแบบไม่แยกตัวพิมพ์และผลว่าง ความคิดเห็น ส่งตรวจ/ส่งกลับ/ผ่านทั้งงานคดีและงานส่วนตัว สร้างนัดหลายคน แก้ทีมและรายละเอียด และ preview/ยืนยันเลื่อนนัด อ่านผลที่บันทึกจริงแล้วลบงาน/นัดที่สร้างและ soft-delete คดีทดสอบ

`node apps/mobile/scripts/check-task-assignment.cjs /private/tmp/samnuan-mobile-e2e-fixture.json` ผ่านการมอบหมาย ผู้รับเห็นงาน และการปฏิเสธผู้ไม่เกี่ยวข้อง/มอบหมายขึ้น role

Expo Go บน iPhone 17 Pro จำลองเปิด Today หลัง login ได้ เปิดตั้งค่าและเลือกใหญ่พิเศษได้ เปิดฟอร์มรับเคส เลือกคนหลัก คนรอง และ dropdown ศาลได้ ตรวจข้อความและค่าที่เลือกผ่าน accessibility รวมทั้งภาพที่เห็นบางส่วน การตรวจภาพเต็มฟอร์ม คีย์บอร์ด และ file picker รอบนี้ยังไม่ครบ: กล่อง Save Password ของ Simulator ไม่ปรากฏใน accessibility และการกดพิกัดผิดพลาด จึงไม่อ้างว่า native E2E ครบทุกหน้า หรือผ่านจอเล็ก/Android จริง

## ขอบเขตการส่งมอบ

ผลนี้เป็น source และการทดสอบในเครื่อง ไม่ใช่การยืนยัน production ไม่มีการสร้างข้อมูลทดสอบใน production กล้องจริง Face ID เน็ตหลุดกลาง upload และการใช้งานฟอนต์ใหญ่บนเครื่องจริงยังต้องตรวจ ไม่มี server idempotency ใหม่ จึงไม่รับประกันกรณีเซิร์ฟเวอร์รับการสร้างรายการแล้ว response หาย

Production API default และ EAS preview ยังชี้ `https://api.samnuan.com` การใช้ `127.0.0.1:3101` เป็นค่าเฉพาะ Metro ทดสอบ APK 0.1.1 ที่ส่งก่อนหน้านี้ยังไม่มีรอบฟอร์ม/การค้น/ขนาดตัวอักษรนี้ ต้อง build APK ใหม่จึงจะนำรอบนี้ไปลองติดตั้ง Android ได้

## การตรวจเพิ่มเติมหลังเติม actions และ search (27 กันยายน 2569)

- API fixture local ผ่าน filename-only search เอกสารคดี/ไฟล์งาน/งานทั่วไป ตรวจ tag-only ไม่เจอ คดีที่ไม่มีสิทธิ์ไม่ปรากฏและดาวน์โหลดถูกปฏิเสธ โหลด 105 ผลครบไม่ซ้ำ ตรวจ offset ผิด และปิดคดีที่มีของค้างถูกปฏิเสธก่อนรับทราบ สรุปสั้นถูกปฏิเสธ ปิด/เก็บ/เปิดใหม่สำเร็จและของค้างยังอยู่
- Regression มือถือ/assignment ผ่าน API local และ Jest ที่ documents, task access, case access, close outstanding ผ่าน 51 tests

- Native iPhone 17 Pro Simulator ฟอนต์ 160% ตรวจภาพช่องคดีและความคิดเห็นงานพ้นคีย์บอร์ด dropdown ศาลค้น/เลือกพร้อมคีย์บอร์ดได้และหัวไม่ซ้อน status bar หน้าค้นแสดงผลจริง 3 แหล่ง ขยายรายละเอียดและเปิดงานต้นทางได้ ผลใหม่แทนข้อจำกัดกล่อง Save Password ที่บันทึกไว้ข้างต้น

- รอบนี้ยังไม่ได้ deploy API ใหม่ `/documents/files` ขึ้น production และยังไม่ได้สร้าง APK ใหม่ ต้องส่ง API และแอปด้วยกันก่อนทดสอบเวอร์ชันที่จะติดตั้งจริง
