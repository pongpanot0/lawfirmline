# Samnuan mobile: E2E and UX review

## Android crash fix: 0.1.1

ผู้ใช้รายงานจาก bug report ของ S23 Plus / Android 16 ว่า `AgendaRow` ใน `MyDayScreen` เด้งด้วย `Cannot read property 'filter' of undefined` หลังล็อกอิน ตรวจ source พบจุด `.filter()` ใน `AgendaRow` เพียงจุดเดียวคือ `item.assignees` ข้อมูล agenda เก่าจาก API หรือแคชที่ไม่มีฟิลด์นี้จึงทำให้หน้าแรกปิดได้

แก้ให้ตัวแสดงผู้ร่วมไปศาลตรวจ `Array.isArray(item.assignees)` และใช้ array ว่างเมื่อฟิลด์หาย เป็น null หรือชนิดผิด ครอบคลุมแถวในนัดวันนี้ นัดที่ใช้ข้อมูล agenda สำรอง และรายการเกินกำหนด โดยไม่ต้องล้างแคชหรือข้อมูลร่าง ทดสอบฟิลด์หาย/undefined/null/object/string/array ว่าง และรายชื่อปกติที่ต้องตัดผู้รับผิดชอบหลักออก ผ่าน `check-court-workflow.cjs`; mobile typecheck และ diff check ผ่าน

APK 0.1.1 / versionCode 2 ผ่าน EAS build `7f3f6efe-8c22-4f75-96d7-69fbffc37bc8` สำเร็จ โดยผู้ใช้อนุญาตอัปโหลด source แล้ว ใช้ API `https://api.samnuan.com` และลายเซ็นเดิม ตรวจ APK ZIP integrity ผ่าน ยืนยันชื่อ Samnuan, versionName 0.1.1, versionCode 2 และ production URL ใน bundle แล้ว ติดตั้งทับ 0.1.0 บน Android 16 ARM64 emulator ผ่าน (`adb install -r`: Success) และเปิดแบบ cold start สำเร็จ (232 ms) การทดสอบนี้ยังไม่ยืนยันผลหลังล็อกอินบน S23 จริง

ตรวจตัว `AgendaRow` เพิ่มเติมโดยรัน source ของแถวกับตัวแทน React Native elements: โค้ดเดิมสร้าง TypeError ได้เมื่อไม่มี `assignees`; โค้ดที่แก้ render ข้อมูลหาย/null/non-array และชื่อผู้ร่วมปกติผ่าน การตรวจนี้เป็น source rendering regression ไม่ใช่ native UI E2E บนเครื่องจริง

## ข้อพบที่แก้ในรอบนี้

1. เปลี่ยนชื่อที่มองเห็นและชื่อแอปจาก LexFlow เป็น Samnuan
2. นัดที่ยืนยันผลแล้วเคยหายจากหน้าแรก: เปลี่ยนส่วน “นัดวันนี้” ให้ใช้ปฏิทินทั้งวัน โดยคงคิวงานวันนี้แยกต่างหาก
3. หน้าทีมเคยนับนัดวันนี้เป็นศูนย์: แก้ช่วงวันที่ใน hook ปฏิทินร่วมกันเป็น 00:00–23:59:59.999 เวลาไทย และ encode เวลาใน query; ครอบคลุมหน้าปฏิทินด้วย
4. ปุ่มทีม/ผลศาลของทนายอาวุโสไม่ตรงกับ API เดิม: ปรับ UI ให้ตรงกับสิทธิ์เข้าถึงคดีที่ API รองรับอยู่แล้ว ไม่เปลี่ยน authorization ของ API
5. ปุ่มย้อนกลับเคยแสดง “(tabs)”: เปลี่ยนเป็น “กลับ”
6. หลังบันทึกร่างเข้าระบบยังแสดงเหมือนเก็บเฉพาะเครื่อง: แสดงสถานะร่างในระบบเมื่อ version และข้อมูลตรงกัน
7. รหัสชุดเบิกยาวเต็ม UUID: ย่อให้ตรงกับรหัสที่ใช้ในรายการชุด
8. เพิ่มค่าที่เลือกให้ตัวอ่านหน้าจอของ dropdown และชื่อปุ่มเมนู/แจ้งเตือน
9. หน้าล็อกไม่มีทางออกเมื่อยืนยันตัวตนบนเครื่องไม่ได้: เพิ่มออกจากระบบแล้วเข้าสู่ระบบใหม่ โดยไม่เปิดข้อมูลที่ถูกล็อก
10. ป้ายกำลังคนเคยเรียกคนมีงานเดียวว่า “งานมาก”: ใช้ “มีงานเปิด/ไม่มีงานเปิด” และระบุ “คดีหลัก” กับ “นัดศาล 7 วันถัดไป” ให้ตรงฐานตัวเลข
11. ย้ายสรุปชุดเบิกรออนุมัติ/รอจ่ายขึ้นใต้คำทักทาย ก่อนนัดวันนี้ แตะแล้วเปิดรายการกรองตามสถานะ; บน iPhone SE เห็น 1 ชุด 590 บาทโดยไม่เลื่อน และหน้ารายการแสดงเฉพาะชุดรออนุมัติ
12. ฟอร์มค่าใช้จ่าย นัดใหม่ รับเรื่อง และบันทึกวันศาล ใช้ ScrollView หลบคีย์บอร์ดของ iOS; จำนวนเงินมีปุ่ม “เสร็จ” เหนือแป้นตัวเลข ทดสอบบน SE แล้วช่องยอด 42 บาทมองเห็นเหนือคีย์บอร์ดและปิดคีย์บอร์ดได้ ส่วนรายละเอียดใช้ปุ่มเสร็จของแป้นพิมพ์ได้
13. เก็บภาพลงโฟลเดอร์ร่างของบัญชีก่อนแสดง preview พร้อม MIME และตรวจขนาด/ชนิดไฟล์ แก้ตัวคั่นเส้นทางโฟลเดอร์; รูปตัวอย่างยังแสดงหลังออกแล้วเปิดร่างใหม่
14. พบจริงขณะ E2E ว่า Expo SDK 56 ปฏิเสธ multipart แบบ `{ uri, name, type }` ก่อนถึง API แก้ร่วมกันทั้งใบเสร็จและเอกสารคดีเป็น File-like part ที่อ่านผ่าน `bytes()`; native UI อัปโหลดภาพสำเร็จ และดาวน์โหลดภาพผ่าน endpoint ที่ต้องยืนยันตัวตนได้จริง
15. ตั้ง timeout การส่งไฟล์ 60 วินาทีและไม่ส่งซ้ำอัตโนมัติ เมื่อ API ทดสอบปิด แอปแจ้งส่งไม่สำเร็จ ออกจากฟอร์มและเปิดใหม่ได้หมวด ยอด และรายละเอียดครบ หลังเปิด API กลับ ส่งพร้อมรูปได้ 1 รายการ สถานะ DRAFT และปิดร่างในเครื่องสำเร็จ
16. เพิ่มข้อความขอสิทธิ์กล้อง รูปภาพ และ Face ID ของ Samnuan สำหรับ native build พร้อมปิดการขอสิทธิ์ไมโครโฟนจาก image picker ตรวจ introspected Info.plist แล้วมีข้อความครบ; Expo Go ยังคงแสดงสิทธิ์ของ Expo Go

## ตรวจผลในระบบจริงหลังคลิก UI

`node apps/mobile/scripts/verify-e2e.cjs /private/tmp/samnuan-mobile-e2e-fixture.json` ผ่าน โดยตรวจบัญชีทั้ง 4 บทบาท ทีมที่เพิ่ม ผลศาลที่ยืนยัน นัดทั้งวัน คำขอลาที่รออนุมัติ และชุด 200 บาทที่มี 2 รายการและจ่ายแล้ว

ตรวจเพิ่มเติม: บัญชีทนายอนุมัติไม่ได้ (403), บัญชีผู้ช่วยไม่เห็นชุดของทนาย, ทนายอาวุโสเข้าคดีนี้ผ่าน API ได้ เงินสดย่อยจาก 50,000 เหลือ 49,800 บาท หักเพียงครั้งเดียว และคำขออนุมัติซ้ำของชุดที่จ่ายแล้วถูกปฏิเสธโดยยอดไม่เปลี่ยน

Mobile typecheck, check-court-workflow.cjs, git diff --check และการ export bundle iOS/Android ผ่าน การตรวจนี้ไม่ใช่การเผยแพร่แอปหรือหลักฐานการทำงานบน production

รอบ UX: `node apps/mobile/scripts/verify-e2e.cjs /private/tmp/samnuan-mobile-e2e-fixture.json --ux` ผ่าน ตรวจรายการ 42 บาทจาก native UI มีเพียงรายการเดียวและดาวน์โหลดภาพได้ HTTP 200 พร้อม bytes จริง ภาพเป็นภาพดอกไม้ตัวอย่างเพื่อทดสอบไฟล์ ไม่ใช่ใบเสร็จจริง ตรวจ typecheck, upload contract ของใบเสร็จ/เอกสารคดี, เส้นทางภาพ, การแจ้ง network error โดยไม่ retry และ export iOS/Android อีกครั้งหลังแก้ไฟล์แล้วผ่าน

## ความเห็น UX และขอบเขตที่ยังต้องทดสอบ

### หน้า Today เน้นกำลังคนและงานประจำวัน

ลำดับสำหรับเจ้าของ: กำลังคนรายคน → งานครบกำหนดวันนี้ → นัดวันนี้ → ชุดเบิก → ตัวเลขภาพรวม/งานเกินกำหนด/คำเตือน → เมนูลัด แสดงนัดพร้อมเวลาและบทบาทหลัก/ร่วม ชื่องานที่ครบกำหนดวันนี้ สถานะลา และแยกจำนวนงานค้างทั้งหมดออกจากงานวันนี้ มีปุ่มมอบหมายงานและขยายรายชื่อเมื่อทีมเกินสี่คน บทบาทอื่นเริ่มจากงานครบกำหนดวันนี้และยังไม่มีข้อมูลทีมของเจ้าของ

ตรวจบน native iPhone 17 Pro ด้วยข้อมูล local fixture หลังโหลด bundle ล่าสุด: กำลังคนเป็นส่วนแรก ทีม 4 คน มีนัดศาล 3 คน (รวมผู้ร่วม) ลาอนุมัติ 1 คน การลารออนุมัติแสดงต่างกัน ผู้ช่วยที่มีนัดตรงวันลามีคำเตือน ทนายมีนัด 2 รายการและงานครบกำหนด 1 งาน กดมอบหมายงานเปิดแท็บงานที่มี dropdown ผู้รับผิดชอบและปุ่มมอบหมายรายงานได้ ตรวจ TypeScript, court-workflow regression และ diff ผ่าน; มี regression สำหรับผู้รับผิดชอบหลัก/ร่วมและ assignees ที่หายหรือเป็นชนิดผิด ยังไม่ได้ตรวจหน้า Today รอบนี้บนจอเล็ก บทบาทอื่นผ่าน native UI หรือ APK ใหม่

### งานบนมือถือ: เพิ่มและเปลี่ยนผู้รับผิดชอบ

เพิ่ม dropdown ผู้รับผิดชอบก่อนสร้างงาน ป้ายผู้รับผิดชอบบนการ์ด และปุ่มมอบหมายที่มองเห็นได้ ใช้ `/users/lawyers` กับลำดับสิทธิ์เดิมสำหรับงานทั่วไป; งานคดีใช้สิทธิ์เจ้าของสำนักงานหรือทนายหลัก การมอบหมายที่ล้มเหลวคงหน้าต่างไว้และแสดงข้อผิดพลาด; สร้างงานไม่สำเร็จคงชื่อที่พิมพ์ไว้ แสดงวันลาและเตือนเมื่อเปลี่ยนผู้รับผิดชอบไปหาคนที่ลา

`node apps/mobile/scripts/check-task-assignment.cjs /private/tmp/samnuan-mobile-e2e-fixture.json` ผ่านบน API/ฐานข้อมูลทดสอบในเครื่อง: สร้างงานให้ทนาย เปลี่ยนเป็นผู้ช่วย ผู้รับใหม่เห็นงาน ผู้รับเดิมไม่เห็นงาน สิทธิ์ผู้ไม่เกี่ยวข้องและมอบหมายขึ้น role ถูกปฏิเสธ รวมถึงการมอบหมายงานคดีและอ่านผลที่บันทึกจริง ลบงานทดสอบที่สร้างออกหลังจบ ตรวจ mobile typecheck และ diff check ผ่าน ยังไม่ได้ยืนยันหน้ามอบหมายใหม่ผ่าน native UI หรือ production และ APK 0.1.1 เดิมยังไม่มีการเปลี่ยนนี้

- ทดสอบ API ติดต่อไม่ได้ก่อนส่งแล้วร่างไม่หาย; ยังไม่ได้ทดสอบเน็ตเครื่องจริงหลุดระหว่างส่ง หรือ server รับสำเร็จแต่ response หาย ระบบยังไม่มี idempotency สำหรับสร้างค่าใช้จ่าย จึงแจ้งให้ตรวจรายการก่อนส่งอีกครั้ง ห้ามตีความผล “1 รายการ” ว่ารองรับ response หายโดยไม่ซ้ำทุกกรณี
- ยังไม่ได้ทดสอบการปิดแอปแบบบังคับและความขัดแย้งระหว่างหลายเครื่อง
- ยังไม่ได้ทดสอบ native UI ของผู้ช่วย/ทนายอาวุโสทุกหน้า; สองบทบาทนี้ตรวจ login/access/isolation ผ่าน API ส่วน UI walkthrough ใช้ทนายและเจ้าของ
