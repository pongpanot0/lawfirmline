# 2026-09-08 — E2E/UX round: P1 fixes

Source: the role-based exploratory E2E report of 2026-09-08 (Owner / Senior / Lawyer).

## Fixed (verified on the worktree preview against the running API)

1. **Reviewer list empty for non-admins** — `/todos` and `/cases/[id]/tasks` called
   `GET /users` (ADMIN only) and swallowed the 403. Both now call `GET /users/lawyers`
   (firm-scoped). The todos page keeps a separate "reviewer list failed to load" state
   with a retry button inside the handoff form, distinct from "no reviewers in firm".
2. **Handoff/review failures invisible** — `KanbanBoard` now awaits handoff / accept /
   reject, keeps the form open on failure, and shows the server's reason on the card
   (`role="alert"`). Pages rethrow instead of catching these.
3. **Handoff offered to the case's own reviewer** — the lead lawyer no longer sees the
   handoff button (server always rejected it). Others see "ส่งให้ {lead lawyer} ตรวจ".
   Finished *personal* tasks no longer offer handoff (server rejects DONE there).
4. **Personal-todo reviewer not firm-checked** — `handoffStandalone` now requires the
   reviewer to be a member of the caller's firm (spec added).
5. **Documents page defaulted to the first (closed) case** — no default; option list is
   "เลือกคดี" + `ref — title`, closed cases tagged and sorted last.

6. **Case wizard required black + red numbers (P1-4)** — decision taken: both optional at
   creation. `CreateCaseDto` accepts omitted/empty values (a present value must still match
   the court format); the service stores null; the wizard marks the fields "(ถ้ามี)", drops
   the `required` attribute, explains that the office reference tracks the case until the
   court numbers arrive, and the review step shows "ยังไม่มี". Numbers are added later on
   the case page, which already allowed it. Spec: `case-numbers.spec.ts`.

## P2 round (same day, same branch)

5. **Numbers** — dashboard "awaiting approval" lists PENDING only (matching its count and the
   expense pages); approved-but-unpaid is its own line; "view all" opens reimbursements on the
   same filter. Team workload shows distinct open cases with the assignment total underneath.
6. **Scope** — menu/page renamed "งานส่วนตัว"; description explains case tasks vs My Day; owners
   and seniors get a mine / team / awaiting-my-review switch; agenda rows carry the assignee and
   show it when it is not the viewer.
7. **Case page** — opens on lead lawyer, next hearing, soonest task; tabs are the only
   navigation; the AI panel is folded below the work.
8. **AI pricing/file rules** — `AI_CREDIT_COST` and upload limits in `@lawfirm/shared`, used by
   the server and both panels; each panel names its service.
9. **Calendar** — an existing event opens read-only with a case link; Edit is one click further;
   delete lives only in edit mode.
10. **Silent loads** — no non-admin page calls an admin-only GET any more (only four exist);
    clients, cases, intake, knowledge and the case board show a "load failed / retry" state via
    `components/ui/LoadFailed` instead of an empty list.
