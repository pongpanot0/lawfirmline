## 2. ฟอร์มสร้างคดี (/cases/new) — ลด field / ลด step

ปัจจุบัน 4 ขั้น: ประเภทคดี → ข้อมูลคดี → ข้อมูลเฉพาะ → ทีมและตรวจสอบ
ช่องบังคับจริงมีแค่ 4: ชื่อคดี, ระดับศาล, ศาล, ทนายผู้รับผิดชอบ

| ปัญหา | ข้อเสนอ |
|---|---|
| **AI "วิเคราะห์เนื้อหาไฟล์" อยู่บนสุด ทุก step** กินพื้นที่ครึ่งจอ ก่อนถึงฟอร์ม และซ้ำกับหน้า intake | ย้ายไปเป็น collapsible ด้านล่าง หรือให้ทำหลังสร้างคดี (tab "วิเคราะห์ด้วย AI" มีอยู่แล้วในหน้าคดี) |
| Step 3 "ข้อมูลเฉพาะ" มีแค่ 2 ช่อง optional และ **Claim Amount ซ้ำกับ ทุนทรัพย์ (step 2)** | ตัด step 3 ทิ้ง: ลบ Claim Amount, ย้าย "คู่ความ" ไป step 2 ส่วน optional |
| Step 1 "ประเภทคดี" เป็นหน้าเต็มสำหรับ radio 5 ตัว | รวมเป็น dropdown บนสุดของ step ข้อมูลคดี |
| ระดับศาล + ศาล บังคับ ทั้งที่ intake/คดีปรึกษาบางเรื่องยังไม่ถึงศาล (เห็น 3 คดีในระบบที่ศาล = —) | ทำเป็น optional เหมือน เลขดำ/เลขแดง, default ศาลชั้นต้น |
| ลูกค้า: search box + select + text "ชื่อที่ไม่มีในรายชื่อ" + checkbox "ยังไม่ทราบชื่อ" = 4 control สำหรับ 1 ค่า | combobox เดียว พิมพ์ค้นหา/สร้างใหม่ได้ (creatable select) |
| หน้าตรวจสอบแสดง "ลูกค้า: tmp" ทั้งที่ไม่ได้เลือกลูกค้า (น่าจะเป็น draft ค้าง) | ถ้ามี draft ค้าง ให้แจ้ง "มีข้อมูลค้างจากครั้งก่อน — ใช้ต่อ / เริ่มใหม่" |
| "คำนวณค่าบริการ" toggle + ตารางประมาณการ 3 แถวว่างในหน้าคดี | ซ่อนตารางจนกด "เพิ่มรายการ" แถวแรก |

## 4. Data / Display bugs ที่กระทบ UX

- **เวลานัด 00:14, 21:23, 23:14** ปรากฏทั่วระบบ (dashboard, my-day, court-schedule, case detail) → น่าจะ timezone/seed bug; นัดศาลตอนเที่ยงคืนทำให้ผู้ใช้ไม่เชื่อถือข้อมูล
- Dashboard "กำไรสุทธิรวม ฿12,371,173" มาจากคดี test "dsaasdas" ที่กรอก ฿12,312,323 — KPI ถูก outlier ครอบ; รายงานควรแยก "ประมาณการ" ออกจาก "รายได้จริง"
- Case detail: "ประเภทคดี —, ระดับศาล —" ทั้งที่ seed มี → ข้อมูลไม่ครบแต่ไม่มี CTA ให้เติม
- Reports "จำนวนคดีตามประเภท: Uncategorized 10 คดี" ไม่มีประโยชน์ถ้า case type ว่างหมด
- ตารางคดีบน mobile (375px) เป็น 9 คอลัมน์ scroll แนวนอน อ่านไม่ได้ → ควรเป็น card list บน mobile
- Dashboard mobile: 5 KPI card เต็มความกว้าง ต้อง scroll ~3 จอถึงจะเห็น "วันนี้" → ให้ KPI เป็น 2 คอลัมน์ และย้าย "วันนี้" ขึ้นบน

## 5. Feature ที่ควรเพิ่ม (เรียงตามผลต่อการใช้งานประจำวัน)

1. **Global search ใช้งานได้จริง** — ช่องค้นหาบน header มีแล้ว ควรค้นได้ทั้งคดี/ลูกค้า/เลขดำ/เลขแดง พร้อม keyboard shortcut (⌘K)
2. **Quick-add จากทุกที่** — ปุ่ม + เดียวเปิด popover: รับเรื่อง / นัด / ค่าใช้จ่าย / งาน โดยไม่ต้องออกจากหน้าปัจจุบัน
3. **บันทึกผลหลังขึ้นศาล → สร้างนัดถัดไปในขั้นตอนเดียว** — ปุ่มมีแล้วในหน้าคดี ควรถามวันนัดหน้าและอัปเดตสถานะคดีทันที
4. **Case status ที่ derive อัตโนมัติ** — มีนัดศาลถึงเปลี่ยนเป็น "นัดศาล", มีเลขดำถึงเป็น "ยื่นฟ้องแล้ว" แทนให้เปลี่ยนมือ
5. **Deadline จาก deadline-rules ถูกสร้างอัตโนมัติ** เมื่อบันทึกผลศาล (เช่น อุทธรณ์ภายใน 30 วัน) แสดงใน my-day
6. **Template ชื่อคดี/งานเริ่มต้นตามประเภทคดี** — สร้างคดี "Litigation" แล้วได้ checklist งานพื้นฐาน (ยื่นฟ้อง, ส่งหมาย, เตรียมพยาน) ทันที
7. **Bulk action ในตารางคดี** — เปลี่ยนผู้รับผิดชอบ/ปิดคดีหลายรายการ, และ column picker (ซ่อนคอลัมน์ "เลขอ้างอิงลูกค้า", "รายได้โดยประมาณ" ที่ส่วนใหญ่ว่าง)
8. **Empty state มี CTA** — "ยังไม่มีคู่ความ", "ยังไม่มีงาน", "ประเภทคดี —" ควรมีปุ่มเพิ่มในที่นั้นเลย
9. **ลบข้อมูล test ออกจาก demo** — คดี "dsaasdas", "ฟหกฟหก", "กกกก" ทำให้ demo ดูไม่น่าเชื่อถือและบิด KPI
