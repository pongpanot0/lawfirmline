# ชุดร่างโฆษณา สำนวน · 15 พ.ย. 2026

ออกแบบเท่านั้น งบวันนี้ 0 บาท ไม่เผยแพร่ ไม่ตั้งเวลา ไม่เรียก Meta และไม่ commit

จากโฟลเดอร์หลักของ repo รัน:

```sh
node marketing/ads/render-ads.mjs
```

ใช้ `playwright` ของ repo และ Chromium ที่ติดตั้งไว้ รอ Trirong / Noto Sans Thai จาก Google Fonts และภาพพื้นหลัง หากเปิด browser ไม่ได้ ฟอนต์หรือภาพโหลดไม่ผ่าน ข้อความล้นหรือออกนอกภาพ พื้นที่กล่องข้อความเกิน 30% หรือ Story หลุด safe zone สคริปต์จะหยุด ไม่ย่อหรือซ่อนข้อความเพื่อให้ผ่าน ผลที่สำเร็จอยู่ `out/{a,b,c}-{feed,square,story}.png` ขนาด 1080×1350, 1080×1080 และ 1080×1920 ตามลำดับ หากหยุดกลางทางให้ถือว่ามีเพียงบางภาพสำเร็จ

เปิด `ad.html` ผ่าน HTTP server แล้วเลือก `?c=a&f=feed` เปลี่ยน c เป็น a/b/c และ f เป็น feed/square/story ได้ ใช้ HTML เดียว ภาพ `bg-*.png` สร้างด้วย built-in imagegen; prompt ที่ใช้จริงอยู่ใน `ads.json` ข้อความอยู่ชั้น HTML แยกจากภาพ AI

เริ่มตรวจทั้งภาพเต็มและภาพย่อบนมือถือ โดยเฉพาะจังหวะตัดคำไทย จากนั้นเมื่อมีงบค่อยทดสอบ A เทียบ B ใน Feed ก่อน ใช้ outbound CTR และต้นทุนต่อการเปิดหน้าเว็บถ้าวัดได้ คุมกลุ่มเป้าหมาย งบ และช่วงเวลาให้เท่ากัน แล้วนำแนวที่ได้สัญญาณดีไปเทียบ C รายละเอียดอยู่ `concepts.md` ไม่มีผลทดสอบโฆษณาจริงในชุดนี้

กติกา Meta ที่ยึดตาม brief: พูดถึงสำนักงานและสถานการณ์ ไม่ระบุหรือส่อว่ารู้คุณลักษณะของผู้ชม ไม่ใช้ “คุณเป็นทนาย…?” ไม่รับประกันผลหรือความแม่นยำ ไม่ให้คำแนะนำทางกฎหมาย ไม่ขู่ผลคดี ไม่แต่งตัวเลขหรือคำรับรอง ไม่เสนอส่วนลด ทดลองฟรี หรือข้อเสนอที่ยังไม่มี AI ช่วยงานเมื่อคนเรียกใช้ ทนายตรวจและตัดสินใจ มีปุ่ม LEARN_MORE เพียงแบบเดียว ไม่ใส่ข้อมูลคดีจริง ตราครุฑ ตราชการ หรือชื่อศาลในภาพ

ข้อความนี้เป็นแนวทางตาม brief ไม่ใช่ผลการตรวจอนุมัติจาก Meta ต้องตรวจนโยบายปัจจุบันและปลายทางอีกครั้งก่อนลงจริง

## ส่งต่องาน / สิ่งที่สังเกต

controller เป็นผู้สังเกตตาม task-observer; งานนี้ไม่สั่ง controller ไม่เรียกระบบเผยแพร่ และไม่อ้างว่ามีผลสังเกตจาก controller ที่ไม่ได้รับ ตรวจพบไฟล์การตลาดเดิมที่มีการแก้ค้างอยู่ก่อนเริ่มและไม่ได้แก้ทับ ขอบเขตงานมีเฉพาะโฟลเดอร์ชุดนี้และ `marketing/ads/render-ads.mjs` บันทึกผลตรวจจริงใน `verification.txt`

ตรวจ JSON และเพดานข้อความผ่าน แต่ Chromium เปิดไม่ได้ใน sandbox: `MachPortRendezvousServer: Permission denied (1100)` จึงยังไม่มี PNG โฆษณาทั้ง 9 แบบ ยังไม่ยืนยันฟอนต์ การตัดคำ ข้อความล้น พื้นที่ข้อความ หรือ safe zone จากภาพเรนเดอร์จริง ต้องรันคำสั่งข้างต้นใน Terminal ที่เปิด Chromium ได้ก่อนนำไปใช้
